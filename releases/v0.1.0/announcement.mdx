# MoonBox v0.1.0

发布时间：2026-08-08 23:44:51

关联 Sprint：sprint-001

MoonBox v0.1.0 汇总 sprint-001 已归档交付，覆盖官网首页品牌视觉、Web 登录页、数据库双环境兼容、管理后台用户管理、后台认证、后台 CRUD 列表页模板、首次登录激活状态治理，以及研发治理流程优化。

## 新增

- 官网首页品牌视觉与登录入口体验。
- Web 登录页返回首页、Logo、用户名密码表单、记住我和登录按钮。
- 管理后台用户管理、头像上传、敏感操作确认、状态操作和审计边界。
- 管理后台登录认证、access token、服务端会话记录、退出登录和后台 API 鉴权。
- 管理后台 CRUD 列表页模板、分页、确认弹窗、表单弹窗、toast、加载和空状态。
- 后台用户首次登录激活、冻结前状态记录与解冻恢复策略。
- SQLite 开发路径与 MySQL 生产兼容路径。
- 原型驱动 UI 验收、命令顺序、Sprint 与 OpenSpec 治理优化。

## 修复

本版本没有纳入正式 BUG 范围。

## 发布注意事项

本公告已进入 release-prepare 阶段。正式发布前仍需完成镜像构建计划、镜像构建证据和最终 publish 确认。

## 升级步骤

- 升级前备份数据库和对象存储中与管理后台用户、头像上传和会话相关的数据。
- 部署 v0.1.0 对应的后端、Web、Docker Compose 与环境变量配置。
- 执行数据库迁移或 schema drift 校验，并完成 MySQL smoke。
- 完成后台登录、用户管理、头像上传、冻结/解冻、首次登录激活和首页/登录页 smoke。

## 回滚

- 回退到上一 Git tag 或上一部署包。
- 恢复上一版本环境变量、Compose 配置和镜像 tag。
- 按数据库回滚说明恢复备份或回退迁移。
- 复核后台 token/session、用户状态和头像对象访问。

## 已知问题

- 镜像构建计划和镜像 manifest 尚未生成，发布前需继续执行镜像发布链路。

## 影响范围

- Web 管理后台：登录、用户管理、CRUD 列表页模板和首次登录激活状态治理。
- Web 公开端：首页品牌视觉与登录入口体验。
- 后端：后台认证 API、管理后台用户 API、会话记录、上传读取与权限边界。
- 数据库：SQLite/MySQL 兼容路径、管理后台用户、会话和冻结前状态相关 schema。
- 对象存储：管理后台头像上传与对象访问链路。
- Docker：本地/生产 Compose、后端/Web Dockerfile、部署矩阵与镜像发布链路。
