# sprint-002 Release Note

## 计划范围

- REQ-0009：新增 `/git-check` 推送前安全检测命令。
- REQ-0012：建设 MoonBox 前台需求中心首版 9 阶段 Requirement/Bug 看板与空间上下文交互。
- REQ-0013：接入需求中心真实数据，新增登录保护的 BFF 聚合接口并替换前端 Mock 数据。
- REQ-0014：实现前台用户菜单个人资料弹窗，支持头像和昵称修改并即时刷新当前用户上下文。
- REQ-0015：为 Web 登录页密码输入框新增显示/隐藏切换控件。
- REQ-0016：统一账号认证与个人中心 API，迁移到 `/api/v1/auth/*` 并统一前端 session 与头像上传边界。
- REQ-0017：新增后台管理空间管理模块，覆盖空间列表、申请审批、回收站、空间详情、配额生命周期、通知审计和原型驱动 UI 验收。
- REQ-0017：空间有效期固定日期支持时分秒与季度末默认值，详情概览展示真实最近 6 条审计，操作记录支持分页、标签化摘要和右侧明细抽屉。
- REQ-0017：操作记录分页轻量化，操作明细中的变更前后值支持格式化 JSON 展示；空间列表长期有效文案统一为“长期有效”。
- REQ-0017：优化空间详情成员表格行距与最近操作字重，降低信息拥挤和视觉抢占。
- REQ-0017：空间有效期固定日期改用后台日期时间选择控件，可直接选择日期和时分秒。
- REQ-0017：优化操作记录详情抽屉空值展示，避免“无”占用大块 JSON 区域。
- REQ-0017：优化后台亮主题金色主按钮文字颜色和字重，成员 Tab“添加成员”等主操作按钮在亮/暗主题下保持可读。
- REQ-0017：修复空间回收站数据来源，回收站 Tab 独立请求真实 `status=RECYCLE` 分页数据并展示删除时间、删除人、删除原因、剩余天数和回收站专属操作。
- REQ-0017：修复回收站行内“更多”菜单遮罩问题，回收站更多菜单与普通列表一致使用 body 级 fixed 浮层并保持按钮锚定、主题适配和分页/表格不遮挡。
- REQ-0017：回收站更多菜单位置回退到按钮下方，修复无更多操作时仍展示空菜单面板的问题，避免只露出面板边框。
- BUG-0001：修复 Docker Web 管理后台登录 API 误路由与 `/admin` 直达 404。
- BUG-0002：修复首页前台登录入口误跳后台登录页。
- BUG-0003：修复官网「开启 MoonBox」进入 `/#login`，应进入 `/login` 独立登录页。
- BUG-0004：修复前台用户菜单“修改密码”入口点击无效。
- BUG-0008：修复管理后台当前登录管理员可冻结或删除自己的安全问题。
- BUG-0009：修复前台与后台侧边栏版本号展示不一致。

## 预期用户价值

- 开发者和 Agent 在推送前可统一检查 staged/tracked 文件中的隐私数据、真实环境文件、运行时数据、数据库文件、大文件、密钥/Token/连接串、本机绝对路径和不应进入 Git 的本地数据。
- 产品与研发角色可在 MoonBox 前台统一查看 Requirement 与 Bug 从采集、规划、评审、Sprint、OpenSpec、研发、验收到归档的完整流转。
- 需求中心需登录后访问，可基于治理事实源展示真实统计、筛选、搜索、当前项目空间、权限态、加载态、错误态和空态；Docker 环境通过只读治理挂载读取 `project.yaml`、REQ、BUG、Sprint 与 OpenSpec 事实源，降低 Mock 数据误导。
- 前台用户可在需求中心用户菜单中维护个人头像和昵称；保存后无需刷新页面即可看到最新菜单展示，并保持头像上传、受保护读取和昵称清空回退一致。
- 管理后台 Docker Web 入口可通过同源 `/api` 正确访问后端，并支持 `/admin` 直达和刷新。
- 前台用户从首页主入口进入时将打开前台登录页，后台登录仅保留在明确后台入口；当前前台登录原型提交会进入前台需求中心，不再静默无响应。
- 官网「开启 MoonBox」和「打开第一个项目」将进入 `/login` 统一登录路由；统一登录页复用后台登录 API，成功后进入 `/requirements`；`/admin` 未登录也回到 `/login`，不再展示独立管理后台登录页。
- 前台用户可从需求中心用户菜单打开“修改密码”弹窗，复用既有改密接口；弹窗在前台主题中清晰可读并可填写，普通前台用户也可修改自己的密码，继续编辑密码字段会清理旧接口错误，成功后会清理前后台会话并回到 `/login` 重新登录，后台管理接口权限不变。
- 登录页用户可临时显示或隐藏已输入密码，便于确认复杂密码输入，同时保持登录提交、记住我、错误反馈和敏感信息安全边界不变。
- 前台用户和后台管理员将使用同一套 `/api/v1/auth/*` 认证与个人中心能力，所有登录用户可维护自己的昵称、头像和密码；后台管理接口仍保持独立授权，旧 `/api/v1/admin/auth/*` 路径不再作为正式接口。
- 后台管理员可在空间管理模块中治理空间全生命周期，完成空间与产品一对一绑定、申请审批、回收恢复、配额预警/超限、有效期、冻结恢复、永久删除、通知与审计追溯。
- 后台管理员不能冻结或删除当前登录账号；用户管理列表保留对应操作按钮但置为禁用状态，不额外显示当前账号标签，降低误操作和界面跳变。
- 前台需求中心与管理后台用户管理页将展示一致的 MoonBox 产品版本号，降低发布状态误判。
