# 固定候选隔离验收

`candidate_template.py` 读取部署批准的 `MOONBOX_CANDIDATE_TEMPLATE` JSON 文件；文件为绝对路径、非符号链接、禁止组/其他人写入，并且不能位于被验证候选内。请求端不指定模板、命令或物理路径。

首期模板 `moonbox-web-python-v1` 固定 linux/arm64、Python/MySQL/浏览器三个镜像 ID（`sha256:`）、依赖锁摘要、Python ASGI 入口、迁移/种子/检查命令数组以及既有浏览器计划。实际 MySQL 必须为8.4；SQLite 独立矩阵也必须通过。批准命令不使用宿主 shell，候选只读挂载，写入仅限独立 `/state` 和 `/tmp`。模板用于满足自身已批准验收计划的项目；不能把简单健康检查模板当成任意项目的完整验收。

`MOONBOX_CANDIDATE_ROOT` 是 API 和 worker 共用的持久受控目录，部署时显式设置。目录包含环境锁、固定源导出、控制计划和浏览器证据；不得指向仓库或业务数据目录，不挂载整个宿主 HOME。生产不依赖默认临时目录。镜像依赖必须预装且由批准计划的依赖锁摘要对应，不在候选执行时联网安装。

`candidate.py` 先写 `verification_candidate_environments`，记录精确候选、模板、Docker daemon、租约和清理状态，再创建 internal 网络与独立临时数据库。全局最多两个未清理环境、每空间一个；每环境命令有限超时，总期限120分钟。应用/数据库各1CPU、2GiB、256进程，浏览器复用原执行器1CPU/1GiB；源码导出上限512MiB/十万文件，输出上限2MiB；不复制链接、Git管理或凭据目录。源代码不持有Docker控制接口。

迁移、合成种子、应用健康和固定候选版本探针、适用检查、浏览器检查全部成功后保存证据摘要。随后清理容器和专属网络，复查零残留后才返回 passed。失败仅公开稳定原因，不输出命令原文、连接串或日志。任务结果和清理结论分别持久化。

worker 每次处理工作前核对遗留环境；文件锁仍被控制器持有则跳过，失去控制器时只核对与清理资源，不重跑未知测试。daemon 变化、错误标签或外部网络连接导致清理拒绝。环境重试保留原期限；过期须重新建立候选。合入仍由当前具备迭代操作权限的人确认。

测试的 `MOONBOX_TEMP_RUN` / `MOONBOX_TEMP_EXPIRES` 仅由登记后的本地验收进程注入，给容器及网络附加临时环境三标签。产品没有客户端设置这些参数的接口。测试替身明确标注，不能开启正式模板。

本模块交付 REQ-0048 对三个工作区需求的必要供应依赖；全量 Chat 自主编排、继续/停止 UI 和角色矩阵仍保留后续范围。

## Chat 隔离验收编排（REQ-0048，实施中）

`acceptance_*` 在固定候选供应底座上增加持久操作、尝试、分项结果、资源预留和短期身份引用。HTTP 与 `moonbox_exec.acceptance_operation` 共用鉴权，浏览器只提交会话、来源轮次、Change、幂等键或当前版本号，不能传命令、镜像或路径。HTTP创建接收执行器已关闭且文件已归集的授权检查点；原生工具可在所属存活轮次内捕获独立检查点。`acceptance_tool.py` 实现一次发送及完成确认；`acceptance_delivery.py` 使用正常Chat准入事务建立最多一次关联续接，未知发送/执行、取消、撤权及预算不明均拒绝。

部署须单独设置 `MOONBOX_ACCEPTANCE_TEMPLATE` 和 `MOONBOX_ACCEPTANCE_ROOT`，缺配置只将相关操作标为受阻。模板为 `moonbox-chat-acceptance-v1`，包含原候选 `base`、固定 Node 镜像、Python/Node/MySQL/Chromium/Firefox 实际版本、批准角色、逐 AC 的 argv/database/role、身份 issue/revoke/login 适配、部署摘要和 bounded-tmpfs 策略。仅 linux/arm64；amd64 未验证，不启用。模板应位于代码仓库外的部署受控目录，禁止组或其他人写入。验收目录应为独立私有目录，不能使用业务库、仓库或用户主目录。

每操作原始总期限120分钟，排队30分钟、准备20分钟、全部检查60分钟、单项10分钟。恢复不延长期限；新尝试保留旧尝试证据，仅复验非通过项；部署模板摘要变化会使保留结果失效并拒绝执行，不能跨模板复用通过结果。操作取消增加 epoch，拒绝迟到结果和续跑。worker 每30秒重验权限及续租；扫描仅在取得本机执行锁并核对 daemon、所属标签与检查点后回收。清理失败保留测试结果，自动重试有30/120秒退避且最多三次，人工重试仍需当前版本和写权限。

每个预留最多4CPU、8GiB内存、20GiB磁盘和2GiB证据，最多两槽、每空间一槽；主机容量不足会减少可用槽，平台另留2CPU/2GiB。容器使用只读根、有限 tmpfs 和受控证据文件。旧候选供应与验收编排共用持久预留，旧版未登记且未清理的候选环境会阻止新环境入场；共享池合成竞争回归及原候选真实 SQLite/MySQL 路径已通过。新编排双浏览器、SQLite/MySQL、角色登录和容器资源采样已在登记合成项目通过；完整磁盘硬限额边界仍需实测，当前不能据此声明完整资源 AC 已通过。来源内容、身份文件和原始命令输出不进入公开响应。身份私有介质0600，租约最长15分钟；撤销失败仍尝试精确移除环境，未证明资源消失则保留失败状态。

证据摘要经原会话/项目权限读取，按结果形成时间提供7日在线窗口；心跳不延长保留期。`acceptance_archive.py` 自动转存逐AC脱敏摘要并校验不可变哈希，HTTP长期读取重验ACL；原始视觉/日志不自动延长访问期限。完整产品证据尚待接入。合成项目回归只证明标明的 SQL、Docker 或 UI 机制，不替代真实产品轮次、模型续接、部署批准模板或完整签认。

## 续接与长期摘要运行边界

新建受控实现线程注册固定App Server 0.153.4原生工具；旧thread/resume协议无动态工具参数，不能补造能力。存活轮次发送预留和完成确认分离，未知发送不重放；已确认失败且关闭/归集/释放的来源最多创建一次正常Chat关联轮次。有限token仅用原余额，总期限不重置，关联轮次禁止再建操作扩展续接次数。权限、取消与输入在准入及执行入口复核。

长期摘要复用项目写锁与原子文件发布，pending记录可在写后中断恢复。材料仅保留逐项结果和摘要，不复制原始日志/截图。归档后根据唯一Change身份定位原材料，当前ACL和SHA-256仍逐次验证。API和worker需要共享授权项目目录及MOONBOX_GOVERNANCE_STATE_ROOT；每60秒有界扫描并轮转游标。真实模型和产品签认仍待接入。
