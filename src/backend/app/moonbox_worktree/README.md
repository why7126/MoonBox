# moonbox-worktree

可信 Git 管理适配器，通过 Git common directory 识别同一物理仓库。创建真实 linked worktree；不采用导出后重新初始化的副本。

创建、候选生成、合入和清理使用同一仓库文件锁。拒绝路径重叠、未知目录接管、删除主目录、脏工作树和未合入成果。候选生成不修改工作目录；候选有目标与源两个父提交，合入仅快进到该候选，保留任务提交。重复对账已到达的候选不再合入。

调用方负责当前权限、交付门禁、工作区写锁、验证证据、用户确认和操作日志。该适配器本身不授予合入权限，不提供沙箱，也不能阻止外部进程绕过 MoonBox 修改 Git。Git 结果未知时保留现场，不使用 reset、stash、强制删除或强制推送。
