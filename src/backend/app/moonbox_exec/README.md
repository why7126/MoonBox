# moonbox-exec

非交互服务适配，接收服务端已认证的 actor 和数据库上下文，复用 `moonbox_core` 的工作区、交付权限与合入策略。支持列表、登记主目录、创建开发树、创建后继会话、清理、恢复预检、候选准备和人工确认记录。

不接受客户端声明角色；调用者仍需履行真实用户确认交互，不能将后台调度当作确认。异步 Git 与恢复操作由对应持久 worker 服务推进。首期没有新增 TUI，也没有另建绕过 Web 鉴权的命令服务。
