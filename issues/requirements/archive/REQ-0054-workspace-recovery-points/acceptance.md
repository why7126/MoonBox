# 工作区恢复点复用保留与冲突恢复验收标准

## 验收说明

所有清单初始未执行；文档检查不构成产品验收。FR、US 与 AC 按编号一一对应。实现阶段逐项附输入版本、脱敏环境、操作与观察结果；失败项保留证据，不以 wrapper 成功代替真实结果。

## 功能验收

- [x] AC-001 **历史与恢复分离**（FR-001 / US-001）：连续只读轮次保留历史但不新增文件恢复点；多个轮次可引用同一完整版本；上下文摘要和缺正文旧记录不可显示为完整可恢复。

- [x] AC-002 **按变化采集**（FR-002 / US-002）：连续写轮次复用可信前轮结束版本；无文件变化不新增版本；外部改动后重新采集；写前采集失败时模型/命令尚未开始修改文件。

- [x] AC-003 **采集覆盖**（FR-003 / US-003）：在授权范围内分别新增、修改、删除普通文件并改执行位，恢复得到正确内容与模式；排除项不采正文；链接不跟随越界；备份范围缩小同步限制执行器写范围。

- [x] AC-004 **采集中变动**（FR-004 / US-004）：采集中修改文件或中断内容写入，不发布虚假完整版本，原有效基线仍可用；重启丢监听后完整复核；相同内容复用对象、删除记录仍可解释。

- [x] AC-005 **十版本轮转**（FR-005 / US-005）：创建十二个未保护变更点及三个保护点，最后保留最近十个未保护点与三个保护点；无变更轮次不挤出版本；配置零或负数拒绝；不按天自动删除。

- [x] AC-006 **保护与回收竞争**（FR-006 / US-006）：新增引用与 GC 同时发生时有引用内容不被回收；解除一个保护后其他保护仍有效；人工保护仅经授权明确解除；删除工作树后仍可读交付证据。

- [x] AC-007 **内容授权及备份**（FR-007 / US-007）：同仓库去重后未获引用权限者仍无法读取；已删除历史不会因共享内容复活；备份恢复同时验证索引和内容；SQLite 两份自动备份策略不被十版本策略覆盖。

- [x] AC-008 **三方预检**（FR-008 / US-008）：对本轮新增后被人工编辑、删除后被重建、修改后再修改三类路径均标冲突，不删除/覆盖；当前等于结束版本的路径可恢复；预检列出排除项。

- [x] AC-009 **恢复执行**（FR-009 / US-009）：预检后再次改文件或撤权限，执行被拒绝且无覆盖；冲突可生成恢复用途目录供检查，不计活动开发树且不能直接接新开发；Git 暂存区和业务数据库不冒充已还原。

- [x] AC-010 **部分恢复中断**（FR-010 / US-010）：在多文件恢复中间中断，重启逐项核对已完成内容后续接，不盲目重放；同幂等键返回原操作；未知执行状态不自动重新调用模型。

- [x] AC-011 **磁盘及旧数据**（FR-011 / US-011）：模拟空间不足，保留已有点与成果并阻断新的受保护写入；旧缺正文快照标不可完整恢复；历史完整版本校验后迁移；不额外加入用户总量门槛。

- [x] AC-012 **模块和观测**（FR-012 / US-012）：执行采集、预检、恢复、回收成功与拒绝样本均关联仓库/工作区/轮次/操作；日志无文件正文、密钥或私有路径；采集范围和完整性状态可从 Web 查询。

## 数据、安全与观测验收

- [x] AC-DATA-001 SQLite 与 MySQL 分别验证迁移、约束、并发与失败续接；升级失败保留旧数据和恢复路径；OpenAPI、Orval、数据库设计及部署挂载说明同步。
