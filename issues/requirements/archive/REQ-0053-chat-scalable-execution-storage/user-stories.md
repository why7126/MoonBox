# Chat 无默认运营配额与大规模工作区持续执行用户故事

## US-001 无默认运营配额

作为研发负责人，我希望持续使用同一空间且查看真实用量。

关联：FR-001、002；验收：AC-001、002。

## US-002 大仓库持续执行

作为开发者，我希望仓库增长后仍可建立可信快照并启动任务。

关联：FR-003、004；验收：AC-003 至 AC-006。

## US-003 长结果可靠保存

作为长任务使用者，我希望过程输出持续保存，刷新后仍按顺序可读。

关联：FR-005；验收：AC-007、008。

## US-004 大文本按需阅读

作为审阅者，我希望按需查看全文、文件列表和差异而不冻结页面。

关联：FR-006；验收：AC-009、010。

## US-005 资源异常有明确处理

作为部署维护者，我希望看到不足资源与失败阶段，保留已完成成果。

关联：FR-007、008；验收：AC-011 至 AC-013。

## US-006 安全恢复原轮次

作为任务使用者，我希望资源恢复后续接或核验，避免重复副作用。

关联：FR-009；验收：AC-014、015。

## US-007 历史与用量可信

作为空间负责人，我希望升级后历史可读、计量准确且删除不复活。

关联：FR-010、011；验收：AC-016 至 AC-019。

## 实现一致性核对（2026-10-26）

用户可在保存状态区分别读取执行输出和最终答复，最多保留四页正文；读取失败保留已加载内容。历史准备失败保存在 attempt 与事件中，恢复请求重复提交返回同一尝试。已有停止确认、历史轮次选择与未知状态运行锁继续有效。 验证结论以 Change 当前 acceptance-plan 和证据清单为准。
