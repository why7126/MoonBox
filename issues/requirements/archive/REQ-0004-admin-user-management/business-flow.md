# 业务流程

## 主流程

```text
后台管理员进入管理后台
  |
  v
SYSTEM / 用户管理
  |
  +-- 查看用户列表
  |     |
  |     +-- 输入关键词 / 选择角色 / 选择状态
  |     |     |
  |     |     v
  |     |   自动查询并刷新列表
  |     |
  |     +-- 翻页 / 切换每页条数
  |
  +-- 新增用户
  |     |
  |     +-- 填写用户名、头像、昵称、角色
  |     +-- 校验用户名格式与唯一性
  |     +-- 创建成功，状态为待激活
  |
  +-- 编辑用户
  |     |
  |     +-- 用户名只读
  |     +-- 修改头像、昵称、角色
  |     +-- 保存后刷新列表
  |
  +-- 冻结 / 解冻 / 删除 / 重置密码
        |
        +-- 打开设计系统确认弹窗
        +-- 填写操作原因
        +-- 服务端鉴权、幂等校验、版本校验
        +-- 写入审计记录
        +-- 返回 fixed toast 反馈
```

## 冻结用户流程

```text
点击冻结
  |
  v
展示影响提示和原因输入
  |
  +-- 取消 -> 关闭弹窗，不变更用户
  |
  +-- 确认
        |
        v
      服务端冻结用户
        |
        +-- 成功 -> 10 秒内使目标用户有效会话失效 -> 列表状态更新为已冻结
        |
        +-- 失败 -> 显示错误，不改变本地状态
```

## 超级管理员保护流程

```text
加载用户列表
  |
  v
识别系统内置唯一超级管理员
  |
  v
展示系统内置标识和不可操作说明
  |
  v
隐藏或禁用编辑、重置密码、冻结、解冻、删除入口
```

## 与父 REQ 差异

暂无父需求。本需求从平台运营后台材料中抽取“用户管理”能力，不包含 Workspace 管理、授权配额、用量分析、安全中心、日志审计页面和平台管理员权限矩阵。
