# MoonBox 平台运营后台·空间管理 PRD

## 1. 背景与目标

MoonBox 以空间作为产品研发协作和资源隔离容器，并执行“一空间对应一个产品”的强绑定规则。平台运营后台需要提供覆盖创建、审批、启用、冻结、恢复、续期、回收与永久删除的统一治理能力，同时让空间负责人能够管理空间内成员与研发资源、申请扩容，但不得调整平台级配额。

本版本目标：建立可审计、可恢复、可控配额的空间全生命周期管理闭环；降低空间、产品、负责人和资源用量之间的数据不一致风险。

## 2. 用户与核心场景

| 用户 | 核心任务 |
|---|---|
| 超级管理员 | 治理全部空间；提前永久删除回收期空间；保护系统保留空间 |
| 后台管理员 | 创建、审批、编辑、冻结、恢复、续期空间，调整配额并处理扩容申请 |
| 空间负责人 | 管理空间内基础信息、成员、产品及资源；移交负责人；提交扩容申请 |
| 审计人员 | 查看空间全生命周期操作记录及变更前后值 |

## 3. 领域规则

1. 创建空间时同步创建同名产品，二者永久一对一绑定；空间改名时产品同步改名。
2. 空间唯一标识创建后不可修改；正常、冻结、回收期空间均参与重名校验。
3. 空间成员即产品成员，角色为负责人、管理员、普通成员、只读成员。
4. 配额包括成员数、存储量、AI Token/模型调用量；产品数固定为 1，不设产品配额。
5. 用量达到 80% 预警，达到 100% 禁止新增或继续消耗对应资源；已有数据不删除。
6. 到期前 30/7/1 天通知，到期后自动冻结为只读，续期后恢复。
7. 冻结后允许查看、检索、导出及平台管理员调整配置；禁止成员变更、内容修改、任务执行、Agent/Skill 运行及 AI 调用。
8. 删除前必须停止运行中 Agent/任务并完成或关闭未完成迭代；删除后空间、产品和关联数据整体进入 30 天回收期。
9. 回收期内后台管理员可恢复；仅超级管理员可提前永久删除，且必须输入唯一标识并填写原因。
10. 系统保留空间及超级管理员创建的受保护空间不允许删除。

## 4. 功能范围

### 4.1 空间列表（P0）

- 搜索：空间名称、唯一标识、负责人。
- 筛选：状态、创建来源、有效期、用量状态。
- 字段：空间、负责人、成员、产品、用量、有效期、状态、创建来源、更新时间、操作。
- 状态化操作：正常空间可查看/编辑/冻结；冻结空间可查看/恢复；回收中空间不可编辑，其他操作收进“更多”。
- 搜索与筛选区域占满整行；筛选控件宽度保持不变，搜索输入框弹性占据剩余空间。
- 创建空间：填写名称、唯一标识、简介、负责人、初始成员、配额、有效期；成功后同步创建同名产品。

### 4.2 申请审批（P0）

- 展示待审批数量；支持查看申请详情、通过、拒绝。
- 申请信息：空间名称、用途说明、负责人、预计成员数、存储及 AI 资源需求。
- 审批时可调整负责人、有效期与核定配额。
- 拒绝必须填写原因；申请人可修改后重新提交；保留历次审批记录。
- 同一申请人仅允许一条处理中申请；审批前可撤回。

### 4.3 回收站（P0）

- 展示删除时间、删除人、删除原因、剩余天数。
- 后台管理员可整体恢复空间、产品和关联数据。
- 超级管理员可提前永久删除；不可撤销。

### 4.4 空间详情（P0）

- 概览：基本信息、负责人、状态、有效期、创建来源、产品绑定、用量概览；负责人并入详情顶部核心信息区，不再单独占用信息卡。
- 成员：查看成员和角色；平台侧可辅助处理异常成员关系。
- 产品：展示唯一绑定产品，不允许解绑或迁移。
- 配额与用量：展示当前值、上限、百分比、预警状态；后台管理员可调整配额。
- 操作记录：覆盖创建审批、信息修改、负责人移交、成员角色、配额、冻结恢复、续期、删除恢复和永久删除。
- 列表“编辑”打开空间编辑弹窗，可修改名称、简介和有效期；唯一标识不可修改，空间名称保存后同步产品名称。
- 负责人通过详情顶部独立“变更”入口操作；配额通过配额卡调整，避免高风险变更混入常规编辑。
- 概览模块采用双列布局；“基础信息”位于左上，“配额与用量”作为独立模块位于其下方，“最近操作”位于右侧。基础信息与配额用量不得合并为同一卡片。

### 4.5 通知与审计（P0）

- 按事件通知申请人、空间负责人及相关管理员。
- 通知事件覆盖申请、配额 80%/100%、到期 30/7/1 天、冻结/恢复/续期、负责人变更、回收与永久删除。
- 审计记录包含操作人、时间、来源、变更前后值、原因和结果；高风险记录不可删除。

## 5. 用户故事与验收标准

### US-01 创建空间

作为后台管理员，我希望创建空间并同步创建产品，以便一次完成研发容器初始化。

- [ ] 名称、唯一标识、负责人、配额、有效期必填，初始成员可选。
- [ ] 唯一标识格式为小写字母、数字和连字符，且全平台唯一。
- [ ] 创建成功后生成同名产品，空间与产品 ID 建立不可解绑关系。
- [ ] 创建和产品初始化结果写入操作记录。

### US-02 审批空间申请

作为后台管理员，我希望核定申请配额后批准或拒绝申请。

- [ ] 页签角标展示实时待审批数量。
- [ ] 通过前可调整负责人、有效期和三类配额。
- [ ] 拒绝未填写原因时不能提交。
- [ ] 通过后空间与同名产品同步创建，并通知申请人和负责人。

### US-03 治理配额

作为后台管理员，我希望查看并调整空间配额，以控制资源消耗。

- [ ] 80%≤用量<100% 显示警告；≥100% 显示超限。
- [ ] 达到 100% 时，对应资源新增或调用被服务端拒绝，返回明确原因。
- [ ] 下调配额低于当前用量时不删除数据，但立即触发限制。
- [ ] 配额调整必须填写原因并记录变更前后值。

### US-04 冻结与恢复

作为后台管理员，我希望冻结异常或到期空间，并可在条件满足后恢复。

- [ ] 冻结确认明确说明受影响能力。
- [ ] 冻结后所有写入与 AI 执行入口不可用，查看/检索/导出仍可用。
- [ ] 恢复后按原角色、配额和数据恢复可用状态。

### US-05 删除与恢复

作为后台管理员，我希望将空间放入回收期，以降低误删风险。

- [ ] 存在运行中 Agent、任务或未完成迭代时禁止删除并列出阻塞项。
- [ ] 删除需二次确认并填写原因；空间与产品整体进入 30 天回收期。
- [ ] 恢复时空间、产品、成员和关联数据整体恢复。
- [ ] 提前永久删除仅超级管理员可见，需输入唯一标识和原因。

### US-06 查看审计记录

作为审计人员，我希望追踪关键操作，以定位责任和还原变更。

- [ ] 每条记录展示操作人、时间、来源、对象、前后值、原因和结果。
- [ ] 高风险记录不可在产品界面删除或修改。

## 6. 非目标

- 不设计用户侧空间申请页面和空间负责人扩容申请页面。
- 不支持一空间多产品、产品迁移或解绑。
- 不支持自定义角色权限、计费套餐、安全策略和数据区域配置。
- 不提供跨空间成员或资源批量迁移。

# v1.0.1 补充规则：空间有效期

- 空间有效期支持两种互斥类型：`固定日期`、`长期有效`。
- 选择固定日期时必须填写晚于当前日期的结束日期，并沿用到期前 30/7/1 天提醒、到期后自动冻结只读规则。
- 选择长期有效时不保存结束日期，不触发到期提醒或到期自动冻结；仍可被平台管理员手动冻结、删除或调整为固定日期。
- 创建空间、审批空间申请、续期/调整有效期必须使用同一有效期类型组件与校验规则。
- 列表与详情页对长期有效空间显示“长期有效”，不得显示空日期或占位符。

# v1.0.1 UI 基线

空间管理的功能、页面、字段和流程以原 `package.zip` 为准；视觉 Token、侧边栏、按钮、表格、表单、弹窗、状态色及明暗主题与 `MoonBox-Platform-Operations-v1.0.5` 保持一致。

- 主题切换入口位于侧边栏底部用户菜单的下拉列表中，顶部不再设置独立主题按钮。

# v1.0.2 PATCH 补充规则

- 正常状态空间在列表中提供“编辑”入口；冻结状态仅允许平台管理员调整必要配置，回收中空间必须先恢复后才能编辑。
- 常规编辑范围为名称、简介和有效期；唯一标识只读，负责人移交与配额调整继续使用原有独立高风险操作。
- 空间详情顶部展示负责人头像、姓名、角色及“变更”入口，概览中移除独立负责人卡片。
- 空间列表搜索框自适应填满筛选栏剩余宽度，原筛选控件尺寸与顺序保持不变。

# v1.0.4 PATCH 补充规则

- 右侧内容区域不设置顶部导航栏；删除原主题按钮迁移后遗留的空白顶部容器。
- 页面内容从右侧内容区域顶部开始布局，沿用既有 `.content` 内边距，不额外新增占位高度。
- 主题切换继续保留在侧边栏底部用户菜单中。

# v1.0.5 PATCH 补充规则

- 空间详情页“概览”Tab 中，“配额与用量”作为独立卡片放在“基础信息”卡片下方。
- “基础信息”与“配额与用量”保持独立标题、边框、内容及操作入口，不允许合并。
