# 空间管理交互说明

## 1. 信息架构

侧边栏 `OPERATIONS / 空间管理` 进入模块，模块内包含三个页签：空间列表、申请审批（带待办角标）、回收站。点击空间名称或“查看”进入独立空间详情页；详情页包含概览、成员、产品、配额与用量、操作记录五个分区。

## 2. 空间列表

1. 进入页面加载统计卡片与列表，默认显示全部非回收空间。
2. 搜索支持名称、标识、负责人；筛选变更后立即刷新结果。
3. 点击“创建空间”打开大尺寸弹窗，按基础信息、负责人和成员、资源配额三组填写。
4. 名称失焦时校验重名；标识实时转换为小写并校验格式与唯一性。
5. 提交后按钮进入加载态；创建成功关闭弹窗、刷新列表并 Toast 提示“空间与同名产品已创建”。
6. 正常空间显示“查看、编辑、冻结、更多”；冻结空间显示“查看、恢复、更多”，回收中空间不提供编辑入口。
7. 搜索框使用弹性宽度占据筛选栏剩余空间，筛选控件保持原宽度，使搜索与筛选模块完整铺满整行。

## 3. 创建空间弹窗

字段规则：

| 字段 | 规则 | 错误提示 |
|---|---|---|
| 空间名称 | 必填，2–40 字符，全平台不与有效或回收空间重复 | 请输入 2–40 个字符的空间名称 |
| 唯一标识 | 必填，3–32 字符，小写字母/数字/连字符，创建后不可改 | 仅支持小写字母、数字和连字符 |
| 简介 | 可选，最多 200 字符 | 最多输入 200 个字符 |
| 负责人 | 必填，仅可选择正常状态用户 | 请选择空间负责人 |
| 初始成员 | 可选，不得超过成员配额 | 初始成员数不能超过成员配额 |
| 成员配额 | 正整数，必须≥初始成员数 | 配额不能小于初始成员数 |
| 存储配额 | 正数，单位 GB | 请输入有效的存储配额 |
| AI 月配额 | 正整数，单位万 Token | 请输入有效的 AI 配额 |
| 有效期 | 必填，结束日期晚于当前日期 | 请选择有效期 |

弹窗底部提示“一空间对应一个产品，创建后将同步生成同名产品”。取消时若已填写内容，二次确认是否放弃。

## 4. 申请审批

1. 待审批列表显示申请人、申请空间、用途摘要、资源需求和提交时间。
2. 点击“审批”打开审批弹窗，展示原始申请并允许核定负责人、有效期和配额。
3. 点击“通过”后二次确认，成功后生成空间与产品，待办角标减 1。
4. 点击“拒绝”切换为拒绝态，原因必填；成功后记录审批意见并通知申请人。
5. 已撤回或已处理申请不可重复审批；发生并发变化时提示“申请状态已更新，请刷新后重试”。

## 5. 空间详情

- 概览双列区域中，“基础信息”位于左上，“配额与用量”作为独立卡片位于左下，“最近操作”位于右侧；基础信息和配额用量保持两个独立模块，模块内容与操作能力不变。

- 顶部展示面包屑、空间名称/标识、状态、创建来源、负责人和状态化操作；负责人支持在顶部直接发起变更。
- 概览页不再使用独立负责人卡片；基础信息、配额、有效期仍沿用对应编辑入口。
- 列表点击“编辑”打开编辑空间弹窗，可修改名称、简介和有效期；唯一标识置灰只读，负责人和配额不纳入该弹窗。
- 修改空间名称时明确提示产品名称将同步变更。
- 负责人移交只能选择当前空间正常成员；平台管理员可直接选择平台用户并同步加入空间。
- 配额下调低于当前用量时，提交前显示警告，不阻断保存；保存后空间对应资源进入超限状态。
- 操作记录支持按操作类型和操作人筛选，展开查看前后值。

## 6. 冻结、恢复、续期

- 冻结弹窗展示写入、任务、Agent/Skill、AI 调用将停用，原因必填。
- 恢复弹窗展示恢复后的配额和有效期；若已到期，必须先续期或在恢复弹窗中设置新有效期。
- 续期弹窗显示当前到期日和新到期日；保存后通知负责人。
- 到期自动冻结的空间显示原因“有效期已结束”，续期完成后可一键恢复。

## 7. 删除与回收站

1. 删除前执行阻塞检查。存在运行中 Agent、任务或未完成迭代时，弹窗展示阻塞清单并禁用确认。
2. 无阻塞项时要求填写删除原因并勾选影响确认，提交后整体进入 30 天回收期。
3. 回收站展示剩余天数；恢复需确认目标名称未被占用。
4. 仅超级管理员显示“永久删除”。提交前输入唯一标识并填写原因；不匹配时按钮禁用。

## 8. 页面状态

| 状态 | 处理 |
|---|---|
| 加载 | 表格骨架屏，操作按钮禁用 |
| 空列表 | 展示对应页签空态与明确下一步；空间列表提供创建按钮 |
| 请求失败 | 保留筛选条件，展示错误提示与“重新加载” |
| 权限受限 | 隐藏无权操作，直接访问时返回无权限提示 |
| 配额预警 | 80% 黄色、100% 红色；悬停显示当前值/上限 |
| 冻结 | 状态标签蓝灰色，详情顶部显示只读说明条 |
| 回收中 | 显示剩余天数和不可访问业务数据提示 |

## 9. 跳转关系

| 来源 | 动作 | 目标 |
|---|---|---|
| 侧边栏 | 点击空间管理 | 空间列表 |
| 空间列表 | 点击名称/查看 | 空间详情·概览 |
| 申请审批 | 审批通过后点击查看 | 新空间详情·概览 |
| 回收站 | 点击查看 | 回收态空间详情 |
| 详情页 | 点击成员/产品/配额/记录 | 对应详情分区 |
# v1.0.1 有效期交互补充

1. 创建、审批及续期弹窗中的有效期字段先选择“固定日期 / 长期有效”，默认选择固定日期。
2. 选择固定日期时显示日期选择器并设为必填；结束日期必须晚于当前日期。
3. 选择长期有效时隐藏日期选择器并取消日期校验，同时显示说明“空间不会因有效期结束自动冻结”。
4. 长期有效可切换为固定日期；固定日期也可调整为长期有效，保存后记录变更前后值与操作原因。
5. 列表、详情和恢复确认信息统一显示最终有效期类型；长期有效显示明确文案，不显示空值。

# v1.0.1 视觉一致性

原型采用平台运营后台 v1.0.5 的深色默认主题、金色主色、2px 圆角、224px 侧边栏、表格和弹窗样式，并保留亮色主题切换；右侧不设置顶部导航栏，内容区从顶部按既有内边距开始布局。

- 点击侧边栏底部用户信息区展开用户菜单；点击“主题”在暗色与亮色之间切换，切换后菜单收起并显示 Toast。点击菜单外区域收起菜单。

# v1.0.2 PATCH 交互补充

1. 只有 `ACTIVE` 状态且当前用户拥有 `space:update` 权限时显示列表“编辑”。
2. 冻结空间保留平台管理员必要配置能力，但列表不显示常规编辑；回收中空间必须先恢复。
3. 编辑保存前校验空间名称唯一性和有效期规则；名称变化需明确提示同步修改绑定产品名称。
4. 保存成功后刷新当前行与详情顶部信息，并写入操作记录。

# v1.0.4 PATCH 交互补充

2. 用户菜单、主题切换和侧边栏交互保持 v1.0.3 不变。

# v1.0.5 PATCH 交互补充
