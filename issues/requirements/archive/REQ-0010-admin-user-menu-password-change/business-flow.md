# 业务流程

## 主流程

```text
后台管理员已登录
  |
  v
打开用户菜单
  |
  v
点击“修改密码”
  |
  v
修改密码 modal
  |-- 当前密码为空/新密码为空/确认密码为空 --> 字段校验反馈
  |-- 新密码与确认不一致 ------------------> 字段校验反馈
  |
  v
提交当前密码 + 新密码
  |
  v
后端校验 access token 与服务端会话
  |-- 未登录/会话失效/账号不可用 --> 401/受控错误，前端回登录入口
  |
  v
后端校验当前密码
  |-- 当前密码错误 --> 受控错误，不更新密码
  |
  v
后端校验新密码安全规则
  |-- 弱密码/示例密码/与当前密码相同 --> 受控错误，不更新密码
  |
  v
更新当前用户密码哈希 + 记录审计
  |
  v
撤销当前用户所有后台会话
  |
  v
前端清理本地登录态并进入后台登录入口
```

## 与父需求差异

```text
REQ-0005-admin-auth-system
  ├─ 登录：账号密码换取 access token 与服务端会话
  ├─ 退出：撤销当前会话
  ├─ me：读取当前登录用户
  └─ REQ-0010：登录后自助修改当前用户密码
       ├─ 要求当前密码二次校验
       ├─ 更新当前用户 password_hash
       └─ 修改成功后撤销当前用户全部旧会话
```

## 异常流程

| 场景 | 系统行为 |
|---|---|
| 当前密码错误 | 返回受控错误，不透露账号状态或哈希细节，不更新密码 |
| 新密码弱或命中示例密码 | 返回密码规则错误，不更新密码 |
| 新密码与确认密码不一致 | 前端优先阻止提交，并展示字段级反馈 |
| 登录态过期或会话撤销 | 后端返回 401，前端清理本地登录态并回登录入口 |
| 密码修改成功后旧 token 复用 | 后端返回 401 |

## 数据与接口依赖

- 当前登录用户来自后台认证依赖解析，不来自前端传入的用户 ID。
- 密码哈希复用后台认证仓储能力。
- 会话撤销复用当前用户会话失效能力。
- 审计记录复用后台用户管理审计写入能力。

## UI 流程边界

- 本需求只改造管理后台用户菜单和修改密码 modal。
- 不新增独立个人资料页，不新增全页设置表单。
- modal 是原型驱动 UI，后续实现必须按 `prototype/web/context.md` 完成 UI Skeleton 与 1440px 视觉验收。
