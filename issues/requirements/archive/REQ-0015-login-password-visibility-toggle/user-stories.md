# 用户故事

## US-001 默认保护密码输入

作为通过 Web 登录页进入 MoonBox 的用户，我希望密码输入框默认隐藏明文，以便在公共或共享屏幕环境中降低密码暴露风险。

验收要点：

- 进入登录页时，密码输入框默认 `type="password"`。
- 浏览器自动填充和登录提交仍使用既有 `password` 字段。
- 页面不默认展示密码明文。

## US-002 主动查看已输入密码

作为输入复杂密码的用户，我希望可以临时显示密码内容，以便确认自己没有输错。

验收要点：

- 密码字段提供显示/隐藏切换控件。
- 用户触发控件后，密码输入框可在隐藏和显示之间切换。
- 切换不清空、不改写密码输入值，也不触发表单提交。

## US-003 连续输入不中断

作为正在输入密码的用户，我希望切换显示状态后继续留在密码输入框，以便不被迫重新点击或定位光标。

验收要点：

- 切换后应尽量保持输入焦点和光标位置。
- 登录按钮、记住我、错误反馈和返回首页不受影响。
- 登录中状态下不得因切换控件造成布局抖动或重复提交。

## US-004 使用键盘或辅助技术登录

作为依赖键盘或辅助技术的用户，我希望密码显隐控件有清晰语义和可操作状态，以便不用鼠标也能完成登录。

验收要点：

- 切换控件可键盘聚焦，并支持 Enter/Space 触发。
- 控件具备“显示密码/隐藏密码”语义。
- 控件状态可被辅助技术感知。
