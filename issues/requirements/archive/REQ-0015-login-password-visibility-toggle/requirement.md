# 登录页密码显示/隐藏切换功能

## 背景

MoonBox Web 登录页已经具备用户名、密码、记住我、登录按钮、返回首页和登录错误反馈等基础体验。当前密码输入框默认使用密码类型展示，能够保护输入内容，但用户在输入较长或复杂密码时无法主动确认明文，容易因输错密码导致登录失败。

本需求在既有 Web 登录页基础上补齐密码显示/隐藏切换能力，提升登录表单的可用性。该能力仅改变登录页密码输入框的前端展示状态，不改变账号认证、密码规则、会话策略或登录接口。

## 目标用户

- 已获得 MoonBox 访问资格并通过 Web 登录页进入产品空间的用户。
- 使用复杂密码登录、需要确认输入内容的用户。
- 需要依赖键盘或辅助技术完成登录操作的用户。

## 范围

### 包含

- Web 登录页密码输入框默认隐藏明文。
- 在密码输入框内或紧邻输入框提供显示/隐藏切换控件。
- 用户点击或键盘触发切换控件后，密码输入框在 `password` 与 `text` 展示状态之间切换。
- 切换展示状态不得改变密码输入值、登录提交值、必填校验、错误反馈、记住我状态或登录流程。
- 切换控件具备清晰的图标状态、无障碍标签、键盘可操作性和可感知的聚焦状态。
- 保持 Web 登录页在桌面和移动视口下的登录卡片布局稳定。

### 不包含

- 不新增忘记密码、注册、申请体验、验证码、第三方登录、SSO、MFA 或其他认证方式。
- 不修改后端登录接口、Token 签发、会话刷新、权限校验或密码复杂度规则。
- 不覆盖管理后台用户菜单的修改密码流程；该能力由 `REQ-0010-admin-user-menu-password-change` 承接。
- 不覆盖管理员为他人重置密码、首次登录激活、前台个人资料或用户菜单密码修改能力。
- 不新增独立登录页原型、独立个人安全页面或审计日志能力。

## 功能要求

### FR-001 密码默认隐藏

Web 登录页密码输入框 MUST 默认以密码类型展示，进入登录页时不得默认暴露密码明文。

密码输入框 MUST 继续保留当前登录表单所需的字段名、必填校验和 `current-password` 自动填充语义，以避免影响浏览器密码管理器和既有登录提交。

### FR-002 显示/隐藏切换控件

密码输入框 MUST 提供显示/隐藏切换控件。控件 SHOULD 使用项目已有图标体系中的 `Eye` / `EyeOff` 或等价图标表达当前动作。

当密码处于隐藏状态时，控件语义 SHOULD 表达“显示密码”；当密码处于显示状态时，控件语义 SHOULD 表达“隐藏密码”。

### FR-003 切换行为

用户触发切换控件后，系统 MUST 仅切换密码输入框的展示类型，不得清空、重置、改写或持久化密码输入值。

切换后 SHOULD 尽量保持输入焦点和光标位置，避免用户在连续输入过程中被迫重新定位输入框。

### FR-004 登录流程不回归

新增切换控件后，用户名与密码必填校验、登录提交、登录中状态、登录失败反馈、登录成功跳转、记住我控件和返回首页行为 MUST 保持既有语义。

切换密码可见状态不得触发表单提交，不得调用登录接口，不得改变登录错误文案或本地登录态。

### FR-005 无障碍与键盘操作

切换控件 MUST 使用 `button type="button"` 或等价安全机制，避免误提交表单。

切换控件 MUST 提供可被辅助技术读取的标签，并 SHOULD 使用 `aria-pressed` 或等价状态表达当前显隐状态。控件 MUST 支持键盘聚焦和 Enter/Space 触发。

### FR-006 敏感信息安全

密码明文展示只存在于用户主动切换后的当前输入框可视状态中。系统不得将密码写入 URL、日志、错误上报、埋点、截图说明、本地存储或其他可持久化明文位置。

错误反馈和测试断言不得输出真实密码、token、会话 ID 或密码哈希。

## UI 约束

- 切换控件应位于密码输入框右侧区域或与输入框紧邻，视觉上属于密码字段的一部分。
- 密码输入框应预留足够右侧空间，避免输入文本、占位符或浏览器自动填充视觉与切换控件重叠。
- 控件尺寸、颜色、hover、focus-visible 和禁用/登录中状态应与 Web 登录页和现有管理后台密码显隐控件保持一致。
- 控件不得增加登录卡片的高度抖动，不得挤压“记住我”、登录按钮或错误反馈区域。
- 移动视口下控件必须可点按，且不得超出登录卡片边界。
- 图标按钮不应使用额外说明性长文案占据登录卡片空间；可通过无障碍标签和标题属性表达动作。

## 关联需求

- REQ-0002-login-page：本需求是 Web 登录页密码输入体验的后续增强，继承其页面入口、品牌呈现、表单结构和信息收敛边界。
- REQ-0010-admin-user-menu-password-change：该需求已覆盖修改密码 modal 的密码输入显隐；本需求不修改其业务流程，仅可复用相似交互模式。
