# 业务流程

## 1. 主流程

```text
进入 Chat 工作台
  -> 选择或创建个人会话
  -> 输入文字草稿
  -> 可选：添加多张图片
       -> 前端校验格式/大小/数量
       -> 上传或登记图片引用
       -> 展示缩略图、状态、移除/重试入口
  -> 可选：打开 Skill 引用
       -> 读取当前仓库可用 Skill 候选
       -> 选择 Skill
       -> 展示引用 token 与摘要
  -> 点击发送
       -> 后端重验空间/仓库/会话/对象权限
       -> 校验图片与 Skill 引用版本
       -> 构造本轮上下文快照
       -> 记录请求日志、行为事件和 Task Trace 节点
       -> 提交 Codex 执行
  -> 对话区展示用户气泡、助手回复、本轮轨迹入口和状态摘要
  -> 用户查看轨迹、Diff、历史或继续下一轮
```

## 2. 异常流程

```text
图片校验失败
  -> 标记失败项
  -> 保留其他图片和草稿
  -> 用户移除或重试

Skill 候选读取失败
  -> 展示空态或错误摘要
  -> 不暴露本机路径、凭证或宿主机配置
  -> 用户可继续发送无 Skill 的消息

发送时引用失效
  -> 后端拒绝本轮或剔除失效项并要求确认
  -> 不提交不一致上下文

运行中或未知状态
  -> 禁用新增发送
  -> 保留草稿
  -> 停止或恢复后再允许提交
```

## 3. 与父需求差异

| 维度 | REQ-0025 已有能力 | REQ-0028 增强 |
|---|---|---|
| 输入内容 | 文本草稿、对象引用 | 文本 + 多图片 + Skill 引用 |
| 执行上下文 | 对象快照与会话历史 | 增加图片引用快照和 Skill 引用快照 |
| 轨迹展示 | 工具、状态、Diff、详情 | 增加图片/Skill 来源追溯，不保存完整敏感内容 |
| UI 基线 | MoonBox Chat 工作台 | 局部贴近用户提供的 Codex 截图阅读体验 |
| 安全边界 | 个人会话、空间/仓库权限、同会话互斥 | 同步适用于图片、Skill 候选和上下文构造 |

## 4. 数据与权限边界

```text
用户行为
  -> usage_events: 只记录添加/移除图片、选择/移除 Skill、发送结果等脱敏摘要
  -> request_logs: 记录可信 request_id、接口、状态、耗时、错误码
  -> task_traces: 记录图片校验、对象存储、Skill 解析、上下文构造、执行提交
  -> task_trace_spans: 记录节点状态和脱敏 metadata
```

- 前端链路字段只用于归因和排障，不作为权限或租户隔离依据。
- 后端重验用户、空间、仓库、会话、图片和 Skill 权限。
- 对象存储、请求日志、Task Trace 和错误提示不得保存完整图片、完整 Prompt、完整回复、完整 Diff、密钥或凭据。

## 5. 参考截图处理
