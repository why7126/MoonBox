# 继承迭代操作权限的工作区成果确认合入用户故事

## US-001 唯一迭代归属

作为空间成员，我希望系统支持唯一迭代归属，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-001；验收：AC-001。
- 验收要点：服务端解析工作树至链路、Change、Sprint；缺失、重复、跨迭代混合或未正式纳入均阻断；客户端伪造 Sprint 无法改变授权依据。

## US-002 继承操作权限

作为空间成员，我希望系统支持继承操作权限，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-002；验收：AC-002。
- 验收要点：空间所有者/管理员/编辑者且能访问 Sprint、链路与工作区者在有效迭代可确认；只读成员、其他空间成员、被对象 ACL 排除者拒绝；同等权限的发起者可自确认。

## US-003 固定提交范围

作为空间成员，我希望系统支持固定提交范围，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-003；验收：AC-003。
- 验收要点：未提交成果不自动加入候选；固定来源、目标、候选版本与文件范围；保留原提交历史，不自动 squash/rebase；无配置主线时阻断。

## US-004 候选组合验证

作为空间成员，我希望系统支持候选组合验证，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-004；验收：AC-004。
- 验收要点：源分支单独通过但与最新主线组合失败时不得确认；候选冲突保留原树并返回返修；通过证据包含准确候选、目标、来源及环境身份。

## US-005 确认失效

作为空间成员，我希望系统支持确认失效，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-005；验收：AC-005。
- 验收要点：待确认候选提交时保存确认人和版本；确认后来源/目标/候选或迭代关联变化，需要重新验证及确认；确认后撤权在执行前阻断。

## US-006 队列与主目录保护

作为空间成员，我希望系统支持队列与主目录保护，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-006；验收：AC-006。
- 验收要点：两条链路同仓库确认后串行集成；第二条因主线变化回到待验证/确认；主目录受影响脏文件阻断且不 stash/reset；无合法确认不自动合入。

## US-007 持久恢复

作为空间成员，我希望系统支持持久恢复，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-007；验收：AC-007。
- 验收要点：注入 Git 已成功、DB 回写失败，重启核对实际提交后仅补记；重复确认/回调只有一次结果；无法证明 Git 结果时进入待恢复，不重置主线。

## US-008 治理与归档分开

作为空间成员，我希望系统支持治理与归档分开，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-008；验收：AC-008。
- 验收要点：合入后主线受控更新注册表/Sprint 汇总，任务树恶意篡改共享状态不生效；投影写入失败可续接且不再合并；未归档的正式规格不提前生效。

## US-009 证据与清理

作为维护者，我希望系统支持证据与清理，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-009；验收：AC-009。
- 验收要点：已合入记录关联实际提交、授权和验证；工作树清理不删除仍引用恢复点；有未合入返修成果不能删除；撤销已合入成果使用新受控变更。

## US-010 状态能力展示

作为维护者，我希望系统支持状态能力展示，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-010；验收：AC-010。
- 验收要点：待验证、冲突、待确认、排队、合入中、已合入和待恢复均有真实依据；无权限与验证失败分别解释；刷新/断线/重复点击不创建重复合入。

## US-011 审计与模块

作为维护者，我希望系统支持审计与模块，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-011；验收：AC-011。
- 验收要点：缺授权审计持久化时不开始合入；通用遥测失败可降级而不伪造失败回滚；Web 不直接执行 Git，moonbox-core/worktree/rollout 的结果相互可追溯。

## 共同边界

首期保留 Web，模块名统一 moonbox-；工作区、文件恢复、合入分别由三条关联需求承担。故事描述目标行为，不代表功能已实现。

## 实现一致性补充（2026-10-29）

固定来源和目标后创建双父组合候选，由部署批准的隔离模板检查 SQLite/MySQL 8.4、应用和浏览器。未配置模板或检查未通过时不能确认。当前具有迭代操作权限且可访问相应对象的人确认，执行前再次核验权限与版本。同仓库串行合入，主线变化使后续确认失效。Git 完成后独立同步主目录注册表的 workspace_integration 与 Sprint 合入记录；同步失败可续接且不重复合并。治理修改保持可审阅的未提交状态，不自动提交人工修改；正式规格仍只在归档合并时生效。

实施与逐项验收以 `openspec/archive/2026-10-29-add-sprint-authorized-worktree-merge/` 为证据源；本补充不提前签署尚未完成的验收项。
