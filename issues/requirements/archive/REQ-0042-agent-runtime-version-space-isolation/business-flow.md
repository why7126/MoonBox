# 统一主源码目录与交付链路工作区及模块化执行架构业务流程

## 主流程

```text
选择空间与仓库 -> 服务端登记/解析主工作区 -> 选择默认主目录或独立开发树
  -> 校验链路、评审/Sprint/Change、权限与基线 -> 创建或复用唯一开发树
  -> 会话绑定 -> 轮次固定版本/镜像 -> 获取写锁与恢复保护 -> 执行
  -> 保存进度和证据 -> 主看板叠加进度 -> 0055 受控合入 -> 正式归档
失败 -> 保留操作与目录事实 -> 修复权限/基线/环境 -> 核对后续接
```

### 镜像兼容与迁移矩阵

| 条件 | 行为 |
|---|---|
| digest、工具协议与工作区策略均一致 | 原任务可在核对后续接 |
| 仅默认镜像更新、原 digest 仍可用 | 老任务继续固定原版本，新任务使用新版本 |
| 原镜像不可获取或协议不兼容 | 阻断续接并保留成果；显式新任务选择兼容环境，不改写历史 |
| 升级失败 | 回退默认版本供新任务使用，已启动任务逐项核对，不伪装回退执行事实 |

迁移顺序：备份绑定和内容引用 -> 识别物理仓库 -> 登记主工作区 -> 将旧会话映射到原目录身份 -> 校验历史与恢复引用 -> source 使用统一执行入口 -> copy 保留 legacy 身份和成果 -> 三需求集成通过后关闭新 copy 入口并开放独立开发树。每步保存迁移版本和结果；失败不删除旧副本，不将未提交文件自动混入主线。真实支持的镜像 digest/工具版本及数据库迁移脚本由 Change 设计列出，未测组合默认拒绝恢复。

## 状态与异常分支

读取失败保持上次完整展示并标记过期；权限拒绝不变更业务状态；重复提交返回原操作；异步请求迟到不得覆盖另一工作区/候选；未知执行结果保留待核实，不伪造失败或成功。执行前重新确认权限与输入版本，清理不等于交付或归档。

## 动作与浮层矩阵

| 动作 | 浮层 | selector 种子（data-testid） | 状态及行为 |
|---|---|---|---|
| 选择工作区 | popover | workspace-picker | 主目录 / 已有开发树；选择即生效，活动轮次禁止切换 |
| 创建独立工作区 | dialog | workspace-create | 输入链路；准备中 / 已存在复用 / 基线缺失 / 权限拒绝 |
| 清理工作区 | confirm | workspace-clean | 预检 / 被占用 / 未合入 / 可清理；明确确认 |

每个浮层有关闭按钮和 Esc 路径；关闭只退出查看，不取消服务端已接受操作。提交中禁重复提交；提交错误保留上下文。确认类动作因文件写入/合入副作用需要明确确认；轻量工作区选择不额外确认。实现采用共享按钮/弹窗族，错误信息与主操作不重叠。

## 关联与父需求差异

本需求保持独立验收边界；0042 提供工作区身份，0054 提供恢复保护，0055 提供人工确认合入，避免重复实现同一事实源。

## 实现一致性补充（2026-10-29）

工作台的工作区入口使用共享工作区详情浮层；主目录、独立开发、组合验收、独立恢复和历史目录分别标识。会话始终绑定一个工作区，查看选择不会迁移旧会话。同一 REQ/BUG 的子 Change 串行复用，已合入后由主线提交新的正式治理材料，再推进原树基线。主看板正式阶段来自主目录，数据库进度以单独标记展示。模块落位为 moonbox-core、moonbox-app-server、moonbox-exec、moonbox-exec-server、moonbox-rollout、moonbox-worktree，Python 导入使用下划线；首期保留 Web，不交付 TUI。
