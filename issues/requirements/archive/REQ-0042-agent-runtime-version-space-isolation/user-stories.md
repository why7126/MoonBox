# 统一主源码目录与交付链路工作区及模块化执行架构用户故事

## US-001 登记唯一主目录

作为空间成员，我希望系统支持登记唯一主目录，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-001；验收：AC-001。
- 验收要点：同一实际仓库以原路径、符号路径别名或其 linked worktree 重复登记，均解析到同一仓库身份并拒绝重复主目录；远程 URL 相同的不同本地实例不误合并。

## US-002 交付链路复用

作为空间成员，我希望系统支持交付链路复用，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-002；验收：AC-002。
- 验收要点：同一 REQ 的两个子 Change 并发申请，仅创建一个活动开发树；第二个 Change 排队，验收返修仍使用原树；另一 REQ 可获独立树。

## US-003 基线完整

作为空间成员，我希望系统支持基线完整，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-003；验收：AC-003。
- 验收要点：主目录有未提交的任务必要治理材料时创建被阻断，显示缺失材料且不自动提交；材料进入指定提交后创建真实 Git worktree，记录正确基线且不带无关脏文件。

## US-004 会话绑定

作为空间成员，我希望系统支持会话绑定，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-004；验收：AC-004。
- 验收要点：同工作区两会话历史均指向原身份；活动轮次切换被拒绝；删除或替换底层目录后恢复失败且不回落主目录。

## US-005 并行互斥

作为空间成员，我希望系统支持并行互斥，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-005；验收：AC-005。
- 验收要点：同一工作区两个写任务只能一个执行；不同链路可按容量并行；外部编辑后旧版本写入被拒绝或重新预检，公共治理更新串行且不会丢失。

## US-006 治理写入分工

作为空间成员，我希望系统支持治理写入分工，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-006；验收：AC-006。
- 验收要点：任务树可修改本 Change 任务和实现；直接重写公共注册表、Sprint 汇总及已生效规格被拒绝；主线受控流程可更新对应正式事实。

## US-007 看板事实

作为空间成员，我希望系统支持看板事实，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-007；验收：AC-007。
- 验收要点：任务树完成而尚未合入时主看板不显示正式交付；主目录治理读取失败保留上次完整快照并显示未更新；其他工作区证据不能混用。

## US-008 模块复用

作为空间成员，我希望系统支持模块复用，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-008；验收：AC-008。
- 验收要点：Web 与非交互入口对同一身份和输入执行相同鉴权与核心策略；依赖检查证明 Git/内容存储通过受控接口访问；所有模块名使用 moonbox-，无 TUI 交付要求。

## US-009 镜像及资源隔离

作为维护者，我希望系统支持镜像及资源隔离，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-009；验收：AC-009。
- 验收要点：启动时保存镜像 digest 和工具版本；更新默认镜像不改变活动轮次；不兼容恢复拒绝；两个空间的凭证、缓存、端口、数据库和容器资源不交叉。

## US-010 Git 与路径权限

作为维护者，我希望系统支持Git 与路径权限，以便任务成果、权限和执行事实保持可解释。

## US-011 生命周期与清理

作为维护者，我希望系统支持生命周期与清理，以便任务成果、权限和执行事实保持可解释。

## US-012 旧数据迁移

作为维护者，我希望系统支持旧数据迁移，以便任务成果、权限和执行事实保持可解释。

- 对应：FR-012；验收：AC-012。

## 共同边界

首期保留 Web，模块名统一 moonbox-；工作区、文件恢复、合入分别由三条关联需求承担。故事描述目标行为，不代表功能已实现。

## 实现一致性补充（2026-10-29）

工作台的工作区入口使用共享工作区详情浮层；主目录、独立开发、组合验收、独立恢复和历史目录分别标识。会话始终绑定一个工作区，查看选择不会迁移旧会话。同一 REQ/BUG 的子 Change 串行复用，已合入后由主线提交新的正式治理材料，再推进原树基线。主看板正式阶段来自主目录，数据库进度以单独标记展示。模块落位为 moonbox-core、moonbox-app-server、moonbox-exec、moonbox-exec-server、moonbox-rollout、moonbox-worktree，Python 导入使用下划线；首期保留 Web，不交付 TUI。
