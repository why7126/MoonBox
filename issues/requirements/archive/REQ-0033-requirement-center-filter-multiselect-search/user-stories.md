# 用户故事

## US-001 多维度组合筛选

作为产品负责人，我希望在需求中心同时选择多个 Sprint、分级、负责人或阶段，以便一次性查看当前关注范围内的全部对象，而不需要反复切换筛选条件。

验收要点：

- 同一维度内多选使用 OR 语义。
- 不同维度之间使用 AND 组合。
- 卡片列表、阶段数量和空态与当前筛选条件一致。

## US-002 下拉内快速搜索

作为研发或测试协作者，我希望在筛选下拉框内搜索候选项，以便在较多负责人、Sprint 或 Change 选项中快速定位目标。

验收要点：

- 搜索能匹配用户可见名称。
- 含稳定 ID 的选项支持 ID 匹配。
- 清空搜索后恢复完整候选列表和原排序。
- 搜索无结果时保留已选项，不清空筛选条件。

## US-003 清晰的已选状态

作为需求中心用户，我希望通过复选框和触发器摘要理解当前筛选状态，以便确认自己看到的是完整范围还是收敛后的结果。

验收要点：

- 候选项选中、未选、禁用、hover 和 focus 状态清晰。
- 少量选择展示名称，较多选择展示数量摘要。
- Sprint 等于默认范围时展示默认态文案，不计入外层已激活筛选数量；手动改变 Sprint 选择后再展示选项名或数量。
- 支持全选当前候选项、清空单个维度和全局清空筛选；Sprint 全选包含未纳入 Sprint 的对象。

## US-004 稳定排序与可解释候选项

作为项目负责人，我希望常用、当前相关或业务优先级更高的筛选项排在前面，以便减少查找成本。

验收要点：

- Sprint 只展示进行中/已归档两类状态，“当前迭代”作为同行标签，并提供“未纳入 Sprint”候选项。
- 阶段按需求中心业务顺序展示。
- 分级控件内需求优先级按 P0、P1、P2、P3 展示，BUG 严重性按 blocker、critical、high、medium、low 展示。
- 负责人可优先展示当前用户或最近参与者，缺证据时按名称或 ID 稳定排序。

## US-005 安全与权限一致

作为空间成员，我希望筛选候选项只反映我有权访问的对象，以避免通过筛选项、数量或搜索提示泄露隐藏对象。

验收要点：

- 无权限对象不出现在候选项和搜索提示中。
- 筛选控件不作为访问控制依据。
- 错误态不暴露本机路径、内部堆栈、密钥、Token 或原始文档全文。
