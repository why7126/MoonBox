# 用户故事

## US-001 查看已加入空间

作为前台普通成员，我希望空间切换列表只展示我已加入的真实空间，以便避免误以为自己可以访问未加入或已回收的空间。

验收要点：

- [ ] 列表仅包含当前登录用户作为负责人或成员加入的空间。
- [ ] 未加入空间不出现在切换列表中。
- [ ] 回收中空间默认不出现在切换列表中。
- [ ] 空间名称、角色、成员数和状态来自后台空间事实源，而非前端 Mock 或项目配置兜底。

## US-002 切换当前空间

作为前台用户，我希望选择空间后，用户菜单、当前空间和需求中心上下文立即一致更新，以便我在正确空间下查看治理对象。

验收要点：

- [ ] 点击空间项后关闭浮层并回显新空间名称。
- [ ] 当前空间项展示唯一勾选态。
- [ ] 最近选择写入本地缓存前必须通过接口返回的可访问空间列表校验。
- [ ] 切换后统计、筛选结果和看板数据与当前空间上下文一致。

## US-003 识别冻结空间

作为空间管理员，我希望冻结空间仍可切换查看，但前台明确显示只读状态，以便我能查看历史内容而不误触发写操作。

验收要点：

- [ ] 冻结空间在切换列表中带有“已冻结”或“只读”标记。
- [ ] 冻结空间可以成为当前空间。
- [ ] 冻结空间当前上下文包含只读语义。
- [ ] 服务端仍必须校验冻结状态，不允许仅靠前端隐藏写入口。

## US-004 最近选择失效回退

作为前台用户，我希望本地保存的空间失效时系统自动回退，以便登录后不会停留在不可访问空间。

验收要点：

- [ ] 本地保存空间不存在、被移出、进入回收中或权限不足时自动回退。
- [ ] 有其他可访问空间时回退到接口默认空间或首个可访问空间。
- [ ] 没有可访问空间时展示空态，并保留创建或加入空间入口。
- [ ] 失效回退不得短暂闪现不可访问空间名称。

## US-005 前台安全访问

作为产品负责人，我希望普通前台用户只能通过前台安全接口读取空间切换数据，以便后台全量空间、配额和审计信息不会泄露。

验收要点：

- [ ] 普通前台用户不能通过后台管理空间列表接口读取全量空间。
- [ ] 前台接口只返回切换所需字段。
- [ ] 错误态不暴露本机路径、堆栈、数据库错误详情、密钥、token 或审计原文。
- [ ] API 文档和测试覆盖权限边界。
