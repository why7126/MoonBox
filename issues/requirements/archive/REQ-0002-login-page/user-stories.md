# Web 端登录页用户故事

## US-001 从首页进入登录页

作为从 MoonBox 官网了解产品的访客，我希望点击首页的登录入口或 CTA 后进入同一个登录页，以便明确下一步是使用已有账号进入 MoonBox。

验收要点：

- 首页所有登录相关入口进入同一登录页。
- 登录页显示后，首页主体内容被隐藏或退出主交互状态。
- URL 或前端状态能表达登录页状态，刷新 `#login` 可恢复登录页。

## US-002 返回首页

作为误点登录入口或希望继续浏览官网的访客，我希望能从登录页返回首页，以便继续查看 MoonBox 的产品介绍。

验收要点：

- 登录页左上角存在“返回首页”入口。
- 点击返回后恢复首页视图。
- 返回后清除 `#login` 或等价登录页状态。

## US-003 识别 MoonBox 品牌

作为准备登录的用户，我希望登录页延续官网视觉并展示 MoonBox Logo，以便确认自己处在正确、可信的产品入口。

验收要点：

- 登录卡片顶部展示 MoonBox 产品 Logo。
- 登录背景复用首页产品视觉并叠加深色遮罩。
- 登录卡片与背景之间具有足够对比度，表单内容可读。

## US-004 使用用户名密码填写表单

作为已有账号的用户，我希望通过用户名与密码填写登录表单，以便完成最基础的身份认证动作。

验收要点：

- 表单包含用户名、密码、记住我和登录按钮。
- 用户名和密码均为必填。
- 密码输入默认隐藏明文。
- 当前原型提交仅拦截默认提交，不发起真实鉴权请求。

## US-005 避免未定义认证路径

作为使用登录页的用户，我希望页面不出现暂未支持的入口，以免被引导到不可用流程。

验收要点：

- 不展示忘记密码。
- 不展示申请体验。
- 不展示注册、第三方登录、邮箱验证码或手机号验证码。
