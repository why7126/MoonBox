# 个人资料 Modal 原型拆解

## 页面清单

- 管理后台用户菜单栏：触发“个人资料”入口。
- 个人资料 Modal：承载头像上传、昵称编辑、保存和取消。
- 全局 toast：展示保存成功、保存失败或上传失败等反馈。

## 关键区域

- 用户菜单触发区：头像、昵称或用户名、角色摘要、菜单展开状态。
- 菜单项区：“个人资料”“密码修改”“界面主题”“退出登录”。
- Modal 标题区：标题“个人资料”和关闭入口。
- 用户摘要文本区：用户名、角色摘要，只读展示，不出现头像图标。
- 头像上传区：参照创建用户表单，只含一个头像预览位、上传/更换按钮、格式与大小提示、上传错误。
- 昵称编辑区：昵称输入、长度限制、错误提示。
- 底部操作区：取消、保存、保存中状态。

## 状态矩阵

| 状态 | 触发 | UI 行为 |
|---|---|---|
| idle | Modal 初始打开 | 展示用户名、角色摘要、单头像预览位和昵称，保存按钮可用 |
| uploading | 选择头像文件 | 上传按钮和保存按钮禁用，展示上传中 |
| done | 上传成功 | Modal 内单头像预览位即时回显新头像，保存按钮恢复 |
| failed | 上传失败 | 保留表单，展示错误，允许重新上传 |
| saving | 点击保存 | 保存按钮禁用，展示保存中 |
| saved | 保存成功 | 更新用户菜单展示，关闭 Modal 或展示成功 toast |
| save_failed | 保存失败 | 保留输入和头像预览，展示错误，允许重试 |

## 交互触发

- 点击用户菜单触发器：展开或收起用户菜单。
- 点击“个人资料”：打开个人资料 Modal，并关闭用户菜单浮层。
- 点击上传/更换：通过创建用户同款按钮触发隐藏文件选择。
- 选择文件：进入上传状态，上传成功后写入持久 URL 并即时预览。
- 输入昵称：本地更新草稿，保存前不污染会话摘要。
- 点击取消或关闭：丢弃草稿。
- 点击保存：调用当前用户专用更新接口，成功后刷新当前用户摘要和本地缓存。

## 数据依赖

- 当前会话摘要：`access_token`、`expires_at`、`user`。
- 当前用户资料：`id`、`username`、`nickname`、`avatar_url`、`role`、`status`、`is_system_superadmin`。
- 头像上传结果：后端返回持久 URL。
- 临时预览 URL：仅用于当前浏览器会话预览，不写入后端资料。

## 响应式断点

- 1440px 桌面：主要验收视口，确认菜单、Modal 宽度、单头像上传区和底部操作区布局。
- 1024px 窄桌面：Modal 不应超出视口，内容保持可读。
- 768px 及以下：Modal body 可滚动，底部操作可访问；本 REQ 不要求移动端专门重排。

## 1440px 验收焦点

- 用户菜单浮层不被侧栏底部裁剪，点击个人资料后打开 Modal。
- 个人资料 Modal 标题区、用户摘要文本、头像上传区、昵称输入区和底部操作区层级清楚。
- Modal 内只有一个头像图标，即头像上传区的预览位；不得额外展示身份摘要头像。
- 头像预览、上传/更换按钮、昵称输入、错误提示和底部按钮没有重叠。
- 保存成功后菜单头像和昵称即时更新。

## 创建用户头像交互参考

- 参考对象：当前管理后台创建用户表单的头像区域。
- 吸收点：`admin-avatar large` 等价单头像预览位、右侧格式提示、上传/更换按钮、隐藏 file input、上传中禁用重复选择、失败后展示错误并允许重试。
- 不吸收点：用户名、角色等创建用户字段；个人资料 Modal 只编辑头像和昵称。
