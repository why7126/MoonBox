# 用户故事

## US-001 从用户菜单打开个人资料

作为后台管理员，我希望从管理后台用户菜单栏打开个人资料弹窗，以便快速查看和维护自己的头像和昵称。

验收要点：

- 用户点击用户菜单中的“个人资料”后打开 Modal。
- Modal 展示用户名、角色摘要、单个头像预览位和昵称输入项。
- 入口与“密码修改”“界面主题”“退出登录”保持同一菜单体系。
- Modal 采用 MoonBox 现有后台弹窗风格。

## US-002 修改头像

作为后台管理员，我希望在个人资料弹窗中上传或更换头像，以便后台全局区域展示更清晰的个人识别信息。

验收要点：

- 支持 JPG、PNG、WEBP 头像上传，单文件不超过 2MB。
- 上传过程具备 uploading 状态，上传失败可重试。
- 上传成功后同一会话即时预览，保存时写入后端返回的持久头像 URL。
- 头像上传区参照创建用户表单，只展示一个头像预览图标和一个上传/更换按钮。

## US-003 修改昵称

作为后台管理员，我希望在个人资料弹窗中修改或清空昵称，以便后台展示符合我当前身份的名称。

验收要点：

- 昵称非必填，最长 128 个字符。
- 保存时去除首尾空白。
- 清空昵称后用户菜单回退展示用户名。

## US-004 保存后刷新当前用户展示

作为后台管理员，我希望保存个人资料后立即看到菜单栏头像和昵称更新，以便确认修改已经生效。

验收要点：

- 保存成功后刷新当前用户摘要和本地会话缓存。
- 用户菜单栏优先显示昵称；昵称为空时显示用户名。
- 保存失败保留用户输入并提示可恢复错误。
