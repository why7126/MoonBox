# 管理后台 CRUD 列表页模板原型说明

## 原型策略

本需求属于管理后台 UI 模板与组件化需求。当前阶段提供原型上下文与静态 HTML 草图，用于后续 OpenSpec 设计时确认页面结构、组件边界和横切验收点；不要求导出 PNG。

## 页面结构

- 后台 Shell：保留现有后台导航、受保护页面容器和全局反馈区域。
- 页头区域：展示页面标题、简短说明和主操作按钮。
- 筛选区域：支持关键词、状态、时间或页面自定义筛选项，并提供查询与重置操作。
- 表格区域：展示业务字段、状态标签和行级操作。
- 分页区域：总数位于左侧，页码、翻页与每页数量控制位于右侧。
- 弹窗区域：新增/编辑使用表单弹窗；删除、启用、禁用、重置等状态变更使用设计系统确认弹窗。
- 反馈区域：成功和失败使用 fixed toast，不挤压页面布局。

## 页面状态

- 默认：展示筛选栏、表格数据、分页和行级操作。
- 加载中：表格区显示加载状态，页面结构不跳动。
- 空数据：展示与当前筛选条件一致的空态提示。
- 接口错误：展示受控错误文案，不暴露内部路径、堆栈或敏感字段。
- 操作成功：显示 fixed toast，并按模板规则刷新列表。
- 操作失败：显示 fixed toast 或表单级错误，保留可恢复操作路径。
- 低视口弹窗：弹窗 body 可滚动，底部主操作和取消操作可访问。

## 视觉约束

- 复用 MoonBox 管理后台近直角、细线、克制金色强调和深浅主题规则。
- 表格、筛选、弹窗和 toast 不引入新的强装饰风格。
- 页面主操作、筛选区、表格操作和分页位置稳定。
- 常见窄屏下文本不重叠，控件不遮挡。

## 待实现确认

- 后续 OpenSpec design.md 需要明确模板组件命名、props 边界和用户管理页适配策略。
- 后续实现需用浏览器验证分页 DOM、fixed toast、确认弹窗、无 `window.confirm`、computed width 和低视口滚动。
