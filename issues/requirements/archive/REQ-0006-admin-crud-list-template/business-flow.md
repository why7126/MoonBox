# 业务流程

## 总览

```text
新增后台 CRUD 列表页需求
  |
  v
选择后台 CRUD 列表页模板
  |
  v
配置页面结构
  |-- 标题区 / 主操作
  |-- 筛选区 / 表格列 / 分页
  |-- 行级操作 / 状态标签
  |-- 新增编辑弹窗 / 确认弹窗 / toast
  |
  v
接入页面业务字段与接口
  |
  v
执行模板一致性验收
  |-- 筛选、分页、表格、状态操作
  |-- fixed toast 无布局位移
  |-- 设计系统确认弹窗，无 window.confirm
  |-- computed width 与低视口滚动
  |
  v
交付后台列表页
```

## 模板创建流程

```text
开发者创建后台列表页
  |
  v
选择 AdminCrudListPage 组合模式或等价模板
  |
  v
传入页面配置
  |-- 页面标题与主操作
  |-- 筛选项定义
  |-- 表格列定义
  |-- 分页配置
  |-- 行级操作与批量/状态操作
  |
  v
接入业务数据源
  |
  v
补齐页面专属表单、确认文案和状态标签
  |
  v
复核 UI、交互、错误和加载状态
```

## 用户管理页适配流程

```text
读取现有用户管理页
  |
  v
识别可复用结构与业务专属逻辑
  |
  +-- 可复用结构 --> 收敛为模板 / 通用组件
  |
  +-- 业务专属逻辑 --> 保留在用户管理页
  |
  v
回归用户管理页功能与视觉
  |
  v
将用户管理页确认为首个模板验收样板
```

## CRUD 操作流程

```text
管理员在列表页触发操作
  |
  +-- 新增 / 编辑
  |     |
  |     v
  |   打开表单弹窗 --> 校验输入 --> 提交 --> fixed toast --> 刷新列表
  |
  +-- 删除 / 禁用 / 启用 / 重置
        |
        v
      打开设计系统确认弹窗 --> 确认 --> 提交 --> fixed toast --> 刷新列表
```

## 与父需求/关联需求差异

| 关联需求 | 差异 |
|---|---|
| REQ-0004-admin-user-management | 用户管理页提供已验证的后台 CRUD 列表页基准；本需求将其沉淀为可复用模板和组件约束。 |
| REQ-0005-admin-auth-system | 后台认证系统提供访问边界；本需求不定义认证、权限或会话，只要求模板兼容后台受保护页面。 |
