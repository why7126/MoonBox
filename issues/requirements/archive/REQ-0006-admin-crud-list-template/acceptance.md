# 验收清单

## 功能 AC

- [ ] AC-001 提供后台 CRUD 列表页模板结构，覆盖页面标题区、主操作区、筛选区、表格区、分页区、加载状态、空状态、错误状态和操作反馈区域。
- [ ] AC-002 模板支持传入业务字段、筛选项、表格列、状态标签、行级操作、主操作和表单内容，不固化为用户管理页专用实现。
- [ ] AC-003 通用组件或模板边界覆盖筛选栏、数据表格、分页、确认弹窗、表单弹窗、toast 反馈、空状态和加载状态。
- [ ] AC-004 模板与现有后台 Shell 或页头兼容，不引入冲突布局、重复导航或破坏后台整体视觉。
- [ ] AC-005 现有用户管理页完成模板化适配或等价验证，核心能力、视觉密度、筛选行为、表格列展示、分页、弹窗操作和 toast 反馈无可感知回退。
- [ ] AC-006 用户管理页适配后，页面仅保留业务字段、接口调用和业务规则，可复用结构和行为收敛到模板或通用组件。
- [ ] AC-007 新增、编辑、删除、启用、禁用、重置或等价状态操作具备一致的入口位置、按钮层级、确认策略和反馈方式。
- [ ] AC-008 破坏性操作必须使用确认弹窗或等价确认机制，并在成功或失败后给出受控反馈。
- [ ] AC-009 操作完成后，列表数据、分页状态和筛选条件按模板规则刷新，不出现操作成功但页面仍显示旧状态。
- [ ] AC-010 筛选提交、重置、加载反馈、空态提示与当前筛选条件一致。
- [ ] AC-011 表格列定义、行级操作、状态展示和空数据展示稳定，列宽、操作区和状态标签不因内容变化造成明显布局跳动。
- [ ] AC-012 分页支持当前页、每页数量、总量展示或等价能力，并与筛选条件联动。
- [ ] AC-013 模板提供加载中、空数据、接口错误、操作成功、操作失败和权限不足等统一状态呈现。
- [ ] AC-014 错误反馈使用受控文案，不暴露内部接口路径、堆栈、数据库错误或敏感字段。
- [ ] AC-015 后续新增后台 CRUD 列表页优先通过模板和通用组件创建；若偏离模板，需说明偏离原因并保持基础布局、反馈状态和交互规则一致。
- [ ] AC-016 实现不得引入新的前端 UI 框架，不替换现有技术栈，不新增普通 Web 前台、移动端、小程序或桌面端页面能力。

## UI 与测试 AC

- [ ] AC-017 页面视觉符合 MoonBox 管理后台近直角、细线、克制金色强调和信息密度规则。
- [ ] AC-018 页面主操作、筛选区、表格操作和分页位置稳定，常见窄屏下不发生文本重叠或控件遮挡。
- [ ] AC-019 前端测试或浏览器验证覆盖筛选、分页、空状态、加载状态、错误状态、新增/编辑弹窗、确认弹窗和 toast 反馈。
- [ ] AC-020 后续 OpenSpec design.md 必须引用 `trace.md` 的 `knowledge_base_refs`，并说明横切 AC 如何落到模板设计。

## 横切 AC（knowledge-base）

> 来源：`docs/knowledge-base/best-practices/admin-list-page-consistency.md`、`docs/knowledge-base/best-practices/admin-modal-width-css-cascade.md` — 预防 Sprint 002/003 复发类缺陷

- [ ] AC-XCUT-001 后台 CRUD 列表页分页 DOM 必须与当前用户管理页基准一致：总数位于左侧，翻页、页码、“每页显示”文案和条数下拉位于右侧。
- [ ] AC-XCUT-002 成功和失败反馈必须使用 fixed toast，不引发布局位移，不挤压列表、分页、弹窗或抽屉内容。
- [ ] AC-XCUT-003 删除、启用、禁用、重置或等价状态变更必须使用设计系统确认弹窗。
- [ ] AC-XCUT-004 管理后台状态变更不得调用 `window.confirm`。
- [ ] AC-XCUT-005 表格行内操作列在横向滚动或列较多时必须保持易访问。
- [ ] AC-XCUT-006 筛选条件变化后，列表结果、分页状态和空态提示必须与当前条件一致。
- [ ] AC-XCUT-007 TSX 或模板实现中不得让通用 `modal-card` 与专属宽度类并存，避免通用样式覆盖业务弹窗宽度。
- [ ] AC-XCUT-008 新增、编辑或确认弹窗必须在浏览器 computed style 中验收最终宽度，确认最终宽度与设计预期一致。
- [ ] AC-XCUT-009 低视口下弹窗 body 必须可滚动，底部主操作和取消操作必须可访问。
- [ ] AC-XCUT-010 弹窗背景遮罩不得吞掉内部滚动，也不得导致页面主体误滚动。
- [ ] AC-XCUT-011 必填字段、错误提示和底部操作区不得互相遮挡。
