# Chat 按执行状态优化过程输出提示与结果反馈

## 一句话

Chat 按执行状态优化过程输出提示；正常执行中去除重复警告，失败、停止、未知、正文缺口及结果校验失败分别提供明确反馈，覆盖所有命令与普通对话。

## 背景与目标

当前“部分输出 · 不代表执行完成”能避免用户把过程说明误认成最终结果，但正常运行时与“执行中”重复，异常时又未充分区分结果状态和下一步行动。目标是在保留真实状态和过程内容的基础上减少噪音，让用户判断是否仍在执行、是否成功、正文是否完整，以及结果是否通过业务校验。

同一消息展示契约按一条需求记录，各状态为一个交付单元内的分支。P2 为初判：现有提示机制有用途且输出可读，本次主要改进理解成本和异常指引；不据此降低真实执行失败的严重性。

## 承接的探索证据

- 本会话先前 Chrome /chat 刷新观察：BUG-0028 新轮次最终失败，正文包含过程说明，同时显示失败说明和部分输出提示。
- 只读数据核对：旧会话已完成的三轮消息 output_partial 均为 false；新 bug-opsx 轮次为 failed，output_partial 为 true、output_truncated 为 false。属于当时样本，不代表所有命令的现状统计。
- `src/backend/app/chat/assistant_output.py` 根据轮次终态、最终答复和截断情况生成标识；`src/web/src/components/chat/ConversationMessages.tsx` 共用组件显示提示，没有按具体命令分别添加。
- BUG-0030 的历史修复解决已有事件输出但对话正文为空；本需求保留过程输出可见性，优化状态表达，不撤销该能力。

## 范围与建议表现

| 情况 | 建议反馈 | 边界 |
|---|---|---|
| 正常执行中 | 保留执行中状态和过程正文，去除重复的“不代表执行完成”警告 | 不隐藏真实断连或内容缺口 |
| 正常完成且正文完整 | 展示最终结果，不显示部分输出警告 | 执行完成不等于业务结果已通过校验 |
| 失败 | 合并说明执行失败及已保留过程输出，提供查看轨迹入口 | 不自动重试，不把过程中的成功措辞当结果 |
| 停止 | 明确已停止及已保留内容 | 不混同失败或成功 |
| 未知 | 明确结果待确认，提供已有可用的核对/恢复入口 | 不诱导重复发送写入命令，不承诺尚不存在的恢复功能 |
| 正文缺口或截断 | 明确内容不完整及可查看的证据入口 | 与执行状态分别表达，可与成功/失败并存 |
| 结果校验失败 | 明确结果未通过校验，展示可信校验原因或入口 | 助手的成功措辞不能覆盖业务拒绝事实 |

覆盖全部使用共用 Chat 消息展示的治理命令、其他 Skill 和普通对话。文案采用用户可理解的状态，不在产品中暴露内部事件或字段名。具体文案、组合优先级和入口位置在需求完善阶段定稿。

## 非目标与关联边界

- 不在此需求改变命令执行状态机、对象互斥、阶段完成门禁或会话选择策略；这些属于 BUG-0044。
- 不删除过程输出，不伪造最终答复，不因减少警告而掩盖失败、未知或截断。
- 不自动重试、停止、合并、删除会话或回滚已产生的成果。
- 不重做 REQ-0028 的附件/Skill 输入与整体布局，不扩展为全站通知系统。

## 建议验收

- 正常执行时不重复显示同义警告；正常成功且正文完整时无部分输出误报。
- 失败、停止、未知、内容缺口、业务校验拒绝可明确区分；组合状态下信息不冲突、不重复。
- 历史消息、实时流式输出、最终结果到达、刷新/重连后的展示一致，过程内容仍可阅读。
- 各命令与普通对话共享规则，覆盖有无最终答复、有无正文、截断、业务校验不适用等情况。
- 轨迹/核对入口指向对应轮次；状态未知时不能误导用户重复写入。无权限或无对应功能时不显示虚假可操作入口。
- 单元/组件状态组合测试与真实浏览器验证分别记录；页面验证覆盖 1440px 的运行中及异常消息交互。当前未实现或执行新需求验收。

## 补充案例：执行结束与任务完成区分

用户于本次 bug-capture 明确选择将状态混淆反馈补充到本需求，不另建第三条 BUG。来源为产品 Chat 执行 /opsx-apply BUG-0028-requirement-center-card-owner-raw-user-id：验收环境能力不足、助手中途要求补充信息，运行终止或结束与 Change 任务完成容易混淆。

执行轮次结束仅说明运行不再继续，不能替代任务全部完成、验收通过或可归档事实。建议复核“运行已结束但任务未完成/验收受阻”组合，并提供同一对象的可信进度与阻塞原因；不得仅依据助手成功措辞或轮次终态推导交付完成。此案例补充现有组合状态验收，不改变需求生命周期，不承诺尚不存在的恢复入口。

环境能力与预检独立追踪 BUG-0045-chat-acceptance-runtime-capability-gap；执行中问题回答和续接独立追踪 BUG-0046-chat-midrun-question-response-unavailable；阶段迁移与并发门禁继续由 BUG-0044 处理。当前仅记录反馈，未宣称以上产品问题已修复。
