# Chat 过程输出与状态反馈验收标准

## 验收状态

首轮技术验收已完成；本轮返修须重新核验受影响证据。功能合成验证、真实运行观察、原型预览和用户签认分别记录。

## 功能验收

### AC-001 正常执行去重

- [ ] 排队、连接、运行和停止请求中分别呈现真实状态；正常流式输出不出现通用部分输出警告，停止请求中不提前显示已停止。
- 关联：FR-002。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-002 正常终态

- [ ] 成功且最终正文完整时无部分输出警告；普通聊天不显示校验通过；过程和最终内容仍可阅读。
- 关联：FR-003。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-003 失败与无正文

- [ ] 失败有正文时说明已保留过程输出；无正文时说明未收到可展示输出；不自动重试，不重复通用警告。
- 关联：FR-004。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-004 停止

- [ ] 已停止与执行失败明确区分，已产生内容仍可读；无内容时不声称已保留正文。
- 关联：FR-004。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-005 未知与读取异常

- [ ] 服务端未知显示结果待确认；本地请求失败/加载中分别表达状态暂不可用/读取中，不伪造终态，不诱导重复写入。
- 关联：FR-005。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-006 正文缺口组合

- [ ] 运行、成功、失败和停止分别与已知截断组合，保留执行事实并独立显示一次缺口说明。
- 关联：FR-001、FR-006。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-007 缺最终答复

- [ ] 正常运行尚无最终答复不警告；结束后缺最终答复说明原因；最终正文可信到达后清除已解决提示，不隐藏未解决缺口。
- 关联：FR-006。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-008 校验拒绝与待定

- [ ] 成功执行且业务拒绝显示结果未通过校验；待定显示结果待校验；正文成功宣称不覆盖拒绝，展开仍可读原文。
- 关联：FR-007。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-009 组合优先级

- [ ] 失败/停止/未知与校验拒绝、正文缺口组合时主次信息正确，无重复同义警告；不适用校验无虚假结论。
- 关联：FR-008。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-010 轨迹与权限

- [ ] 查看轨迹定位当前消息轮次；无权限/不可用给出真实原因；不出现无效恢复按钮，不新增自动写操作。
- 关联：FR-009。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-011 历史兼容

- [ ] 历史分页、字段缺失和无正文样本不误报成功或一律异常；执行信息可用时保持可信事实。
- 关联：FR-010。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-012 重连与隔离

- [ ] 刷新、重连、最终消息迟到及切换会话后状态收敛，不串用轮次，不被陈旧事件覆盖。
- 关联：FR-010。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-013 全入口一致

- [ ] 治理命令、Skill、普通对话的相同事实组合反馈一致；入口映射和代表性真实执行分别记录，不能宣称逐命令全跑。
- 关联：FR-001—FR-010。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-014 可访问性与观测

- [ ] 键盘可操作，状态不只靠颜色，读屏不逐 token 重播；轮次关联可追溯，不输出凭证、原始 Prompt 或内部堆栈。
- 关联：FR-009、UI约束。证据：对应状态样本、组件/API 断言；涉及交互时附真实浏览器状态与轮次关联摘要。

### AC-027 跨入口归档一致性

- [x] AC-027 REQ与BUG产品评审→CLI开发/验收→产品归档准入一致；标题式和列表式AC统一计数。合法承接不重放模型或应用，真实评审冲突、规则变化、证据过期、执行中和人工未签认均拒绝。

## 验收后归档衔接补充

再次验收产生的报告与 trace 运行正文属于派生输出，不得使归档恢复记录自失效；交付输入、链路身份、真实证据完整性及并发变化仍受门禁保护。验收收尾后必须通过产品与 CLI 共用的正式准入，验收 passed 不等于归档 ready。错误须区分交付输入变化、旧记录过期、规格基线缺证、身份冲突和记录损坏。

关联链路先归档后，验收证据按唯一已完成归档身份定位，继续核对原内容哈希；活动目录仍存在、归档身份歧义、未完成或证据被篡改时仍阻断。
