# 平台提供跨空间项目验证环境业务流程

## 主流程

```text
授权空间/项目 + 验证声明
  → 读取锁文件并生成环境身份
  → 基础工具、依赖、浏览器、系统库和目标服务预检
  → 已就绪？ ─ 是 → 分配隔离任务 → 真实浏览器执行
       └─ 否 → 可准备？ ─ 是 → 受控准备并校验制品 → 重新预检
                         └─ 否 → 返回缺失类别，保持未验收
  → 保存受保护证据与脱敏摘要
  → 项目/Change 验收读取结果，由其自身门禁决定是否完成
```

## 异常与恢复

- 声明或权限无效：预检前拒绝，不访问工作副本或制品。
- 依赖制品缺失且网络不可用：返回不可准备和缺失来源，不把 DOM 合成测试提升为浏览器验收。
- 浏览器启动失败：标记环境失败，保存版本与错误类别；不得标记测试失败或通过。
- 测试断言失败：标记验证失败，保留受权限控制的截图与断言摘要。
- 任务取消、超时或平台重启：维持可查询终态或恢复事实，不重复创建可写工作区；活跃制品引用在清理前释放。
- 撤权：禁止继续读取结果或发起新任务；既有证据按保留策略处置。

## 与 REQ-0042 的关系

REQ-0042 管理基础 Agent 执行镜像及空间运行身份；本需求基于同一授权与隔离原则，为项目验收提供独立制品和浏览器任务，不改变 Chat 执行轮次的权限语义。
