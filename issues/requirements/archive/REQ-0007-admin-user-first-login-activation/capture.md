# 一句话

优化后台用户账号生命周期：新建用户保持待激活，首次登录成功后自动转为正常；冻结待激活用户后解冻应恢复待激活，而不是直接变为正常。

# 原始描述

后台用户待激活首次登录自动激活且解冻恢复冻结前状态。

# 待澄清

- [ ] 首次登录自动激活是否仅适用于角色为“后台管理员”的用户，前台用户是否仍不得登录后台。
- [ ] 待激活用户首次登录是否必须使用创建或重置密码生成的一次性临时密码。
- [ ] 冻结前状态是否通过新增字段记录，还是通过独立的激活状态与访问状态拆分实现。
- [ ] 解冻已冻结用户时，是否需要在确认弹窗中提示将恢复为“待激活”或“正常”。

# 探索结论

建议采纳“首次登录完成激活”的设计：新建用户默认为待激活，用户本人使用临时密码首次登录成功后，账号状态调整为正常。冻结/解冻不应改变账号原本的生命周期阶段；冻结待激活用户后，解冻应恢复为待激活，避免绕过首次激活流程。短期推荐记录冻结前状态并在解冻时恢复，长期可考虑拆分激活状态与访问状态。
