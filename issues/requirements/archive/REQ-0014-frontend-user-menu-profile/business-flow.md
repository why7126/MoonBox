# 业务流程

## 主流程

```text
前台需求中心
  -> 点击左侧用户区域
    -> 打开用户菜单
      -> 点击“个人资料”
        -> 关闭用户菜单
        -> 打开 rc-* 个人资料弹窗
          -> 用户修改昵称 / 上传头像
            -> 点击保存
              -> 后端按当前认证用户更新 nickname/avatar_url
              -> 返回最新当前用户摘要
              -> 前端更新 currentUser 与会话缓存
              -> 关闭弹窗并刷新用户菜单展示
```

## 头像上传流程

```text
选择头像文件
  -> 校验类型与大小
  -> 上传到现有对象存储头像链路
  -> 返回持久 avatar_url
  -> 通过 Bearer token 读取头像资源
  -> 弹窗内即时预览
  -> 保存个人资料时提交持久 avatar_url
```

## 失败流程

```text
上传失败
  -> 弹窗内展示错误
  -> 保留原头像或当前预览状态
  -> 允许重新选择文件

保存失败
  -> 弹窗内展示错误
  -> 保留昵称和头像选择
  -> 允许修正后再次保存

登录态失效
  -> 返回受控认证错误
  -> 前端复用既有登录态失效处理
```

## 与父 REQ 差异

REQ-0012 已提供前台需求中心、用户菜单、空间浮层、主题切换、当前用户展示和受保护头像读取能力。本需求只扩展用户菜单中的个人资料编辑闭环，不改变需求看板阶段、空间切换、进入后台、退出登录或主题切换能力。

## 与后台个人资料差异

REQ-0011 面向后台管理用户菜单，使用后台 `admin-*` 视觉体系。本需求面向前台需求中心，必须使用 `rc-*` 视觉体系；能力可复用当前用户资料接口、头像上传链路和持久 URL 约束，但不得引入后台用户管理字段或后台页面样式。

## 权限与安全边界

- 更新目标必须来自服务端认证上下文中的当前用户。
- 请求体不得指定任意目标用户、角色、权限或账号状态。
- 头像读取继续走后端代理和 Bearer token。
- 错误提示不得泄露对象存储路径、密钥、数据库错误或堆栈。
