# 原型拆解

## 页面清单

| 页面/状态 | 说明 |
|---|---|
| 前台需求中心默认页 | 继承 REQ-0012 左侧边栏、需求看板和当前用户展示。 |
| 用户菜单打开态 | 左侧底部用户菜单展开，账号分组内“个人资料”可点击。 |
| 个人资料弹窗默认态 | 居中弹窗展示账号摘要、单头像预览位、昵称输入、取消和保存。 |
| 头像上传中 | 上传按钮显示上传中，上传按钮和保存按钮禁用。 |
| 头像上传失败 | 弹窗内头像区域下方展示错误，允许重新上传。 |
| 保存失败 | 弹窗内保存区展示错误，保留输入内容。 |
| 保存成功 | 弹窗关闭，用户菜单展示新头像和昵称。 |

## 关键区域

```text
RequirementCenterPage
  ├─ rc-sidebar
  │  ├─ rc-nav
  │  └─ rc-user-zone
  │     ├─ rc-user-trigger
  │     └─ rc-user-menu
  │        └─ 账号 / 个人资料
  └─ rc-profile-mask
     └─ rc-profile-modal
        ├─ header: 标题 + 关闭
        ├─ account summary: 用户名只读摘要
        ├─ avatar picker: 单头像预览 + 上传/更换按钮
        ├─ nickname input
        ├─ error/status message
        └─ footer: 取消 + 保存
```

## 组件层级

- `rc-user-trigger`：继续展示头像、昵称或用户名、当前空间。
- `rc-user-menu`：账号分组内“个人资料”点击打开弹窗；hover 空间浮层行为不被破坏。
- `rc-profile-mask`：弹窗遮罩层，层级高于用户菜单与空间浮层。
- `rc-profile-modal`：前台个人资料弹窗，不复用后台 `admin-profile-modal` 类名。
- `rc-profile-avatar-picker`：单头像预览、格式说明、上传/更换按钮和隐藏 file input。
- `rc-profile-field`：昵称输入与错误提示。
- `rc-profile-actions`：取消与保存，保存为主操作。

## 状态矩阵

| 状态 | 头像区域 | 昵称区域 | 操作区 | 反馈 |
|---|---|---|---|---|
| idle | 当前头像或首字头像 | 可编辑 | 取消/保存可用 | 无 |
| uploading | 保留当前预览或上传中状态 | 可编辑 | 上传和保存禁用 | 上传中 |
| upload_failed | 保留上一个有效头像 | 可编辑 | 可重新上传/保存按有效状态控制 | 上传错误 |
| upload_done | 新头像即时预览 | 可编辑 | 可保存 | 可选轻提示 |
| saving | 当前预览 | 输入保留 | 保存禁用 | 保存中 |
| save_failed | 当前预览 | 输入保留 | 可重试 | 保存错误 |
| saved | 弹窗关闭 | 同步上下文 | 用户菜单刷新 | 成功 toast |

## 交互触发

- 点击用户菜单“个人资料”：关闭用户菜单并打开弹窗。
- 点击上传/更换：触发隐藏 file input。
- 选择文件：进入上传状态，成功后即时预览，失败后展示错误。
- 点击取消或关闭：放弃未保存改动并关闭弹窗。
- 点击保存：提交昵称和持久头像 URL，成功后刷新当前用户上下文与用户菜单。
- 点击 Esc 或遮罩关闭：建议沿用现有 `rc-*` 弹窗关闭策略；实现阶段如不支持，需在 Change design 中说明。

## 数据依赖

| 数据 | 来源 | 用途 |
|---|---|---|
| 当前用户 name/username | 需求中心上下文或会话缓存 | 只读账号摘要和回退展示 |
| 当前用户 nickname | 需求中心上下文或保存接口返回 | 昵称输入初始值与菜单展示 |
| 当前用户 avatar_url | 需求中心上下文或保存接口返回 | 头像预览和菜单头像 |
| access_token | 现有登录会话 | 上传头像与读取受保护头像 |
| 保存接口返回 user | 当前用户资料接口 | 成功后直接更新前台 currentUser |

## 响应式断点

- 1440px 桌面：主验收视口，弹窗居中，用户菜单与弹窗不重叠。
- 1024px 左右：弹窗宽度使用 `max-width` 与视口内边距约束，底部按钮不溢出。
- 768px 以下：弹窗宽度贴合视口，头像区域可纵向排列，长昵称和错误提示不撑破容器。
- 低视口：弹窗 body 允许滚动，footer 保持可达。

## 1440px 验收焦点

- 用户菜单打开态保持 REQ-0012 分组、图标、hover、危险色和空间浮层层级。
- 个人资料弹窗使用前台深色 `rc-*` 面板、细线边框、金色主操作、近直角和紧凑表单密度。
- 弹窗内只出现一个头像预览位。
- 上传错误、保存错误、保存中、上传中不会造成按钮文字重叠或布局跳动。
- 保存成功后用户菜单头像和昵称在同一视口内立即刷新。
