# 治理命令持久化阶段与幂等恢复闭环局部原型说明

## 定位与边界

本原型是前台 Chat 中“操作详情与恢复动作”的局部语义设计，不复刻用户故障截图，不新增整页管理控制台。REQ-0046 管消息反馈布局与文案，本原型只固定恢复能力、按钮和确认语义。使用 MoonBox Ops token，未引用外部资源，无真实 API、模型、写入、鉴权或清理行为；所有状态仅为浏览器内演示数据。HTML 为主原型，本阶段不要求 PNG；真实产品截图待实施采集。

## 页面与组件拆解

1. `#recovery-demo`：操作摘要，显示原对象、原执行终态与业务阶段。
2. `#stage-list`：准备→生成→校验→应用→回读→完成的阶段容器。
3. `#reason`、`#limits`：阻断原因、剩余自动预算及到期说明。
4. `#actions`：只读刷新、继续剩余步骤、重新生成草稿、查看证据。
5. `#resume-dialog`：确认对象、剩余步骤、原终态保留；取消/确认提交。
6. `#evidence-dialog`：脱敏证据摘要，只读关闭。
7. `#feedback`：aria-live 温和反馈，无整页布局跳动。

## 状态与数据矩阵

| 状态 | 主信息 | 允许动作 | 数据依赖 |
|---|---|---|---|
| 可恢复 | 原执行停止；完整成果待确认 | 核验、续接、证据 | 原终态、有效成果、权限、操作版本 |
| 提交中 | 正在续接剩余步骤 | 只读证据；禁重复续接 | 当前尝试、领取凭据 |
| 完成 | 成果已应用，原执行停止仍保留 | 刷新、证据 | 唯一应用、回读版本 |
| 冲突/无权限/不兼容 | 明确阻断原因 | 只读刷新；证据按权限 | reason、allowed_actions |
| 到期 | 成果恢复窗口已过期 | 查看可用诊断，明确重新生成 | expires_at、成果存在性 |
| 结果未知 | 正在确认执行器及提交状态 | 只读刷新 | 租约/执行器终态 |

原型状态选择器是演示控件，产品不提供人工改状态。演示中的恢复成功不是对实际系统的承诺；实际 UI 按后端结果呈现 pending/blocked/completed，不能用定时器推断成功。

## 动作按钮与浮层矩阵

| 动作 | 类型 | Selector | 状态/退出 | 证据 |
|---|---|---|---|---|
| 刷新状态 | 直接只读 | #refresh | loading/error/可用；不确认 | 请求只读与不新增轮次 |
| 继续剩余步骤 | 确认 modal | #resume → #resume-dialog | cancel/confirm/submitting；Esc与取消，提交后仅关闭视图不取消后台事务 | 确认前后、重复点击、冲突 |
| 查看证据 | 只读 modal | #evidence → #evidence-dialog | 关闭/Esc，内容滚动 | 脱敏、权限与正确操作 |
| 重新生成 | 原会话输入草稿 | #regenerate → #draft | 不自动发送，用户显式发送后新建操作 | 无模型调用直到发送 |

续接会产生写入，因此需要显式确认；轻量演示状态选择即时生效，不增加确认。对话框不声明点击遮罩退出，避免提交信息误丢；取消与Esc均有明确行为。真实组件使用项目对话框族，焦点进入弹窗、关闭后回到触发按钮。

## 布局、样式与响应式

桌面1440宽下局部面板最大960px、居中；确认弹窗最大560px且不超视口减32px，最大高度80vh，内容区滚动。小于640px阶段纵向、动作换行，390px不出现横向溢出。背景#0A0D14、面板#131826、边框#242A3A、强调金#D8AC55；字体 Inter/Noto Sans SC/system-ui，正文14px行高1.45，圆角8px。保留文本状态和键盘操作，不只靠颜色。

computed style 采样：#recovery-demo宽度/内边距；#resume-dialog宽度/max-height/overflow；#resume字体/背景/disabled；#reason换行。实现阶段检查浅色主题同义token，不将深色演示视为免检。

## 实施门禁与分工

批次：先Skeleton与数据/权限插槽；再状态和按钮/对话框整族；最后响应式、键盘与错误分支。真实1440px和390px证据、样式及REQ最终一致性在 apply/accept 中完成。本阶段完成拆解，UI Skeleton及真实视觉验收均 pending。API具体路径在Change设计，但读取/写入区分和版本校验不变。
