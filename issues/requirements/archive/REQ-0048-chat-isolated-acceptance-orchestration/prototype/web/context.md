# Chat 自主验收状态反馈原型说明

## 原型定位与事实源

这是原Chat执行详情内的局部交互结构原型，不是新门户，也不是截图复刻任务。业务语义以requirement.md为准；prototype.html仅展示合成状态与动作。沿用现有TurnStatusSkeleton及OperationVerification的展开详情/反馈/核验模式，视觉实现使用项目tokens.generated.css和现有Chat组件。当前原型无后端、无真实凭据；所有点击仅改变示例视图。

## 页面与组件拆解

唯一页面是原Chat会话中的验收详情。层级：会话标题 → 轮次反馈 → 环境阶段与AC摘要 → 可展开详情（能力/数据库/版本/租约/回收）→ 动作区 → 状态反馈。原消息正文、历史轮次及输入行为保持既有语义；状态改变不重建会话。

| 区域 | 原型selector | 当前实现候选/策略 | 数据 |
|---|---|---|---|
| 反馈 | #feedback | turn-status-feedback | 后端状态与稳定原因 |
| 详情 | #details | turn-execution-detail | 原操作/环境/任务摘要 |
| 阶段 | #stage | 在既有详情内扩展稳定testid | 环境阶段与清理状态 |
| AC摘要 | #checks | 在既有详情内扩展稳定testid | 当前有效通过数/总数/阻塞数 |
| 动作 | #actions | 复用既有动作容器 | 服务端允许动作，不由文本推断 |

## 状态与动作族

| 状态 | 允许的示例动作 | 禁止/边界 |
|---|---|---|
| 准备/运行 | 展开详情、查看证据、停止 | 无“重复启动”动作 |
| 局部阻塞 | 重新核验、查看原因；服务端允许时继续 | 核验不执行写入 |
| 恢复 | 查看原执行、状态查询 | 旧轮次终态保留 |
| 停止/已释放 | 查看证据 | 不自动续接模型 |
| 清理失败 | 重试清理、查看原因 | 不重跑AC |

| 动作按钮 | 浮层类型 | selector | 状态/证据要求 |
|---|---|---|---|
| 展开详情 | inline details | #details | 开/关，键盘可达 |
| 查看证据 | inline说明；产品复用授权证据入口 | #evidence | 有/无/过期/无权限，不暴露路径 |
| 重新核验 | 无 | #verify | idle/busy/failed；证明查询无副作用 |
| 继续/重试清理 | 无；按服务端允许动作 | #resume | busy/disabled/error，防重复提交 |
| 停止 | confirm dialog族 | #stop、#confirm-stop | 取消/确认、键盘/Escape，停止后不可自动恢复 |

## 响应式与样式采样

1440px基准：反馈和正文对齐、详情宽度受会话容器限制、动作不挤压正文。390px：动作换行、长原因折行、无页面横向溢出；只在详情内部允许必要滚动。采样font-size、line-height、padding、gap、border、background、color、width、overflow、position。原型颜色参考现有金色强调与浅背景，不作为新的Design System。

## 分批门禁

第一批UI Skeleton复核组件与状态，等待首轮确认；第二批接真实API与动作权限，完成双视口和键盘/取消/重复点击检查；第三批验证失败、恢复与清理状态，完成REQ全包一致性。页面证据在实际Change下采集，本轮不生成产品截图。PNG本阶段不要求，后续真实视觉门禁保留。
