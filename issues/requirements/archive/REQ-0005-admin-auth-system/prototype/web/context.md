# 管理后台登录认证原型说明

## 原型策略

本需求涉及管理后台登录页、退出入口和登录态失效反馈，属于轻量 UI 场景。当前阶段提供原型上下文与静态 HTML 草图，用于后续 OpenSpec 设计和实现时确认页面结构，不要求导出 PNG。

## 页面状态

- 未登录：展示后台登录页，包含品牌标识、用户名输入、密码输入、登录按钮和错误反馈区域。
- 登录中：登录按钮进入 loading 或 disabled 状态，避免重复提交。
- 登录失败：展示受控错误文案，不泄露账号是否存在。
- 登录成功：进入管理后台受保护页面。
- 登录态过期：展示提示后回到后台登录页。
- 退出成功：清理本地登录态并回到后台登录页。

## 视觉约束

- 复用 MoonBox 管理后台近直角、细线、克制金色强调和深浅主题规则。
- 不展示注册、忘记密码、第三方登录、短信验证码、邮箱验证码或 SSO 入口。
- 登录页主操作明确，错误反馈可读但不过度暴露内部状态。
- 移动或窄视口下表单不得横向溢出。

## 待实现确认

- access token 的前端存储位置需在 OpenSpec 设计中结合安全规则确认。
- 401 后的跳转策略需避免死循环，并保留用户重新登录路径。
