# 验收清单

## 功能 AC

- [ ] AC-001 后台登录页提供用户名、密码和登录主操作，且不展示注册、忘记密码、第三方登录、短信验证码、邮箱验证码或 SSO 入口。
- [ ] AC-002 用户名或密码为空时，前端展示可恢复的字段级或表单级校验反馈。
- [ ] AC-003 用户名或密码错误时，后端返回受控错误，不泄露账号是否存在、密码哈希算法、内部用户状态或系统路径。
- [ ] AC-004 登录成功后，后端返回 access token、过期时间和当前管理员摘要。
- [ ] AC-005 登录成功后，后端创建服务端会话记录，且会话记录至少包含会话 ID、用户 ID、过期时间、撤销时间、创建时间和最后使用时间等追溯字段。
- [ ] AC-006 access token 必须有明确过期时间，不得无限期有效。
- [ ] AC-007 每次访问 `/api/v1/admin/**` 时，后端校验 access token 对应服务端会话存在、未过期、未撤销，且关联账号状态仍可用。
- [ ] AC-008 未携带有效凭证、凭证过期、凭证无效或会话失效时，`/api/v1/admin/**` 返回 401。
- [ ] AC-009 已认证但无后台权限时，`/api/v1/admin/**` 返回 403。
- [ ] AC-010 `/api/v1/admin/**` 不再依赖 `x-admin-role: admin` 作为正式鉴权依据。
- [ ] AC-011 后端从 access token 与服务端会话记录解析当前操作者，不信任前端传入的 `user_id`、`role`、`is_admin` 或等价身份字段。
- [ ] AC-012 管理后台前端对后台路由进行登录态守卫，未登录、token 缺失、token 过期、会话撤销或后端返回 401 时进入后台登录页或等价登录入口。
- [ ] AC-013 管理后台提供退出登录入口，退出成功后当前服务端会话失效。
- [ ] AC-014 使用已退出登录的 access token 调用 `/api/v1/admin/**` 时返回 401。
- [ ] AC-015 账号被冻结、删除、重置密码或发生影响权限的状态变化后，相关已有后台会话失效。
- [ ] AC-016 系统首次启动或初始化时，若不存在系统内置超级管理员，则读取环境变量幂等创建唯一超级管理员。
- [ ] AC-017 重复启动不得创建第二个系统内置超级管理员。
- [ ] AC-018 生产环境拒绝空密码、示例密码或弱密码作为超级管理员初始密码。
- [ ] AC-019 初始化密码、明文密码、access token、会话 ID 明文不得写入日志、API 响应、前端页面、错误上报、埋点或审计明文。
- [ ] AC-020 登录失败、登录态过期、会话失效、退出成功和权限不足均有清晰反馈，且页面不出现空白页、死循环跳转或不可恢复状态。

## 安全与测试 AC

- [ ] AC-021 后端测试覆盖登录成功、登录失败、token 缺失、token 过期、会话撤销、退出后复用 token、无后台权限访问和生产弱密码初始化拒绝。
- [ ] AC-022 前端测试覆盖未登录访问后台路由、登录成功进入后台、401 后回到登录入口、退出登录清理登录态。
- [ ] AC-023 API 文档和错误码文档同步公开登录/退出端点、受保护后台接口、401/403 场景和认证 Header 约定。
- [ ] AC-024 数据库文档同步服务端会话记录结构、超级管理员初始化约束和会话失效策略。

## 横切 AC（knowledge-base）

无横切 AC。本需求为后台认证、路由守卫和简单后台登录入口，不涉及管理端 CRUD 列表页、管理端表单页/设置页、管理端弹窗新建/编辑或媒体上传回显，因此未命中 `admin-list`、`admin-form`、`admin-modal`、`media-upload` 知识库标签。
