# 业务流程

## 总览

```text
部署/启动
  |
  v
检查系统内置超级管理员是否存在
  |-- 不存在 --> 读取环境变量 --> 校验生产密码策略 --> 幂等创建唯一超级管理员
  |-- 已存在 --> 跳过创建
  |
  v
超级管理员访问后台
  |
  v
后台路由守卫检查本地登录态
  |-- 无登录态/过期 --> 后台登录页
  |-- 有登录态 ------> 调用后台 API
                         |
                         v
                    后端校验 access token + 服务端会话
                         |-- 401 未认证/会话失效
                         |-- 403 无后台权限
                         |-- 通过 --> 执行管理能力
```

## 登录流程

```text
打开后台登录页
  |
  v
输入用户名和密码
  |
  v
提交登录
  |
  +-- 字段缺失 --> 前端展示校验反馈
  |
  +-- 凭据错误/账号不可用 --> 后端返回受控错误
  |
  +-- 凭据正确
        |
        v
    创建服务端会话记录
        |
        v
    签发 access token + 过期时间 + 管理员摘要
        |
        v
    前端进入管理后台受保护页面
```

## 后台 API 鉴权流程

```text
请求 /api/v1/admin/**
  |
  v
读取 Authorization Bearer token
  |
  +-- 缺失/格式错误 --> 401
  |
  v
验证 access token
  |
  +-- 无效/过期 --> 401
  |
  v
查询服务端会话记录
  |
  +-- 不存在/已撤销/已过期 --> 401
  |
  v
校验账号状态与后台角色
  |
  +-- 账号不可用 --> 403 或 401（按错误码规范收敛）
  +-- 无后台权限 --> 403
  |
  v
注入当前操作者并执行业务逻辑
```

## 退出与失效流程

```text
管理员点击退出登录
  |
  v
调用退出接口
  |
  v
撤销当前服务端会话
  |
  v
前端清理本地登录态
  |
  v
返回后台登录页或未登录状态
```

账号被冻结、删除、重置密码或发生影响权限的状态变化时，系统应使相关后台会话失效，后续请求进入 401/403 处理路径。

## 与关联需求的差异

| 关联需求 | 差异 |
|---|---|
| REQ-0002-login-page | 已归档的 Web 官网登录页仅为前端原型，不连接后端认证；本需求建立真实后台认证能力。 |
| REQ-0004-admin-user-management | 用户管理负责账号元数据和敏感操作；本需求负责后台身份、会话、路由守卫和 API 鉴权边界。 |
