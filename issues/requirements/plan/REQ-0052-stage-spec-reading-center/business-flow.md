# 九阶段流转规范查阅与研发规范中心业务流程

## 主流程

```text
当前项目 → 九阶段入口 → 阶段摘要 → 同版本原文章节
        → 研发规范中心 → 分类/搜索/阶段筛选 → 原文
                      → 迭代日志 → 日志详情 → 历史原文（可用时）
```

读取前校验项目和权限 → 解析明确清单 → 获取来源版本 → 对齐摘要与原文 → 呈现只读结果。返回保留原阶段、筛选及阅读位置；切换项目清空旧项目上下文。

## 更新与异常

打开或手动刷新时核验来源指纹；发现变化提示更新，重新取得一致内容后整体切换。来源读取期间发生变化则重试一次，仍变化显示暂不可用，不拼接混合版本。旧摘要标记过期并允许读取当前原文，不继续作为当前流转要求展示。

无权限：拒绝内容与检索结果；缺文件：显示缺失；无映射：显示未配置；无历史正文：仅显示日志并说明不可取得；无生效依据：显示待核实。单项失败不阻断其他条目。

## 范围差异

无父需求。本需求只查阅规范，不扩展 REQ-0027 的命令执行、不取得 REQ-0050 的规则修改或生效授权。验收返修分支只是说明，阅读不触发返修。

## 数据与权限

项目授权是唯一读取边界，界面隐藏不是权限控制。项目切换、直接链接、缓存读取、历史版本和搜索均重新受权控；无权结果不能暴露标题、路径或片段。观测使用安全标识、结果与耗时，不保存文档或搜索原文。
