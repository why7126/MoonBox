# 九阶段流转规范查阅与研发规范中心用户故事

| 故事 | 用户需求 | 验收映射 |
|---|---|---|
| US-001 | 产品负责人在空列或有卡片阶段查阅下一步条件，区分需求与缺陷要求。 | AC-001、002 |
| US-002 | 研发成员从摘要定位同版本原文，返回后保留阶段上下文。 | AC-003、004 |
| US-003 | 新成员通过分类、关键词和阶段筛选找到当前项目完整规范。 | AC-005 |
| US-004 | 团队成员通过日志了解变化原因，并查看可取得的历史版本。 | AC-006、007 |
| US-005 | 只读成员安全阅读授权内容，看到清晰的缺失或过期提示。 | AC-008、009、010 |
| US-006 | 管理者确认查阅不触发研发操作，观测不泄露正文。 | AC-011、012 |
