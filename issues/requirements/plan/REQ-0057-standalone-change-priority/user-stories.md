# 独立 Change 优先级用户故事

| 故事 | 用户目标 | 对应要求与验收 |
|---|---|---|
| US-001 | 产品经理查看独立交付的轻重缓急，能区分负责人未分配与优先级未设置 | FR-001/003；AC-001/002 |
| US-002 | 有权限的研发负责人设置或调整优先级，保存成功才更新标签 | FR-002；AC-003/004 |
| US-003 | 协作者遇到版本冲突或保存失败时保留选择，重载后重试，不覆盖他人 | FR-002；AC-005/006 |
| US-004 | 产品经理用分级筛选找到独立 Change，不改变 REQ/BUG 的原分级 | FR-003/004；AC-007/008 |
| US-005 | 只读用户或查看归档记录时能理解分级但无法越权修改 | FR-002/004；AC-009/010 |
| US-006 | 运维人员可追溯一次分级修改，遥测故障不影响保存 | FR-005；AC-011/012 |

所有故事均为待实现要求，不表示已通过产品验收。父需求 REQ-0056 负责交付卡模型，本子需求仅负责无来源 Issue 的 Change 分级。
