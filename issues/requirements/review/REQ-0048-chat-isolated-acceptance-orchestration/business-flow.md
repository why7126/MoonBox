# Chat 隔离验收环境编排业务流程

## 正常流程

```text
原会话授权操作 → 能力预检 → 固定输入快照 → 排队/资源预留
 → 创建租约/网络/数据库 → 健康检查 → 迁移/合成样本
 → 构建版本化应用 → 启动及版本核验 → 短期身份
 → AC依赖队列（命令/真实数据库/浏览器） → 发布证据
 → 回传原操作 → 当前验收就绪判定 → 撤销身份/资源清理 → 回读已释放
```

每一步持久化开始、结果、资源归属和版本；资源创建前写意图，创建后记录实际身份。重启查询实际资源与意图匹配，不能补空日志冒充完成。清理阶段与AC结果分别保存。

## 状态与恢复

| 状态/事件 | 守卫条件 | 后续 |
|---|---|---|
| queued | 身份有效、输入固定 | 预留预算后preparing；30分钟超时不建资源 |
| preparing | 模板/摘要/架构和配额有效 | 分步建环境；失败记录已创建资源并清理 |
| ready | 服务健康、部署版本一致、身份有效 | 运行有依赖满足的AC |
| running | 租约有效、执行epoch匹配 | 每AC保留证据；局部失败不停止独立项 |
| blocked | 缺能力、权限/绑定变化或输入冲突 | 保留检查点；仍占资源则受原租约及总时限约束，不无限等待 |
| result_received | 操作/任务/指纹和结果版本一致 | 存活轮次一次投递；已终止轮次按PRD续接守卫处理 |
| cancelling/timeout | 用户停止或阶段超时 | 停止新任务、撤销身份、终止所属执行、清理 |
| releasing | 有所有权记录且无有效继续执行者 | 幂等清理，确认不存在后released |
| cleanup_failed | 清理重试预算耗尽 | 告警及处理入口，保留证据，不宣称释放 |

worker租约回收与旧worker写入以epoch围栏互斥；用户停止优先于晚到成功回调。成功AC仍可保留为历史事实，不能引起自动继续写入。

## 数据库初始化与副作用

迁移、种子使用模板内固定入口和版本。事务结果未知时先回读；无法证明完成或未执行时重建私有实例，不在旧库盲重跑。数据库销毁后相同快照的复验使用新环境attempt；先前登录态和数据现场不可复用。应用本身处理测试输入的副作用限定在隔离资源内。

## 增量复验

代码/锁文件/镜像/迁移/种子/计划变化 → 生成新输入摘要 → 根据AC依赖标记过期 → 保留仍有效证据 → 只调度过期或失败项。依赖映射不完整时扩大到该环境受影响AC，不凭猜测复用；不改写原证据哈希。

## 与父需求差异及跨系统交接

REQ-0044在授权目标上执行浏览器任务；本需求新增“自动创建本轮目标及数据库、身份、环境租约”的前后流程。BUG-0045提供预检/任务调用/结果回传接口，本需求使用同一接口关联环境，不复制另一套任务状态。REQ-0047原则用于原操作恢复；BUG-0046负责人工回答，正常路径不依赖人工问答。

## 观测与证明

按PRD第9节关联操作、尝试、环境、任务、AC与请求/Task Trace；区分首次成功、故障拒绝、恢复成功和清理成功。日志不记录密钥、完整页面或连接串。端到端产品轮次、命令证据和视觉证据分别签认。
