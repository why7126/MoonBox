# Chat 隔离验收环境编排与原操作续接

## 1. 背景与问题

用户在产品 Chat 执行开发命令时，期望在原会话完成实现、测试及验收。当前已有 REQ-0044 的跨空间验证任务、浏览器 runner、依赖制品和证据服务，但这些基础能力不能自动提供本轮代码对应的测试应用、独立 MySQL 和短期测试身份。仅提供目标 URL 或宿主已有数据库不足以证明当前变更通过验收。

BUG-0045 已批准修复已有验证能力部署接入、测试依赖供应、预检和结果回传；本需求在其契约之上增加任务专属环境的准备、执行、恢复和回收。现有代码与运行观察属于问题依据，不代表本需求能力已经实现。P1 沿用 capture，理由为自主开发验收闭环的基础能力，已通过本次需求评审确认。

## 2. 目标用户与成功条件

- 研发成员：在一次已授权的 Chat 操作中完成可自动化验收，无需日常切换桌面或手动提供数据库连接串。
- Agent：取得可解释的能力预检、环境任务和逐 AC 证据，修复后仅复验受影响项。
- 项目维护者：配置受控项目模板、版本矩阵与预算，诊断阻塞并确认资源隔离和回收。

成功条件是原操作下形成“当前代码快照 → 环境就绪 → 实测结果 → 有效证据 → 继续执行 → 临时资源回收”的完整链路。环境 ready、测试进程退出和 Change 验收通过是不同事实；归档仍遵守既有独立授权与门禁。

## 3. 首期范围与非目标

### 3.1 纳入范围

以 MoonBox 当前 Web、Python 后端、SQLite/MySQL 为首个受控模板，覆盖独立 MySQL、本轮代码测试应用、短期测试身份、原操作检查点与恢复、资源租约和清理。复用现有 Chromium/Firefox、验证任务、依赖制品、证据鉴权与存储能力。测试数据库类型按 AC 选择，不要求所有任务同时启动双库。

### 3.2 不纳入范围

不提供任意镜像或任意 Compose 托管、不执行生产部署或真实 DB restore、不复制真实业务数据或个人登录状态、不授予模型 Docker socket 或任意网络权限。不重建浏览器系统、普通聊天问答组件或独立环境管理门户。不自动扩展模型调用预算、自动归档或承诺所有外部系统可无人参与验收。

SQLite 通过不能替代真实 MySQL；测试替身通过不能替代明确要求真实外部服务的 AC。外部资源尚未授权、凭据不可用或模板不支持时返回具体阻塞，其他独立项继续。

## 5. 自主验收流程

1. 用户从已授权的原对象 Chat 发起开发或验收；平台从可信项目绑定和当前 Change 的验收计划提取能力需求。
2. 验证身份、权限、输入完整性、模板版本、配额及执行占用，返回 ready、preparable 或 unavailable 的分项结果。
3. 创建稳定验收操作与环境租约，固定代码快照和计划；供应依赖、数据库、迁移、合成样本、测试应用及短期身份。
4. 健康检查和部署版本核对通过后调度可执行 AC；数据库、命令和浏览器使用明确的依赖关系，独立项不受无关失败阻塞。
5. 保存逐 AC 命令、真实数据库、真实浏览器及产品轮次证据，回传原操作；失败后修复产生新输入指纹，只复验受影响项。
6. 当前必要 AC 全部有效通过且证据可读时，形成验收就绪结论；由既有流程执行后续同步，不自动扩大归档授权。
7. 释放短期身份和临时环境；保留受权限保护的证据。清理失败单独记录，不能把资源泄漏标成已回收，也不能抹除已取得的测试结果。

## 6. 功能要求

### FR-001 能力声明与受控预检

以服务端可信绑定、项目模板及已授权验收计划决定数据库、应用服务、浏览器、测试身份和外部依赖。请求端不能自由指定宿主路径、任意镜像、网络或生产连接串。平台按项报告可用、可准备、不可用及稳定原因，并列出受影响 AC。准备失败不得仅要求用户换桌面；已有能力恢复后可从持久检查点继续。

### FR-002 当前输入身份与一致快照

绑定空间、项目、原会话、原业务操作、来源轮次、Change、验收任务及 AC。快照包含该任务授权范围内的已提交和未提交代码；显式排除真实 env、凭据、运行数据库、日志及无关工作区。记录源版本、实际内容摘要、依赖锁、模板、运行镜像、迁移、合成样本和验收计划指纹。

快照捕获期间发生写入时应重新捕获或报告输入变化，不能产生不一致版本。不得将共享工作区其他任务的修改默认为本任务成果；归属无法确认时阻塞快照。重试同一幂等键和相同输入返回原任务，同键不同输入返回冲突。复验的新输入形成新尝试并保留证据历史。

### FR-003 依赖与构建制品

复用 BUG-0045 提供的 Python/Node 测试环境和 REQ-0044 的已校验制品。按锁文件、平台架构、运行时及镜像身份复用，拒绝 Darwin 原生模块用于 Linux。准备网络与执行网络分离，依赖安装和构建只在受控执行环境中进行；项目脚本视为待执行代码而非平台控制指令，不得接触控制器凭据或 Docker socket。缺制品、无批准源、构建失败分别诊断，不临时解除隔离。

### FR-004 独立数据库供应

每个验收环境使用任务专属 MySQL 容器、网络和临时卷；SQLite 使用任务私有文件。MySQL 基线参考仓库当前 8.4 配置，实际镜像摘要、补丁版本、字符集、排序规则、时区及受支持架构由版本化模板固定，运行时记录实际值，不追随浮动标签。

平台生成短期凭据，分别限定迁移、应用和测试所需权限；不向模型返回凭据。先健康检查，再运行正式迁移与版本化合成样本初始化，之后开放测试。迁移/初始化需有执行记录；中断后可验证已完成事实，无法确认时隔离或重建任务环境，不重复执行未知副作用。不得连接真实业务库或静默以 SQLite 替代 MySQL。

### FR-005 测试应用编排与版本证明

从 FR-002 快照构建受控 Web/Python 应用及声明的必要依赖，按数据库、迁移、后端、前端、登录准备顺序启动并检查健康。平台分配私有服务地址供浏览器和测试进程使用，默认不开放宿主端口。应用端可核对代码/构建身份；目标健康但版本不符时阻塞当前 AC。

并发任务使用独立可写目录、服务命名和网络边界，只共享已校验只读制品。外部服务使用声明的测试替身或获批准端点；证据标明其类别，真实模型调用仍受原授权与预算约束。

### FR-006 短期测试身份与登录态

平台在隔离应用生成必要角色的合成身份；角色范围由 AC 和模板约束，不自动授予平台管理员。登录材料只交付对应测试进程，记录不含秘密的身份引用、权限类别、有效期与撤销结果。角色隔离测试可使用多身份但不能跨任务共享会话状态。身份期限不能超出环境有效租约；到期、取消、撤权或回收时撤销，证据中的截图、请求和 Console 均需避免泄露登录材料。

### FR-007 验证调度与逐项证据

复用既有验证任务执行命令、数据库检查、Chromium/Firefox 指定视口的浏览器流程。AC 依赖图决定可执行队列；失败项不阻塞无关任务。每项结果绑定输入指纹、模板、环境、实际部署版本、执行步骤、退出结果、断言和证据引用，分别标注命令、合成、真实数据库、真实浏览器与产品轮次证据。

现有 runner 能力不足时给出明确不支持项；需要增加动作、网络断言或样式采样时通过受控契约扩展，不接受任意宿主脚本。测试是否通过以实际断言和观察为准，截图生成、工具退出、制品存在不自动等于 AC 通过。对证据做权限校验、完整性校验和脱敏；证据无法安全发布时该项不得宣称可复核通过。

### FR-008 原操作续接与执行围栏

存活模型轮次收到验证工具结果后继续；页面刷新仅恢复显示，不重跑任务。worker 重启后先确认原执行占用、任务租约、当前权限、项目绑定、输入及结果版本，再续接允许步骤。旧 worker 或迟到回调不能覆盖较新的状态。

底层轮次已终止时保留其终态，在同一业务操作下建立关联续接尝试；不能伪造原轮次仍在运行或将失败改写为成功。自动续接仅在原授权覆盖、恢复能力明确且预算可用时执行；能力不支持时提供具体恢复入口。用户主动停止后不自动恢复模型或继续未提交的业务写入，但允许安全回读、撤销测试身份及资源清理。

### FR-009 状态、检查点与幂等

分别保存业务操作、执行尝试、环境、AC 与回收状态，不用单一“执行中”代表全部事实。环境正常阶段为排队、准备、就绪、验收中、释放中、已释放；阻塞、失败、取消、超时及清理待重试保存原因和发生阶段。

创建数据库、迁移、初始化、启动应用、创建身份、调度 AC、发布证据及回收均有持久检查点和资源归属。控制器失败重启后通过事实回读判定已完成步骤，不宣称跨 Docker/数据库/文件天然恰好一次。重复请求、重复结果与取消竞争均需版本或等价围栏保护。

### FR-010 租约、预算与资源回收

任务开始前验证环境并发、CPU、内存、磁盘、准备/运行超时、重试次数与有效租约配置；配置须为有限值，未知或不足时拒绝供应对应资源。预算覆盖数据库、应用及浏览器总量，不沿用浏览器单容器预算冒充整套容量。续租只允许存活且仍获授权的任务，并有总时限；进程重启不重置预算。

正常完成、取消、超时、权限撤销及租约到期均进入可追踪清理。清理只作用于平台记录且归属匹配的容器、卷、身份和网络；无归属资源不得按名称猜测删除。活跃任务不得被孤儿扫描回收。清理失败保留资源清单摘要、原因、重试计数和后续处理；已释放需有实际回读依据。

### FR-011 证据保留与增量复验

临时环境释放不删除尚在保留期内的有效证据；原始证据访问期限与 Change 长期脱敏证据归属分开。现有浏览器证据七日访问策略作为兼容基线，不在本需求中默默扩大。需要长期验收引用时按现有文档治理转存可复核脱敏材料，不能留下到期即失效的唯一证据链接。

相同输入仅复用有当前有效依据的结果；代码、计划、镜像、依赖、迁移或样本变化按影响使相关 AC 过期。环境已释放后重建同输入环境可复验，但不得把先前数据库现场或登录态视为仍存在。验收 ready 要求所有必要项有效通过、证据可读取、无未解决验收阻塞；回收完成作为独立交付事实报告。

## 7. 产品入口与 UI 约束

沿用原 Chat 会话、执行详情和证据入口，不新增环境管理门户。显示准备环境、验收中、局部阻塞、等待恢复和清理异常；明确哪些 AC 已通过、哪些依赖尚未就绪。查询状态不触发重跑；取消、重新核验和继续操作有明确且不同的效果。

正常路径不要求用户逐次填数据库地址或切换桌面。确需人工决策时复用 BUG-0046 的可操作通道；不得仅输出文字选项却禁用唯一回答入口。实施若修改可见 UI，req-complete 与 Change 阶段补充现有组件映射、1440px/窄屏及关键状态视觉验收，不在本轮生成 prototype。

## 8. 验收口径与完成边界

| 编号 | 验证目标 | 必要结果与证据 |
|---|---|---|
| AC-001 | 自主完整链路 | 一次已授权产品操作完成快照、环境供应、真实 MySQL、当前版本浏览器检查、证据回传和资源释放；无需桌面续验 |
| AC-002 | 输入与版本 | 包含授权未提交修改；并发写入/无关修改可识别；目标版本不符、指纹变化拒绝复用 |
| AC-003 | 数据库真实隔离 | SQLite 与真实 MySQL 各自执行声明检查；迁移、初始化、字符集/排序规则有实际记录；跨任务不串数据 |
| AC-004 | 身份与权限 | 不同角色测试、跨空间拒绝、过期及撤销真实生效；模型和证据无凭据 |
| AC-005 | 局部失败 | 数据库、构建、浏览器或外部依赖失败只阻塞相关 AC，原因稳定且可恢复 |
| AC-006 | 原操作续接 | 页面刷新、worker 重启、重复提交和迟到回调不重复副作用；存活/终止轮次行为分别取证 |
| AC-007 | 停止与并发 | 主动停止不自动恢复模型；取消竞争、撤权、绑定变化、旧 worker 写入由围栏阻断 |
| AC-008 | 生命周期 | 正常、超时、失败、崩溃及清理重试均能核对资源归属；活跃/其他任务资源不被误删 |
| AC-009 | 证据有效性 | 命令/数据库/浏览器/产品轮次分层，证据授权、脱敏、过期、转存与输入变更复验可验证 |
| AC-010 | 配额与制品 | 目标架构依赖真实可运行；并发、磁盘、超时和重试上限生效；离线缺制品准确阻塞 |
| AC-011 | 基线兼容 | 原 REQ-0044 预配置目标验证与 BUG-0045 调用仍可独立工作，不强制所有任务启动 MySQL |
| AC-012 | 观测与 UI | 端到端操作/任务/环境关联可查；状态和错误与后端事实一致，关键视口有真实证据 |

BUG-0055 可作为获授权的样本，但使用独立合成数据和新测试操作；历史记录只读，不重放已归档或原现场写入命令。本文定义验收要求，不记录已执行结果；详细步骤与样本矩阵在 req-complete 补齐。

### 11.4 短期身份与外部依赖

身份生命周期：申请→创建合成账户→授予AC所需角色→发放短期登录态→受控刷新→撤销→删除合成账户或随库释放。迁移身份、应用数据库身份、浏览器业务身份分别授权；默认测试成员，管理员AC需模板显式批准。刷新保留审计身份但使旧令牌按应用策略失效；撤权/取消后60秒内撤销受控访问，隔离环境不可达时先断开其任务网络并记录待确认，不把请求已发送写为撤销成功。

共享浏览器制品不共享 browser context、Cookie、存储状态或账号；测试身份使用加密/私有临时介质，模型只见引用。真实外部模型成本单独核对原预算，未授权时阻塞相关AC。截图和网络证据保存前脱敏并检查，不在PRD或日志放连接串。

### 11.5 原操作续接与幂等契约

业务operation_id稳定；每次执行attempt_id和environment_id独立，关联source_turn_id、verification_task_id及AC。请求幂等键作用域为操作者＋空间＋项目＋原操作＋输入指纹；同键同输入回读原任务，同键异输入冲突。重试次数、租约epoch、状态版本和执行占用持久化；恢复采用围栏防止旧worker继续提交，租约失效先停止旧工作再接管。

| 现场 | 平台动作 | 禁止行为 |
|---|---|---|
| 轮次存活、结果返回 | 验证身份/输入/epoch后一次性投递工具结果，重复回调确认原记录 | 重跑已完成AC |
| 页面刷新/断线 | 读取原任务与检查点 | 查询触发重建环境 |
| worker重启且原执行仍存活 | 回连或观察原执行，持久恢复；能力不支持则阻塞 | 启动并发模型冒充续接 |
| 轮次失败/超时且已确认终止 | 原授权、预算、源码与权限有效时建立最多1次自动关联续接尝试 | 覆盖原终态、无限新轮次 |
| 用户主动停止 | 取消待调度写入和模型续接，执行安全回读/身份撤销/清理 | 自动再调用模型 |
| 输入变化 | 已完成证据按依赖失效，新快照创建关联复验尝试 | 旧指纹结果算新版本通过 |
| 撤权/绑定变化/租约冲突 | 阻塞，隔离和清理所属资源，保留证据访问权限校验 | 沿用旧权限续接 |
| 清理失败 | 保留任务成果及清理待处理事实，有限重试 | 报告环境已释放或删除他人资源 |

同一AC初始化失败时先回读迁移/种子版本及事务结果；可证明未执行才重试，可证明完成则跳过，无法证明则废弃该隔离库并在总预算内创建新attempt。副作用不明确的测试步骤不得自动重放。需要人工选择时走BUG-0046；接口不可用时显示明确阻塞和恢复入口，不靠聊天正文猜答案。
