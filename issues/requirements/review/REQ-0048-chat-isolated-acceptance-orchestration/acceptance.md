# Chat 隔离验收环境编排逐项验收标准

## 前提、样本与证据约定

所有项目为待执行计划，不因文档或脚本存在勾选。使用隔离合成数据，禁止对真实业务库注入故障。模板及预算以requirement.md第11节为唯一数值基线。MySQL 8.4实际补丁与摘要在模板发布前锁定；目标架构未实测不得宣称支持。文档Ready不等于运行Ready。

证据在未来Change的evidence/acceptance/按AC归属：manifest保存当前输入/环境/版本及断言；命令结果、真实数据库、真实浏览器、产品轮次与清理事实分类。不得持久化凭据、未脱敏日志、完整Prompt或真实用户数据。首次正常、失败拒绝、恢复、重启回读使用独立样本，不能互相代替。

## 逐项验收清单

### AC-001 完整自主验收

- [ ] AC-001 验证通过并具备当前有效证据。

映射：FR-001—011。

前提/样本：两个授权空间各准备合成项目绑定；一个首次正常样本，BUG-0055仅作授权新样本参考。

操作：从产品Chat发起操作，自动准备MySQL和本轮应用，执行命令及双浏览器，再回读资源。

期望：无桌面切换、无人工连接串；逐AC证据绑定当前快照；原操作接收结果；资源实际释放。

证据：真实产品轮次＋任务链＋MySQL执行＋浏览器＋回收清单。

### AC-002 输入快照和版本

- [ ] AC-002 验证通过并具备当前有效证据。

映射：FR-002/005。

前提/样本：授权未提交改动、他人无关改动、并发写入、旧部署各一例。

操作：捕获快照；同幂等键重复/改输入；部署旧版本；改变锁文件并复验。

期望：只含授权内容；未知归属或捕获竞争拒绝；同键异输入冲突；旧部署不计通过；相关AC过期。

证据：快照清单摘要、冲突响应、部署身份及AC失效记录。

### AC-003 数据库矩阵与初始化

- [ ] AC-003 验证通过并具备当前有效证据。

映射：FR-004。

前提/样本：PRD本地arm64必测组合；amd64启用前同组；真实MySQL8.4、非支持版本、迁移中断。

操作：执行迁移/种子、时间/JSON/排序/分页与事务测试；中断初始化后恢复；双任务各写不同合成标记。

期望：实际版本/字符集/排序/时区匹配模板；不串数据；未知副作用重建私有库；不回退SQLite；不支持组合拒绝。

证据：真实实例元数据、SQL断言摘要、迁移记录、隔离及重建事实。

### AC-004 短期身份与隔离

- [ ] AC-004 验证通过并具备当前有效证据。

映射：FR-006。

前提/样本：成员/只读角色及模板批准的管理员AC；两个空间和两个任务。

操作：登录并执行允许/禁止动作；等待或受控时钟验证15分钟过期；撤权/取消并检查60秒撤销；尝试跨任务证据读取。

期望：权限最小、越权403/等价拒绝；旧会话不可继续；不可达时网络隔离且撤销状态待确认；无Cookie串用或凭据泄露。

证据：角色矩阵、真实请求状态、过期/撤销计时和脱敏扫描。

### AC-005 局部故障与恢复

- [ ] AC-005 验证通过并具备当前有效证据。

映射：FR-001/007。

前提/样本：MySQL未就绪、构建失败、浏览器缺二进制、外部端点无授权各一例。

操作：发起含独立静态AC和数据库/浏览器AC的计划；注入故障，再恢复能力。

期望：只阻塞依赖项；独立检查执行；稳定原因明确；恢复后续接检查点，不把preparable标为passed。

证据：依赖队列、错误类别、前后检查点及执行次数。

### AC-006 原操作续接

- [ ] AC-006 验证通过并具备当前有效证据。

映射：FR-008/009。

前提/样本：首次正常、页面断线、worker重启、结果响应丢失、轮次已终止分别独立样本。

操作：刷新/重启；回放同请求和同回调；已终止但原授权有效时续接。

期望：operation稳定、attempt可追溯；迁移/种子/结果投递无重复副作用；原终态不改写；自动关联模型续接最多1次且预算不重置。

证据：真实轮次与关联attempt、资源数量、幂等记录、状态版本。

### AC-007 停止、撤权与竞争

- [ ] AC-007 验证通过并具备当前有效证据。

映射：FR-008/009。

前提/样本：用户停止与结果同时到达；旧worker持有旧epoch；绑定变化。

操作：取消并投递晚到成功；旧worker提交；更换绑定或撤权后恢复。

期望：停止后无新模型/业务写入；旧epoch拒绝；恢复重新鉴权；只允许安全回读及所属资源清理。

证据：事件顺序、执行器终止确认、拒绝码及无额外模型调用证据。

### AC-008 租约及资源回收

- [ ] AC-008 验证通过并具备当前有效证据。

映射：FR-010。

前提/样本：正常/失败/取消/超时/worker崩溃/清理失败；另有活跃及其他任务资源。

操作：停止心跳超过5分钟，60秒扫描；在清理前后重启；注入删除失败；重复清理。

期望：确认租约与围栏后回收所属资源；活跃资源不删；30秒/120秒重试后仍失败为cleanup_failed；释放有实际回读。

证据：资源归属、租约时间、删除/回读事实、重试与告警摘要。

### AC-009 证据与增量复验

- [ ] AC-009 验证通过并具备当前有效证据。

映射：FR-007/011。

前提/样本：当前/旧指纹、有效/缺失/过期证据、合成/真实类别各一例。

操作：修改代码/镜像/样本，查询证据并调度复验；模拟七日访问过期；转存长期脱敏材料。

期望：证据授权有效；不泄密；旧指纹和缺证据不通过；只复验依赖失效项；环境释放不误删有效证据；长期引用可解析。

证据：证据manifest、访问拒绝、脱敏检查、复验队列及转存校验。

### AC-010 模板、资源与制品

- [ ] AC-010 验证通过并具备当前有效证据。

映射：FR-001/003/010。

前提/样本：错误schema、未固定镜像、架构不匹配、离线缺缓存、配额不足、超过并发。

操作：发布模板探针并故障注入；启动第3环境及同空间第2环境；压测限额与超时/重试。

期望：无批准摘要/架构不运行；制品加载真实通过；预算硬限制可观测；超并发排队；超时不重置；清理不无限重试。

证据：镜像/架构探针、cgroup/磁盘限制、排队与阶段计时证据。

### AC-011 已有基线兼容

- [ ] AC-011 验证通过并具备当前有效证据。
