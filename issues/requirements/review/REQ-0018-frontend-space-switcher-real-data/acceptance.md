# 验收标准

## 功能 AC

- [ ] AC-001 前台空间切换列表仅展示当前登录用户已加入的真实后台空间，包含用户作为负责人或成员加入的空间。
- [ ] AC-002 未加入空间、无权限空间和回收中空间不得出现在前台切换列表中。
- [ ] AC-003 切换列表每个空间项至少展示空间名称、当前用户角色、成员数、状态和当前项勾选态。
- [ ] AC-004 冻结空间可展示并允许切换查看，但必须显示“已冻结”或“只读”标记，且当前空间上下文保留只读语义。
- [ ] AC-005 正常空间可切换并作为默认可用空间；冻结空间不得被误展示为正常可写空间。
- [ ] AC-006 本地最近选择必须经过接口返回的可访问空间列表校验；失效时清理或覆盖本地缓存。
- [ ] AC-007 最近选择失效且仍有可访问空间时，系统回退到接口默认空间或首个可访问空间。
- [ ] AC-008 用户没有任何已加入空间时，浮层展示明确空态，并保留“创建或加入空间”入口；在 REQ-0019 完成前不得伪造可切换空间。
- [ ] AC-009 用户切换空间后，侧边栏用户区空间名称、浮层当前项、需求中心当前空间上下文、统计、筛选结果和看板数据保持一致。
- [ ] AC-010 若当前阶段治理对象仍为项目级聚合数据，当前空间摘要和权限态必须来自真实空间；若治理对象具备空间归属字段，则看板数据必须按当前空间过滤或由接口返回空间范围内数据。

## API / 安全 AC

- [ ] AC-011 系统提供前台安全接口或需求中心 BFF 聚合能力返回空间切换数据，普通前台用户不得直接使用后台管理空间列表接口读取全量空间。
- [ ] AC-012 前台空间响应只返回切换所需字段，不返回后台配额详情、审计记录、删除原因、负责人内部 ID 或高风险操作集合。
- [ ] AC-013 接口必须复用当前登录态和权限校验；登录失效、权限不足和空间不可访问时返回统一错误结构。
- [ ] AC-014 冻结空间的写入限制必须由服务端校验兜底，不得仅依赖前端隐藏按钮。
- [ ] AC-015 错误态不得向浏览器展示本机绝对路径、数据库错误详情、内部堆栈、密钥、token、`.env` 内容或后台审计原文。

## UI AC

- [ ] AC-016 空间切换继续使用 REQ-0012 的用户菜单右侧轻量二级浮层，不新增全屏遮罩、复杂搜索或组织分组。
- [ ] AC-017 空间项保持紧凑列表行，空间名称为主信息，角色、成员数和冻结标记为辅助信息。
- [ ] AC-018 当前空间继续使用勾选图标表达，不使用大面积高亮或重色块。
- [ ] AC-019 冻结/只读标记在深色和浅色主题下均清晰可读，且不得与当前空间勾选图标冲突。
- [ ] AC-020 空态、错误态和加载态出现在浮层自然位置，不撑开一级用户菜单，不遮挡退出登录、主题切换或其他菜单项。
- [ ] AC-021 空间名称、角色文案和成员数过长时必须截断或换行，不得挤压勾选图标、状态标记或浮层边界。
- [ ] AC-022 点击外部、Escape、选择空间、侧边栏收起时，空间浮层关闭行为与 REQ-0012 既有体验一致。

## 测试与文档 AC

- [ ] AC-023 后端测试覆盖已加入空间过滤、未加入空间不可见、回收中空间隐藏、冻结空间返回只读状态和普通前台用户不能读取后台全量空间。
- [ ] AC-024 前端测试覆盖真实空间列表渲染、当前项勾选、冻结空间标记、最近选择失效回退、无空间空态、接口失败和切换后上下文刷新。
- [ ] AC-025 如新增或修改 API，必须同步 API 文档、OpenAPI 来源和客户端调用约束。
- [ ] AC-026 如涉及空间权限或冻结状态边界，必须同步安全相关测试或规则说明。

- [ ] AC-PROTOTYPE-002 `/req-opsx` 必须在 Change `design.md` 写入 UI Contract，明确前台空间浮层事实源优先级、BFF/API 边界、权限显示规则、Mock/API 边界和 REQ-0012 一致性参照。
- [ ] AC-PROTOTYPE-003 实现阶段必须先完成 UI Skeleton，并在 1440px 桌面视口验证用户菜单、切换空间二级浮层、正常/冻结/空态/错误态的首屏结构。
- [ ] AC-PROTOTYPE-004 实现阶段必须覆盖关键交互证据：打开用户菜单、打开空间浮层、选择正常空间、选择冻结空间、最近选择失效回退、点击外部关闭和 Escape 关闭。
- [ ] AC-PROTOTYPE-005 归档前必须确认 linked REQ、prototype context、最终 Change 设计、实现证据、computed style 结果和 Mock/API 边界一致。
