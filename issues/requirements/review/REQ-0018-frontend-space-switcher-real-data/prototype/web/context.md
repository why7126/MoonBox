# Prototype Context

## 页面清单

| 页面 / 区域 | 路由或入口 | 说明 |
|---|---|---|
| 前台需求中心 | `/catalog` 或现有前台需求中心入口 | 承载侧边栏、用户菜单、9 阶段看板和空间上下文 |
| 用户菜单 | 侧边栏底部用户触发器 | 展示个人资料、改密、进入后台、切换空间、设置空间、主题和退出登录 |
| 空间切换二级浮层 | 用户菜单中的“切换空间” | 展示当前用户已加入空间列表和创建/加入入口 |

## 关键区域

- 侧边栏底部用户触发器：展示当前用户和当前空间名称。
- 一级用户菜单：包含“切换空间”菜单项，并在既有触发方式下打开二级浮层。
- 二级空间浮层：展示真实已加入空间列表、当前项勾选、冻结/只读标记、空态和错误态。
- 创建或加入入口：固定在空间列表底部，流程归属 REQ-0019。

## 状态矩阵

| 状态 | 触发条件 | UI 表现 | 交互 |
|---|---|---|---|
| loading | 空间上下文请求中 | 浮层内展示轻量加载占位 | 不展示 Mock 空间 |
| active-space | 空间 `status=ACTIVE` | 名称 + 角色 + 成员数 | 可切换 |
| frozen-space | 空间 `status=FROZEN` | 名称 + 角色 + 成员数 + 只读/冻结标记 | 可切换查看 |
| current-space | 当前空间 ID 命中 | 右侧勾选图标 | 点击可保持当前或关闭浮层 |
| empty | 当前用户无已加入空间 | 空态文案 + 创建或加入入口 | 入口转交 REQ-0019 |
| error | 接口失败或权限不足 | 错误文案 + 重试/重新登录提示 | 可重试或引导登录 |
| stale-local | localStorage 空间失效 | 不闪现失效空间，直接回退 | 覆盖本地缓存 |

## 交互触发

- 打开：沿用 REQ-0012 用户菜单中的“切换空间”打开方式。
- 关闭：点击外部、Escape、选择空间、收起侧边栏或离开浮层延时关闭。
- 选择：点击空间项后更新当前空间、最近选择、用户区空间名和需求中心上下文。
- 回退：页面加载时校验本地最近选择；失效时自动回退，不弹阻断确认。

## 数据依赖

| 数据 | 来源 | 用途 |
|---|---|---|
| `workspace_id` / `id` | 前台安全接口或需求中心 BFF | 当前空间匹配与切换 |
| `name` | 后台空间事实源 | 空间名称展示 |
| `slug` / `code` | 后台空间唯一标识 | 本地缓存与调试可读标识 |
| `member_count` | 后台空间成员统计 | 辅助信息展示 |
| `role` | 当前用户在空间内角色 | 权限和文案展示 |
| `status` | 后台空间状态 | 正常/冻结/回收处理 |
| `readonly` | 后端映射 | 冻结空间当前上下文只读语义 |

## 响应式断点

- 1440px 桌面：重点验收侧边栏、一级用户菜单和右侧二级浮层对齐关系。
- 低视口桌面：空间列表过长时浮层内部滚动，底部创建或加入入口可访问。
- 窄屏或侧边栏收起：若既有前台需求中心不展示二级浮层，应关闭浮层或使用既有移动菜单策略，不新增全屏重构。

## 1440px 验收焦点

- 用户菜单和空间浮层层级清晰，不被看板列或页面滚动容器裁剪。
- 空间行文本、角色、成员数、冻结标记和勾选图标不重叠。
- 当前空间切换后侧边栏底部空间名称同步更新。
- 深色和浅色主题下状态标记、边框、背景和 hover/focus-visible 均可读。
- 空态、错误态和加载态不改变一级菜单布局，不造成明显 layout shift。

## Mock/API 边界

- 原型 HTML 使用静态示例数据，仅表达结构和状态，不代表真实 API 已完成。
- 实现阶段必须接入真实前台空间接口或需求中心 BFF，不能以静态 `workspaces` 作为生产运行时数据源。
- 创建或加入空间入口仅保留位置；流程由 REQ-0019 定义。
