# 用户故事

## US-001 打开创建空间入口

作为前台登录用户，我希望从空间切换上下文打开创建空间弹窗，以便提交新产品空间的创建申请。

验收要点：

- [x] 空间切换浮层提供“创建空间”入口。
- [x] 点击入口后打开标题为“创建空间”的弹窗。
- [x] 弹窗副标题说明每个空间对应一个产品，成员与数据相互隔离。
- [x] 弹窗副标题说明提交后进入平台管理员审批，审批通过后系统会创建空间并分配申请人为负责人。
- [x] 页面和弹窗不展示“加入空间”、空间搜索或申请加入入口。

## US-002 填写创建申请信息

作为创建者，我希望填写空间名称、标识和说明，以便平台管理员理解新空间对应的产品和协作目标。

验收要点：

- [x] 表单包含空间名称、空间标识和空间说明。
- [x] 空间名称和空间标识必填，并展示红色星号。
- [x] 空间说明可选，不展示必填星号。
- [x] 输入空间名称后自动生成空间标识。
- [x] 用户手动修改空间标识后，后续名称变化不得覆盖用户输入。

## US-003 配置资源配额与有效期

作为创建者，我希望设置成员、存储、AI Tokens 和有效期，以便审批人评估新空间资源边界。

验收要点：

- [x] 成员上限默认 20 人，仅接受 1-100000 的整数，与后台空间管理一致。
- [x] 存储空间默认 100GB，仅接受大于 0 的数值，单位与后台空间管理一致。
- [x] AI Tokens 默认 1000000，仅接受不小于 0 的整数，输入框不额外展示 `Tokens` 单位。
- [x] 有效期默认固定日期；到期时间默认本季度最后一天 23:59:59，必须晚于当前时间。
- [x] 到期时间放在 AI Tokens 下方，另起一行，并使用与后台空间管理一致的日期时间选择器。

## US-004 提交申请并等待审批

作为创建者，我希望提交后看到待审批反馈，以便知道空间需要平台管理员审批后才可使用。

验收要点：

- [x] 提交期间按钮禁用并显示“正在创建...”。
- [x] 提交成功后生成待审批创建空间申请。
- [x] 结果态展示空间名称、空间标识和待审批状态。
- [x] 审批通过前不展示进入空间入口。

## 非目标用户故事

- 不支持通过前台申请加入空间。
- 不支持精准搜索空间、公开空间目录、推荐空间、邀请码或邀请链接。
- 不支持我的申请列表、撤回申请、拒绝后重新提交或审批状态追踪。
