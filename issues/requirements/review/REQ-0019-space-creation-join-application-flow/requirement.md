# MoonBox 前台·创建空间流程 PRD

## 1. 背景与目标

MoonBox 以空间作为产品研发协作、权限隔离和资源治理的基础容器。首版前台入口只用于提交创建空间申请，不提供加入空间、邀请码、公开目录或空间搜索能力。

本版本目标：让前台登录用户可从空间切换上下文打开创建空间弹窗，填写基础信息、成员上限、存储空间、AI Tokens 和有效期，提交后进入平台管理员审批；审批通过后才创建正式空间并可使用。

## 2. 领域规则

1. 一个空间对应一个产品，审批通过创建空间时同步建立同名产品绑定。
2. 创建申请提交后进入平台管理员审批，审批通过前不得进入空间。
3. 审批通过后，申请人成为新空间负责人。
4. 空间名称在当前组织内唯一。
5. 空间标识为 2-32 位小写字母、数字或连字符，以小写字母开头。
6. 输入空间名称后自动生成空间标识；用户手动修改标识后，后续名称变化不得覆盖用户输入。
7. 成员上限默认 20 人，仅接受 1-100000 的整数，与后台空间管理一致。
8. 存储空间默认 100GB，仅接受大于 0 的数值，单位 GB 与后台空间管理一致。
9. AI Tokens 默认 1000000，仅接受不小于 0 的整数；输入框不额外展示 `Tokens` 单位。
10. 有效期默认固定日期；到期时间默认本季度最后一天 23:59:59，必须晚于当前时间。

## 3. 功能范围

### 3.1 创建入口

- 从空间切换浮层打开创建空间弹窗。
- 入口文案使用“创建空间”，不得展示“加入空间”入口、标签或搜索提示。
- 弹窗副标题必须说明提交后进入平台管理员审批，审批通过后系统会创建空间并分配申请人为负责人；表单上方不重复展示审批提示行。

### 3.2 创建表单

- 表单包含空间名称、空间标识、空间说明、成员上限、存储空间、AI Tokens、有效期。
- 除空间说明外，必填项必须展示红色星号。
- 不展示负责人卡；负责人由审批通过后的申请人自动承接。
- 到期时间在选择固定日期后展示于 AI Tokens 下方，另起一行，并使用与后台空间管理一致的日期时间选择器。

### 3.3 提交与反馈

- 提交前校验必填、空间标识格式、名称/标识唯一性、配额范围和有效期。
- 提交期间按钮禁用并显示“正在创建...”。
- 提交成功后生成待审批创建空间申请。
- 结果态展示空间名称、空间标识、待审批状态和“待平台管理员审批后才可使用”的说明。
- 审批通过前不展示进入空间入口。

## 4. 非目标

- 不提供加入空间、邀请码、邀请链接、公开空间目录、推荐空间或精准搜索空间。
- 不提供我的申请列表、撤回申请或拒绝后重新提交。
- 不在提交时直接创建正式空间。
- 不在创建弹窗中管理成员、角色、配额调整或负责人转让。
