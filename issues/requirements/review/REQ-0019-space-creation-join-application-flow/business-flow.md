# 业务流程

## 1. 总体链路

```text
前台空间切换入口
  -> 点击“创建空间”
  -> 打开创建空间弹窗
  -> 填写空间名称、空间标识、说明、成员上限、存储空间、AI Tokens 和有效期
  -> 提交创建申请
  -> 校验必填、标识格式、唯一性、配额范围和有效期
  -> 写入待审批空间申请
  -> 展示申请已提交结果态
  -> 等待平台管理员审批
  -> 审批通过后创建正式空间和同名产品绑定
  -> 申请人成为空间负责人
  -> 前台可访问空间列表刷新
```

## 2. 创建空间申请流程

```text
用户打开空间切换浮层
  -> 点击“创建空间”
  -> 系统展示创建空间申请表单
  -> 系统说明待平台管理员审批后才可使用
  -> 用户填写空间名称、空间标识、说明、配额和有效期
  -> 用户点击“创建空间”
  -> 提交期间按钮禁用并显示“正在创建...”
```

提交成功分支：

```text
后端创建待审批申请
  -> 前端展示“申请已提交”
  -> 展示申请状态“待审批”
  -> 提示待平台管理员审批后才可使用
  -> 不展示进入空间入口
```

审批通过分支：

```text
平台管理员审批通过
  -> 复用后台空间创建和产品绑定逻辑
  -> 设置申请人为负责人
  -> 写入通知和审计
  -> 新空间进入前台可访问空间列表
```

## 3. 字段与校验

| 字段 | 默认值 | 校验 |
|---|---:|---|
| 空间名称 | 空 | 必填，红色星号标识 |
| 空间标识 | 随名称自动生成 | 必填，2-32 位小写字母、数字或连字符，以小写字母开头 |
| 空间说明 | 空 | 可选 |
| 成员上限 | 20 人 | 必填，1-100000 的整数，与后台空间管理一致 |
| 存储空间 | 100GB | 必填，大于 0 的数值，与后台空间管理单位一致 |
| AI Tokens | 1000000 | 必填，不小于 0 的整数，输入框不额外展示 `Tokens` 单位 |
| 有效期 | 固定日期 | 必填，到期时间默认本季度最后一天 23:59:59 且必须晚于当前时间 |

## 4. 非目标链路

- 不提供加入空间申请。
- 不提供邀请码、邀请链接、公开空间目录或推荐空间。
- 不提供精准搜索空间。
- 不提供我的申请列表、撤回申请或拒绝后重新提交。
- 不在前台提交时直接创建正式空间。
