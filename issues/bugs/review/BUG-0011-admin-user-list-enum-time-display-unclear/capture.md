# 现象

用户管理列表中，不同用户状态的图标/视觉表达区分不明显；角色字段作为枚举值仅以纯文本显示；最近登录时间和创建时间缺少统一的 `yyyy-mm-dd hh:mm:ss` 展示策略；后端和前端类型已有 `updated_at` 字段，但列表未展示更新时间。

# 复现步骤

1. 进入管理后台用户管理页。
2. 查看用户列表中的角色、状态、最近登录时间和创建时间列。
3. 对比不同状态用户的状态标识、角色字段和时间字段可读性。

# 期望 vs 实际

期望：状态应通过不同图标/标签语义清晰区分；角色应以标签形式展示；时间字段应统一展示为 `yyyy-mm-dd hh:mm:ss`；列表应在创建时间后展示更新时间，方便判断数据最近变更。

实际：状态主要依赖同一胶囊样式与小圆点颜色区分，冻结和删除视觉语义接近；角色为纯文本；时间字段直接输出接口字符串；更新时间字段已存在但未渲染到列表。

# 初步证据

- 用户列表列定义包含角色、状态、最近登录时间和创建时间，但不包含更新时间。
- 后端列表查询已返回 `updated_at`，前端 `AdminUser` 类型也已声明 `updated_at`。
- 当前状态样式统一使用 `.admin-status`，仅通过伪元素圆点颜色做有限区分。
