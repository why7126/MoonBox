# 删除会话预检提示工作区状态不可确认且确认按钮不可用

## 现象

Chat 工作台删除会话弹窗提示“工作区或代码保留状态不可确认”，「确认删除」按钮呈禁用状态，用户无法完成删除。

## 复现步骤

1. 在 Chat 工作台的会话历史中选择一个已有会话，点击删除。
2. 等待删除预检完成，观察弹窗提示与「确认删除」按钮状态。
3. 对出现该提示的会话记录脱敏会话标识、环境及预检响应，以确认触发条件。

## 期望 vs 实际

- 期望：工作区及代码保留状态满足删除条件时可确认删除；不满足时给出可定位、可处理的具体原因。
- 实际：截图显示通用“工作区或代码保留状态不可确认”提示，确认按钮不可用；具体失败条件尚未确认。

## 影响范围与初判

- 已观察到一个删除会话弹窗受阻；其他会话、环境和工作区模式的影响范围待核查。
- 严重度暂定 `high`：核心会话管理操作被阻断，但尚无数据丢失证据。
- 只读代码显示后端删除预检在工作区绑定、目录、Git 状态或快照检查异常时可返回该提示；前端据 `allowed=false` 禁用按钮。本次截图不足以确认具体异常点。

## 附件与待补证

- 用户本次对话提供的删除会话弹窗截图；原图未复制到仓库。
- 待补：环境与脱敏会话标识、会话 `workspace_id`、仓库绑定的 `workspace_mode`、工作区目录可访问性，以及删除预检的状态码和脱敏响应摘要；不得提交凭证或真实本机目录。
