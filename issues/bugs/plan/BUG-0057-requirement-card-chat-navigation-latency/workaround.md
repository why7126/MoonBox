# 会话准备导航延迟临时规避说明

## 临时规避

暂无经验证可消除准备耗时且保留全部门禁的 workaround。

- 等待单次准备结束，避免重复点击或重复发起治理动作；这只减少额外请求，不保证加速当前请求。
- 若仅查看已有执行记录，可使用产品现有“查看执行”入口；它不能替代需要预检的治理写动作，不作为修复完成证据。
- 不手工跳过准备接口、不删除执行保护记录、不复用失效基准、不关闭权限/版本校验。

## 风险与恢复

失败时保留当前对象和错误提示，确认原请求状态后按正常产品入口重试；不要将超时感受等同于失败而重复提交。没有部署变更、数据库修改或回滚操作。根因与验收未闭环前，保持 enriching。
