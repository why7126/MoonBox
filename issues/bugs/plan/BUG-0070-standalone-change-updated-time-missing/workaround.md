# 独立 Change 卡片更新时间缺失临时处理办法

无已验证的界面修复性规避。用户可在 trace 文档查看 execution.started_at/completed_at，理解其为执行事实而非最后更新时间。不要手工填当前时刻、文件mtime或批量重写旧归档；按正式修复流程补齐可信字段。此规避仅辅助理解，不恢复卡片时间展示。

适用范围仅当前来源样本；不修改归档历史、不扩大权限，不承诺消除根因。
