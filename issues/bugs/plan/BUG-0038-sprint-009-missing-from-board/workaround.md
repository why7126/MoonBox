# 需求看板未显示已存在的 sprint-009 迭代临时规避

修复前，规划或归档操作先核对当前所选项目和其实际授权的 Sprint `sprint.yaml`。页面显示“已同步”只能说明一次页面读取完成，不能单独证明它与手头仓库一致。发现同一短 ID 对应不同标题、Sprint 总数与源文件不符时，暂停基于该看板的规划与归档操作，改用已授权治理文件核对完整 ID、状态和范围。

不通过手动改写 Sprint 文件、复制目录或补造卡片来掩盖数据源错位；该规避不能替代产品修复。
