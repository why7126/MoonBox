# 需求看板未显示已存在的 sprint-009 迭代修复验收标准

## 回归 AC

- [ ] AC-001：所选项目的授权治理源包含 `sprint-009` 且状态为 `planning` 时，Sprint 统计计入该迭代，筛选选项显示 `sprint-009` 和“规划中”；刷新后保持一致。
- [ ] AC-002：项目身份、治理数据来源标识、快照修订和同步状态可由用户安全辨认；不暴露容器或宿主绝对路径、凭证及其他项目数据。
- [ ] AC-003：统计、Sprint 选项、容量摘要和对象卡片使用同一已授权快照；同一短 ID 在不同数据源对应不同完整对象时，不将其混合展示或用于错误对象的动作。
- [ ] AC-004：绑定源不符、投影旧于源目录或快照冲突时，页面明确提示可核查原因，并提供重新连接或同步后的恢复路径；不得仅显示“已同步”并继续给出误导性的正常指标。
- [ ] AC-005：覆盖 `planning`、`in_progress`、已归档 Sprint、无活动 Sprint、同短 ID 异对象及跨项目无权访问场景；错误态不扩大读取或写入权限。
- [ ] AC-006：记录本地真实产品复验的项目标识、脱敏来源标识、快照修订、刷新时间、Sprint 指标与选项；自动化测试结果与真实页面观察分别留证。

## 验收记录要求

每项 AC 保留预期、实际、执行环境、版本及脱敏证据入口。当前所有 AC 待验证，不能以本文件生成或单次合成测试代替产品验收。
