# 独立变更迭代归属临时处理建议

## 临时处理
未纳入Sprint时不要尝试绕过禁用按钮。确认确需实施后，通过sprint-propose及正式范围工具纳入合适Sprint，完成容量校验与同步，再刷新卡片。仅希望保留提案时可以暂不排期。

冲突或失效时先核对Change trace.iteration与各Sprint changes列表，由有权限人员按治理流程纠正真实事实；不要删除记录、自动选择最新Sprint或伪造执行时间。本命令不执行排期或修复业务数据。

## 限制
临时处理不能纠正未排期提案所在列，也不替代本BUG的产品修复。
