# 现象

前台需求中心左侧底部用户菜单中已经展示“修改密码”菜单项，但点击该入口后没有打开修改密码弹窗，也没有触发任何密码修改请求。

# 复现步骤

1. 登录前台并进入需求中心页面。
2. 点击左侧底部用户头像或用户名，打开前台用户菜单。
3. 点击“修改密码”菜单项。

# 期望结果

- 点击“修改密码”后打开修改密码弹窗。
- 用户填写当前密码、新密码和确认新密码后，提交调用 `/api/v1/admin/auth/change-password`。
- 修改成功后清理前台会话与后台授权会话，并跳转到 `/login` 重新登录。

# 实际结果

- “修改密码”入口仅展示为菜单项。
- 点击入口后无弹窗、无表单、无接口请求，用户无法在前台完成自助修改密码。

# 影响范围

- 影响页面：前台需求中心用户菜单。
- 影响用户：已登录前台且需要自助修改密码的用户。
- 不影响范围：后台用户管理页的修改密码流程已有独立实现；后端 `/api/v1/admin/auth/change-password` 接口已存在。

# 严重等级说明

严重等级为 `medium`。该问题不阻断登录、浏览需求中心或后台管理能力，但暴露了不可用的账号安全入口，导致用户无法从前台完成已展示的自助改密操作。
