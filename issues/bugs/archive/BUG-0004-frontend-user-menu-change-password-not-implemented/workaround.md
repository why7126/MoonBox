# 临时规避

## 当前可用规避

若用户拥有后台访问权限，可临时进入后台用户菜单使用已实现的“修改密码”流程完成自助改密。

## 人工说明

在正式修复前，如需向测试或演示人员说明入口，可临时提示：

- 前台菜单中的“修改密码”当前为待修复入口，点击无效。
- 具备后台权限的账号可通过“进入后台”后再使用后台用户菜单完成改密。
- 没有后台访问权限的前台用户暂无产品内自助改密路径。

## 不建议的规避

- 不建议隐藏前台“修改密码”入口作为最终修复，因为该入口对应合理的账号安全能力。
- 不建议绕过当前密码校验或新建前台专用弱校验接口；应复用既有 `/api/v1/admin/auth/change-password` 安全规则。
- 不建议只弹 toast 提示“请进入后台修改密码”，这会保留前台自助能力缺口。

## 正式修复方向

复用或抽取后台修改密码弹窗与 API 客户端，在前台用户菜单点击“修改密码”时打开弹窗；提交成功后清理前台 session 与后台 admin session，并跳转 `/login`。
