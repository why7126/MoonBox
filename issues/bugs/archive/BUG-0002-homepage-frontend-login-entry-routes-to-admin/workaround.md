# 临时规避方案

## 可用规避

在正式修复前，可使用以下方式规避：

1. 前台用户直接访问 `http://localhost:18102/#login` 打开前台登录页。
2. 需要进入后台的管理员明确访问 `http://localhost:18102/admin`。
3. 已进入前台需求中心且具备后台权限的用户，可通过用户菜单中的「进入后台」入口访问管理后台。

## 不推荐规避

- 不建议将首页两个 CTA 解释为后台入口；这会继续混淆前台用户与后台管理员的进入路径。
- 不建议移除管理后台登录页或改变 `/admin` 路由含义；后台明确路径仍需保留。
- 不建议仅修改文案规避；按钮行为仍会把普通前台入口导向后台登录。

## 规避风险

- 直接访问 `/#login` 依赖用户知道隐藏 hash 路径，不适合作为长期产品入口。
- 管理员手动访问 `/admin` 不影响后台使用，但不能恢复首页前台 CTA 的转化路径。
- 若不修正测试期望，后续改动仍可能把前台入口重新接回后台路由。
