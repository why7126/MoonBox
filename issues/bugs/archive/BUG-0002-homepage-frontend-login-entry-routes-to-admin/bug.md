# 首页前台登录入口误跳后台登录页

## 现象

访问本地首页后，点击首页「打开第一个项目」或「开启 MoonBox」会跳转到 `/admin`，并展示管理后台登录页。

## 复现步骤

1. 访问 `http://localhost:18102`。
2. 点击首页「打开第一个项目」。
3. 返回首页后点击「开启 MoonBox」。
4. 观察两个入口的跳转路径和展示页面。

## 期望 vs 实际

| 项目 | 说明 |
|---|---|
| 期望 | 首页前台入口应打开前台登录页。后台登录页只在明确访问 `/admin`，或点击具备权限的进入后台入口时出现。 |
| 实际 | 首页两个前台入口都会跳转到 `/admin`，并展示管理后台登录页。 |

## 影响范围

- 影响本地 Web 首页前台入口体验。
- 普通前台用户从首页进入产品时会被误导到管理后台登录页。
- 管理后台入口边界被前台 CTA 混用，容易造成权限入口语义混淆。
- 现有首页测试已将跳转 `/admin` 写为期望，存在测试固化错误行为的风险。

## 严重等级说明

严重等级建议为 `high`。该问题阻断首页主 CTA 的前台登录路径，影响首次进入和产品转化关键链路；但后台明确路径 `/admin` 与具备权限的后台入口仍可用，未观察到数据破坏或系统整体不可用。
