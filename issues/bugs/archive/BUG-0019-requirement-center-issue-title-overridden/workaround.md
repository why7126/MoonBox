# 需求中心阶段业务标题来源与文档中文标题校验临时规避

## 临时核对

以卡片 ID 定位对象：采集池核对注册表 title；规划至迭代规划核对 Issue 主文档；开发及后续阶段先核对唯一 Change proposal，再按主文档、注册表、ID 回退。暂无自动恢复全部标题的产品内开关。

## 限制

只读核对不解决根因。不删除关联、不改变真实阶段、不重命名追溯文档来影响标题提取。历史标题补齐在明确范围下执行，不批量改写归档。
