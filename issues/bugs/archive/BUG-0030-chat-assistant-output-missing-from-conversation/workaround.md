# Chat 助手正文缺失临时查看方案

## 临时方案

在同一轮次打开“轨迹”阅读已保存的助手文字，并结合轮次状态判断内容是否完整。历史资料证明两轮轨迹可见文字，当前已登录历史会话仅做只读显示观察，原 T1/T2 已删除；此方案只缓解阅读困难，不恢复对话正文，也不证明归档完成。

## 操作步骤

1. 定位原会话及 T1/T2 对应时间的轮次，打开轨迹。
2. 只读查看助手输出事件；若文字不连续、仅有增量或无法判断终态，视为部分内容。
3. 对未知状态保留原提示；通过有权限的只读查询确认终态及实际治理文件状态后，再决定后续操作。

## 限制与退出条件

不重复发送归档命令，不手动改轮次终态，不向消息表插入拼接文字，不导出完整轨迹或聊天原文。当前修复已有隔离回归与合成 API 真浏览器验证，但尚未部署到所有环境。正式修复通过 acceptance.md 的行为验收后，才可退出临时查看流程。

## 验证状态

临时查看路径只用于旧部署或修复未覆盖的轮次；没有宣称原两轮已恢复，也没有执行业务写入或回滚操作。

## 修复期间适用边界

正文补存和读取投影已实现并完成合成 API 真浏览器验收，但尚未验证所有部署环境；上述临时查看方案仍适用于尚未部署修复的环境。原历史轮次已删除，无法依此恢复原实例。
