# 归档包装脚本同步成功漏识别临时处理方案

## 当前可用规避

已部署归档专用只读重核验。重新读取看板或会话时，对已完成原执行校验私有基线、规格合并、正式归档与 Workflow Sync check；通过后恢复正确阶段。证明不足仍保留“结果待核对”，不要直接修改门禁。

## 操作边界

- 不重复执行归档，不回滚已归档文档，不直接修改数据库门禁状态。
- 不因聊天回复“已完成”忽略同步证明，也不将包装脚本退出 0 当作全部业务验证。
- 如需恢复原对象，通过服务端对原执行重新验证并确认；摘要变化时先定位差异，不强制放行。
- 已归档对象保持只读；只读查看文档和证据可以继续。

## 退出条件

修复后原轮次的完成证明通过可信核验，门禁与看板收敛，并通过 acceptance.md 的恢复与幂等性验收。BUG-0048 原轮次已恢复为完成，原工具步骤与历史保持不变；独立首次归档验收见关联 Change 的证据包。
