# Chat 工作台非空白对话出现页面级滚动条及底部布局异常

## 现象

根据 [capture.md](capture.md) 中的用户截图反馈，Chat 工作台打开已有消息的非空白对话后，出现页面级垂直滚动条；向下滚动页面外层后，底部布局表现异常。反馈涉及对话内容、底部输入区以及主界面底部与悬浮元素的位置和背景。

2026-10-06 在本机 Firefox 的长对话中已完成运行态复现：视口高 832 px 时 `body.scrollHeight=2021`，页面外层实际可滚动 1189 px。消息区自身仍可内部滚动；直接溢出来源已由临时样式对照定位到消息角色标签，详见 [根因分析](root-cause.md)。原始用户截图未复制到仓库。

## 复现步骤

### 前置条件

- 进入 Chat 工作台，存在至少一个已有消息的非空白对话。
- 产品版本、访问路由、浏览器及版本、视口尺寸、页面缩放比例待确认。
- 使用测试会话复现，避免记录真实会话正文。

### 操作

1. 打开 Chat 工作台，进入已有消息的非空白对话。
2. 检查页面外层是否出现垂直滚动条，区分页面整体滚动与消息区域内部滚动。
3. 向下滚动页面外层至底部，观察对话内容、输入框、主界面底部及悬浮元素的位置和背景。
4. 在相同环境下切换到空白对话作对照，记录是否出现相同现象；该对照目前尚未验证。

本次长对话中稳定复现；触发所需的最小消息数量和其他浏览器表现仍待回归测试确定。

## 影响范围

- 已报告场景：Chat 工作台中已有消息的非空白对话，影响布局稳定性与阅读体验。
- 待核实场景：空白对话、短消息与长消息、多条消息、不同视口、浏览器及缩放比例。
- 尚无证据表明消息数据、发送功能或其他页面受损，不将其列为已确认影响。

## 连续补证进展

本轮通过 Firefox 实际访问产品，在 BUG-0029 长对话复现页面级滚动。10 个 `.chat-message > strong` 绝对定位到 `BODY`；临时将其设为 `position:static` 或给消息卡片设 `position:relative` 均使 `body.scrollHeight` 从 2021 降至 832，恢复样式后回到 2021。详见 [根因分析](root-cause.md) 的 E1–E5。
