# Chat 工作台非空白对话出现页面级滚动条及底部布局异常修复评审

## 评审结论

通过修复评审。根因材料已包含 Firefox 实际复现、计算样式和两次可逆的单变量对照；本轮审核既有证据，没有重新执行浏览器复现。通过评审表示确认需要修复，不表示修复或验收完成。

## 评审清单

| 检查项 | 结论与依据 |
|---|---|
| 可复现或根因充分 | 通过。root-cause.md E1–E5：页面高度 2021、视口 832，角色标签定位到 BODY；两种临时样式均使高度降至 832，恢复后回到 2021。根因校验 confirmed，5 条证据通过。 |
| 严重等级 | 保持 medium。影响滚动和底部布局，没有数据受损或核心发送能力不可用的证据。 |
| 回归验收 | acceptance.md AC-001–AC-006 覆盖外层与消息区滚动、内容可达、输入区、背景、切换及发送。尚未执行。 |
| 热修路径 | 无需特殊热修，按正常 Sprint 流程安排。 |

## 修复范围与剩余风险

优先为消息卡片建立局部定位上下文，保留角色标签语义。实现时检查卡片内其他定位元素；Firefox 已验证的因果证据不替代 Chromium、1440px、空白及短消息回归。浏览器完整版本、缩放及最小触发消息量仍待完善，不阻断本次修复决策。
