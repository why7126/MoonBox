# Chat 工作台非空白对话出现页面级滚动条及底部布局异常临时规避方案

## 当前结论

暂无已验证的临时规避方案。文档为草稿，不代表问题已缓解。

## 使用建议与限制

若消息区域仍可正常滚动，可尝试将指针置于消息区域内浏览；该操作仅为待验证候选，不能保证阻止页面外层滚动。若输入区已无法使用，先保留当前会话与脱敏异常证据，再交由维护者处理。

不建议删除会话、清除存储、反复发送消息或直接强制隐藏全局滚动条。这些操作没有有效性证据，且可能造成上下文丢失、重复消息或内容裁切。

## 验证与退出条件

按 root-cause.md 的 P1–P4 比较尝试前后页面和消息区滚动量、输入区可见性与内容可达性。仅实际改善且不产生副作用时，才能登记为有效规避；无改善则停止尝试。未更改配置，无需执行持久化配置回滚。正式修复通过验收后撤销临时操作建议。
