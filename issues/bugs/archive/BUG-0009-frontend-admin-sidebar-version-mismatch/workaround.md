# 临时规避方案

## 可用规避

在正式修复前，以前台侧边栏和仓库版本配置为准，将后台侧边栏 `v1.0.5` 视为展示文案错误，不作为发布版本或部署状态判断依据。

## 适用范围

- 适用于人工验收、演示和内部排障时解释版本号不一致。
- 不改变运行时行为，也不能消除用户可见的不一致。

## 限制

该规避方案只能降低误判风险，不能替代代码修复。正式修复仍应让后台侧边栏复用共享版本事实源，并补充回归测试。
