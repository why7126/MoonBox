# 直接治理命令完成证明失效临时处理

## 临时处理

暂无已验证可安全解除本例保护的通用临时命令。保留已有 Change、原执行、同步证明和保护记录，查看原执行与文档以确认成果已保存；区分运行结束与业务核验结论。

不要重复执行 req-opsx/bug-opsx、评审或归档来试探是否流转，不删除成果重建，不手工改库或改阶段，不伪造同步成功时间、指纹或证明。刷新不会改变当前证明不匹配机制。

## 证据与后续恢复

保留必要的操作身份、版本、时间、文件清单及摘要，脱敏记录；不采集完整聊天、凭证或无关业务内容。历史同步时清单缺失应明确标记，不能把执行前到当前的差异作为收尾差异。

后续受控恢复先核对原执行终态、权限/绑定、当前相关交付、证明和新运行占用，再在一致性锁/版本围栏下签发新的核验记录、确认保护并回读卡片；只核验、不重放业务。不满足门禁则保持阻断并给出具体缺口。

## 适用范围与退出条件

适用于支持的所有直接治理命令，不限 BUG-0055 或 bug-opsx。正式恢复能力尚待实施验证，本文件不是已可执行的解锁方案。只有适用验收通过并确认当前现场可安全恢复后才能解除相应保护；不释放新执行的保护。
