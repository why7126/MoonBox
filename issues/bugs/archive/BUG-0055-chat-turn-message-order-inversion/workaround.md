# Chat 同轮消息倒置临时处理

## 当前可用处理

暂无已验证能修正通用顺序的临时产品操作。刷新会重新应用同一排序规则，不能承诺刷新即可恢复；新建会话也不能消除跨秒触发条件。

遇到倒置时，结合本轮执行详情或轨迹核对请求与回复的关联及业务结果，不以助手显示时间推断执行先后。页面无法明确关联时保留现场，按已有排查入口进行只读核验；不猜测邻近消息归属。

## 禁止作为临时修复的做法

- 不因消息倒置而重复发送归档、评审或其他有副作用的命令。
- 不删除历史消息，不手工改数据库时间，不伪造消息发生时间。
- 不关闭准入、权限、完成证明或归档正确性门禁。
- 不仅对 REQ-0046、某个会话或当前轮次交换顺序。

## 适用范围与局限

上述办法仅帮助辨认结果，不能修复显示错误；适用于普通、REQ、BUG、纯 Change 关联会话。原始历史样本用于只读复核。正式修复仍需统一时间语义、轮次排序和分页/恢复规则并完成验收。

## 退出条件

正式修复部署且 [验收标准](acceptance.md) 的所有适用项通过后，退出临时核对流程；不能以文档补齐、准备成功或按钮可点代替通过。
