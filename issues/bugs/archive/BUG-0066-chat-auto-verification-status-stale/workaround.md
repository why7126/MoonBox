# 自动核验状态未刷新临时处理

## 临时处理

先保留未发送草稿，再刷新页面重新读取核验状态；若自动队列已经成功，应显示已核验。仍待核验时查看具体原因，只有合法核验按钮可用且理解当前成果差异时再核验。不要重新发送原治理命令，也不要跳过服务器保护。

## 边界

仅缓解当前体验，不视为修复通过；不得删除历史数据、绕过核验或重放业务。
