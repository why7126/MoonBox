# 临时规避

## 管理员可用规避

- 对重置密码、冻结、解冻、删除操作，先填写不少于 4 个字符的操作原因，再点击「确认」。
- 对编辑用户保存无响应的账号，优先确认该账号用户名是否符合当前规则：4-32 位，字母开头，仅包含字母和数字。

## 运维/开发规避

- 若必须编辑历史异常用户名账号，可临时通过后端接口或数据库维护可编辑字段，但需要保留审计记录并避免绕过权限控制。

## 局限

以上规避不能解决前端静默拦截的问题；正式修复仍需要改造用户管理页表单校验和错误反馈。
