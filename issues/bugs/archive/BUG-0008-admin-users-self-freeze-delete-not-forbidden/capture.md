# 现象

管理后台登录用户可以对当前账号执行冻结或删除操作，缺少自我保护约束。该问题可能导致管理员误操作后立即失去后台访问能力，形成账号管理与运维恢复风险。

# 复现步骤

1. 使用管理后台账号登录。
2. 进入管理后台用户管理页面。
3. 在用户列表中定位当前登录账号。
4. 尝试对当前登录账号执行冻结或删除操作。
5. 观察后端接口响应和前端操作入口状态。

# 期望 vs 实际

- 期望：后端必须对当前登录用户冻结或删除自己的请求返回 `403 Forbidden`；前端应隐藏或禁用当前账号对应的冻结/删除操作，并补充 API 与前端回归测试覆盖。
- 实际：当前账号的冻结/删除操作未被明确禁止，存在后端未以 `403` 拒绝、前端仍暴露危险操作入口、回归测试缺失的风险。
