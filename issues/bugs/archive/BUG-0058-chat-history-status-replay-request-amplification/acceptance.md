# 聊天历史状态与请求生命周期验收标准

以下保留原验收条件。本轮已执行合成回归及隔离真实浏览器验证，逐项证据见下方修复验证记录；自动验收状态由 Workflow Sync 回填。

## 样本与采样契约

使用授权测试环境和合成历史，覆盖1轮及10轮、终态与活跃混合、单轮事件少于200/恰好200/超过400条；保留当前真实单轮样本作为复现参考。准备工作不得重跑真实历史任务。记录部署版本、源码版本、浏览器/视口、缓存配置、轮次/事件规模、阶段与时间窗口。

每次首次进入、重访、展开/收起单独清空 Network，区分残留在途请求。首次进入与重访、默认缓存与禁用缓存分别至少3次，报告中位数和原始样本摘要，不混用窗口、不声称少量样本为稳定P95。记录正文首见与状态稳定时间、按 endpoint/匿名轮次分组请求数、传输量、同键并发峰值、Queueing/Stalled/Waiting；服务端耗时使用匹配 request_id 的脱敏记录，无法关联时明确缺失。

视觉观察使用1440px视口及当前使用视口，记录状态变化；无布局改造不引入原型复刻验收。合成测试、真实浏览器行为、网络计时分别报告。后续证据归属修复 Change 的 evidence/acceptance，不在本次创建空附件或伪造结果。

## 回归标准

| 编号 | 场景与操作 | 通过条件 | 验证与证据 |
|---|---|---|---|
| AC-001 | 首次打开已有终态历史 | 状态摘要可在完整事件详情返回前显示；无需求详情时不从cursor=0全量回放来重建终态；不会把未知状态伪装完成 | 可控延迟事件响应的组件测试＋真实浏览器状态时序 |
| AC-002 | 同轮状态、页脚及详情同时消费数据 | 同一授权上下文、同一轮次与游标的并发读取最多一个在途请求；消费者共享结果，不能重复传输同页来满足不同展示区域 | 请求计数回归＋Network归并；覆盖已观察到的三个消费者 |
| AC-003 | 已结束会话保持详情收起至少15秒 | 无详情专属events/diff/context周期读取；允许的必要摘要/权限更新单独列明，不与详情轮询混算 | 浏览器收起状态＋按endpoint的请求窗口 |
| AC-004 | 展开详情，长事件分页后收起再展开 | 事件顺序正确、无漏页/重复合并；正确处理恰好200条和超过400条；同有效版本已读取页可复用，收起后不继续无需求分页 | 分页组件测试＋事件数量/游标摘要；覆盖详情1000条边界 |
| AC-005 | 活跃、queued、stopping、unknown转终态 | 活跃状态正常更新，终态转换后停止不必要轮询；未知/错误不显示已完成；过程输出与最终正文不丢失 | 可控状态转换回归＋真实观察 |
| AC-006 | 恢复接口延迟大于3秒、乱序返回 | 同一恢复操作最多一个在途读取，最终有效结果能显示，无连续旧响应丢弃导致的长期loading；保留页面隐藏暂停、终态停止与预算语义 | 测试环境受控慢响应；实际重叠峰值与最终状态断言 |
| AC-007 | 切换会话、卸载、隐藏标签页后返回 | 旧会话请求取消或结果隔离，不污染新会话；恢复可见按需更新，无额外重复监听器和请求风暴 | 生命周期回归＋两会话浏览器操作 |
| AC-008 | 401/403/404、瞬断、权限或成果核验变化 | 失效缓存不泄漏或保留未授权内容，错误可恢复；成果核验、治理阶段与写入保护仍由可信状态决定 | 错误/权限测试；核验前后只读与可写边界断言 |
| AC-009 | 首次与重访性能对照 | AC-002/003请求约束满足；同部署条件下重访不再依赖历史事件回放才能显示状态；报告请求/字节及时间的前后差异，不把后端或环境波动归功于修复 | 按采样契约至少3次对照；时间未改善时解释剩余瓶颈，不能只报减少请求即宣称时延改善 |
| AC-010 | 页脚工具数、耗时、Token等摘要 | 与完整事件/可信摘要一致，不因只读取第一页而丢失末尾用量；无重复计算；缺失时不伪造0或完成 | 分页末尾用量合成回归＋浏览器对照 |
