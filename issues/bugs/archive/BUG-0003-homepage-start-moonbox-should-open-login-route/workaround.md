# 临时规避

## 当前可用规避

暂无产品内完整规避。用户仍可通过首页点击后进入 `/#login` 使用当前前台登录原型视图，但地址语义不符合预期，不能替代 `/login` 独立页面。

## 人工说明

在正式修复前，如需向测试或演示人员说明入口，可临时提示：

- 首页点击「开启 MoonBox」后会出现登录视图。
- 当前地址仍为 `/#login`，这是待修复缺陷。
- 验收时不得把 `/#login` 视为通过标准。

## 不建议的规避

- 不建议通过 Nginx 或部署层把 `/login` 重写成 `/#login`，这会固化错误语义。
- 不建议新增后端接口或后台登录跳转处理该问题；根因在前台路由建模。

## 正式修复方向

将前台登录页提升为 `/login` 应用路由，首页 CTA 跳转到 `/login`，直接访问和刷新 `/login` 均展示前台登录页。
