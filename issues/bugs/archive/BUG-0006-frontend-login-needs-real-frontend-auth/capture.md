# 现象

前台登录入口复用后台管理员认证，导致角色为“前台用户”的账号无法登录成功，并提示“账号不可用或无后台权限。”

# 复现步骤

1. 在后台用户管理中创建或准备一个角色为“前台用户”的账号。
2. 打开 MoonBox 前台登录入口 `/login`。
3. 使用该前台用户账号和密码提交登录。
4. 观察登录结果和错误提示。

# 期望 vs 实际

- 期望：前台登录入口应使用真正的前台用户登录能力；前台用户可完成前台身份认证并进入其业务范围，不应被后台管理员权限规则拦截。
- 实际：前台登录入口调用后台管理员登录接口；后端要求登录账号具备“后台管理员”角色，前台用户被拒绝并提示“账号不可用或无后台权限。”
