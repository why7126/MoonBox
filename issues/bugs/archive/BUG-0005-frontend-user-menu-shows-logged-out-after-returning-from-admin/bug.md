# 从后台返回前台时用户菜单显示未登录

## 现象

用户登录 MoonBox 后从前台进入后台，再返回前台需求中心时，左侧底部用户菜单栏会短暂或持续显示“未登录”。

## 复现步骤

1. 登录 MoonBox 并进入前台需求中心。
2. 通过前台用户菜单进入后台。
3. 再从后台返回前台需求中心。
4. 观察前台左侧底部用户菜单栏的用户名与头像区域。

## 期望结果

- 返回前台后，用户菜单应保持显示当前登录用户。
- 如果登录态确实失效，应清晰跳转登录页或展示一致的登录失效反馈。
- 加载需求中心上下文期间，不应把已登录用户显示为“未登录”。

## 实际结果

- 前台用户菜单会显示“未登录”。
- 当需求中心上下文接口加载较慢时，“未登录”可能短暂出现。
- 当前后台 session 不同步或鉴权请求失败时，“未登录”可能持续显示。

## 影响范围

- 影响前台需求中心左侧用户菜单栏。
- 影响从前台进入后台后再返回前台的导航链路。
- 可能影响用户对当前登录态、后台入口权限和账号状态的判断。

## 严重等级说明

严重等级为 medium。该问题不直接造成数据损坏，也不必然阻断需求中心主体内容加载；但它会造成登录态展示不一致，降低用户对账号状态和权限状态的信任，并可能在 session 失配时留下半登录体验。
