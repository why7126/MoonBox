# 临时规避方案

## 用户侧规避

如果从后台返回前台后用户菜单持续显示“未登录”，可手动刷新页面；若仍然显示异常，则退出并重新登录。

## 运营或测试侧规避

- 复现时同时观察需求中心主体区域是否出现权限错误或数据加载错误。
- 如怀疑 session 失配，可清理浏览器本地存储中的 MoonBox session 后重新登录。

## 局限

该规避方案不能消除加载期间短暂显示“未登录”的闪烁，也不能从根本上解决前后台 session 状态不一致。正式修复仍需统一前台用户展示兜底和鉴权失败处理。
