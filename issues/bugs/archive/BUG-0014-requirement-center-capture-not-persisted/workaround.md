# 临时规避

## 建议操作

1. 尚未提交或仍可找回内容时，先保留标题、描述、类型、负责人和来源；已被表单清空的描述不能保证恢复。
2. 在目标项目上下文使用 `/req-capture` 或 `/bug-capture`，提交原始内容，由治理命令完成持久化。执行前核对注册表及同名条目，避免重复记录。
3. 命令成功后检查返回的完整 ID、plan 目录、capture.md、trace.md、注册表和 CHANGELOG，再重新加载需求中心。
4. 不将临时卡片的短 ID 当作已分配正式编号，不依据前端成功提示继续评审或生成。

## 限制与恢复

该方案依赖目标项目治理命令可用及合法写权限；本次未代用户创建任何替代业务条目。此前 bug-capture 的落盘与同步结果可作为命令路径证据，但所有目标项目仍需实际核对。该方案不修复网页入口，也不能恢复已丢失的描述。

未提供部署补丁或生产热修；常规修复验收完成后恢复使用网页创建入口。
