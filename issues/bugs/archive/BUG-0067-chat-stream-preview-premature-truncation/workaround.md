# Chat 流式正文预览过早截断临时处理办法

## 当前可用办法

- 若任务仍执行中，继续观察既有轮次，不因该提示重复发送命令、停止任务或触发恢复。
- 最终答复出现后可阅读最终正文；本样本提示随之消失，但执行是否结束仍以独立状态和成果核验为准。
- 如需诊断，使用已授权的执行轨迹或只读聚合核对是否仍在产出；轨迹本身可能有展示上限，不能保证提供完整正文。

## 限制与风险

暂无已验证的用户侧操作能在运行中解除 21 片段预览上限。刷新仍调用相同读取逻辑，不作为可靠规避；不建议改库、清理事件或放宽所有存储限制。

本办法只降低误判和重复执行风险，不修复正文展示。若终态后仍缺输出，应保留状态、时间与脱敏异常摘要继续核对，不能直接认定只是本缺陷。
