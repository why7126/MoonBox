# 需求中心验收状态与文档入口偏差临时规避

在修复前，卡片的“研发 / 测试”只作为 `tasks.md` 任务进度；不要据此认定验收通过或可以归档。归档前核对目标 Issue 的 `acceptance.md`、关联 Change 的交付证据和产品复验记录，并以 `/opsx-archive` 的实际门禁结果为准；门禁阻断时按返回的缺项补证，不重复勾选已完成任务来掩盖缺口。

卡片未显示既有文档时，可在当前授权项目的治理文档目录或对应 Change 文档入口只读查看；核对 Issue/Change/Sprint 来源，尤其是同名 `trace.md`。不修改文件路径、权限、验收状态或归档记录来绕过卡片展示问题。没有授权目录访问时，按当前项目的文档读取权限取得相关材料。

该规避只帮助人工判断，不改变卡片显示或自动化归档门禁。
