# 需求中心 Capture 卡片负责人标识临时规避

## 可用性与适用范围

暂无已验证的产品内规避方案。以下为协作建议，尚未实测，不代表缺陷已修复。

## 临时处理建议

在有权查看该卡片的团队内，由创建者人工确认归属；必要时在既有获准协作渠道提供可读称呼。无法确认时标记待核实，不凭截断 ID 猜测负责人。详情与筛选可能共用 owner，不将其视为可靠替代。

## 限制与退出条件

不手工替换持久化 owner，不修改权限、数据库或治理文件中的身份键；扩大标签宽度只可能显示完整标识，不能解决名称解析问题。人工核对耗时且不能覆盖所有历史来源。待正式修复按 acceptance.md 验证通过后停止临时人工核对。本轮未实施任何业务侧规避操作，无需业务回滚。
