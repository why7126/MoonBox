|---|---|---|---|
| AC-011 | 首次加载失败 | 看板区域显示紧凑错误态，标题为“需求中心暂时无法加载”，说明为“当前项目数据读取失败，请稍后重试或查看详情。”；提供“重新加载”和“查看详情”；导航与项目切换仍可用，不自动弹窗 | 通过：四组浏览器首次页内错误、主动详情及恢复 |

### 动作与浮层验收矩阵

下列selector均已映射到真实组件，证据见ui-validation.json和浏览器回归脚本；错误区域为`.rc-read-error`。

| 动作 | 浮层类型 | 真实 selector | 状态 | 验收证据 |
|---|---|---|---|---|
| 页面重新加载 | 无 | `[data-testid="rc-error-retry"]` | default、focus、loading、disabled、error、success | AC-011、AC-018 的请求计数与 DOM 状态 |
| 页面查看详情 | dialog | `[data-testid="rc-error-details-trigger"]` → `[data-testid="rc-error-details-dialog"]` | closed、open、error-resolved | AC-015、AC-017 的截图与键盘记录 |
| 抽屉重新加载 | 当前 drawer 内部 | `[data-testid="rc-document-error-retry"]` | loading、disabled、error、success | AC-014、AC-018 的抽屉和请求状态 |
| 抽屉查看详情 | 共用 dialog | `[data-testid="rc-document-error-details-trigger"]` → `[data-testid="rc-error-details-dialog"]` | drawer-open、dialog-open、dialog-closed | 关闭详情后仅回到抽屉，不关闭抽屉 |
| 复制错误信息 | 当前 dialog 内部 | `[data-testid="rc-error-copy"]` | default、copied、copy-failed | 复制内容脱敏；复制失败有内联说明，不再弹窗 |
| 关闭详情 | 当前 dialog | `[data-testid="rc-error-details-close"]`、Esc、遮罩 | focus、closed | 焦点恢复、内外点击和遮罩层级记录 |

复用同一 ErrorState、Button 和详情 Dialog 组件族，页面与抽屉只提供错误上下文；不使用原生 alert 代替设计系统弹窗。详情弹窗关闭快捷键只作用于最上层，避免一次 Esc 同时关闭详情和 MD 抽屉。
