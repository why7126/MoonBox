# 登录失效刷新未跳转登录页临时处理方案

## 当前结论

可用规避方案是手动进入 `/login` 重新登录，再返回 Chat 工作台或原目标页面。该方案只能恢复用户当前会话，不修复 401 后页面未自动跳转的问题。

## 候选操作

先记录异常证据并保留必要的未提交内容，再手动访问同站点 `/login`，使用正常登录流程重新登录，返回原页面验证是否恢复。若页面仍保留旧错误状态，可刷新一次或重新打开 Chat 工作台。

## 限制与反馈

不绕过鉴权，不建议删除全部站点数据，不建议手工篡改 localStorage 中的 token。重新登录仍失败时，记录发生时间、脱敏错误码、请求路径和请求标识。

返回结果：是否打开登录页、是否登录成功、原页面是否恢复。该操作不能替代正式修复与验收。
