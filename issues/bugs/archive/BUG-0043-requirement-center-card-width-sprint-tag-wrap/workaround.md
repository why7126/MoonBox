# 需求中心迭代标签换行临时规避说明

## 临时规避

暂无已验证且无需修改页面样式的布局规避方案。可以将两行文本连读为完整 Sprint 编号，继续查看卡片文档与既有动作；此方法仅缓解阅读困难，不视为修复。

## 不建议的替代操作

不通过重命名 Change 或 Sprint 来迁就布局，不改变治理身份或关联关系。窗口加宽不会改变固定 320px 列宽，因此不能作为可靠规避方案。

## 退出条件

统一扩宽与标签防换行修复完成，并通过 acceptance.md 中的全部回归项后，无需临时规避。
