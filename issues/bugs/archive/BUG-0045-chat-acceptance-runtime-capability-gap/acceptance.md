## 通过与边界

全部适用项通过才签认。命令测试、真实浏览器与产品轮次分别报告；阻塞和缺失证据不算通过。历史 AnyIO/Rollup 问题通过对应目标环境探针验证，不凭安装依赖宣称消失。BUG-0046 的问答回传与 REQ-0046 的文案重做不纳入本条实现范围，但现有状态不能将阻塞伪报通过。

产品入口涉及可见反馈时沿用现有 UI；正式 Change 按实际改动补充 selector、阶段×视口映射、截图与样式证据。本计划的1440px观察不是未经设计的页面重做授权。
