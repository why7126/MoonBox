# 执行保护未收敛期间的临时处置

## 当前结论

目前没有已验证、可安全解除该样本执行保护的临时方案。以下仅用于降低重复操作风险，不宣称解除阻塞。

## 可执行的只读处置

1. 保留原会话、原成果、应用及完成证明；用“查看执行”和已有证据入口核对原轮次，不重新提交评审。
2. 区分文档 approved、历史应用 verified 与当前保护 needs_review；向协作者说明后续准入暂被阻断，原文档没有丢失。
3. 已有刷新只用于读取结果，当前指纹条件未改变时刷新不会解决问题；不要反复刷新或重复运行 Workflow Sync 当作解锁手段。
4. 暂缓该对象的新增治理写入与加入迭代，待正式修复后的受控核验路径恢复；其他无关对象不据此全局停用。
5. 若后续相关成果已变化，保留版本差异与新操作，不回滚当前源文件以强行凑回旧指纹。

## 禁止作为临时方案

不手工把 guard 改 idle/validated，不修改 proof.source_hash，不补造成功记录，不删除原会话，不重复应用成果，不跳过占用、权限、版本或幂等检查。不通过终端绕过产品门禁推进该对象流程。

## 退出条件与失败处理

正式修复完成并通过验收后，对原操作执行已授权的受控核验，验证保护、生命周期和准入一致，确认无重复副作用，再允许后续动作。核验失败继续保留成果和原因，不扩大写权限；需要修复回滚时回滚实现，保留审计与历史证明，不回滚业务成果来消除提示。


## 实施中的受控核验结果

本轮已增加按原操作核验的服务及接口。原 REQ-0046 返回历史成果可信、当前相关依赖冲突，保护继续保留；“已评审”生命周期与“不能继续写入”准入分别表达。此结果不要求重新评审，也不允许手工解锁。REQ-0046 的产品入口尚未交付，当前不建议用户以终端自行绕过入口处理。
