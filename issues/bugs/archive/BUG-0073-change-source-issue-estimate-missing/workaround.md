# Change 来源人力估算缺失临时处理建议

## 临时处理
查看Sprint scope_estimates中的来源Issue计划人天；此样本为3人天。多人或多交付评估时人工核对归属，不把卡片待估算视为零。
不为消除提示复制估算行、补零、修改历史记录或重复累计Sprint容量。当前无自动界面规避方案。

## 退出条件
修复通过真实卡片与容量一致性验收后停止人工对照。
