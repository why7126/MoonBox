# 统一本地宿主机端口段

## 背景

项目当前使用 18101～18199 宿主机端口。按新的端口规划统一迁移到 39001～39050，减少配置、脚本和验收入口之间的偏差。

## 变更内容

- 默认后端、Web、MinIO、文档站、MySQL 与隔离测试端口按原末两位映射到 390xx。
- 环境样例、Compose、启动与校验脚本、测试入口、部署说明和端口规范同步调整。
- 容器内服务端口不变。已有私有环境配置需由部署者在维护窗口迁移。

## 能力范围

- 修改 `deployment-governance`：本地宿主机端口范围及默认 Web 端口。

## 影响

影响本地部署访问地址、CORS 默认来源和端口校验；不改变 API 协议、数据库结构或客户端生成。
