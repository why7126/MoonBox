## ADDED Requirements

### Requirement: 输入区执行配置选择

系统 SHALL 在 Chat 工作台输入区展示 Agent、模型和推理配置选择入口。当前首版 Agent 可用项只有 Codex，界面 SHALL 清楚表达当前执行主体；模型和推理配置 SHALL 由服务端能力配置或前后端共享能力约束驱动，不得仅以前端硬编码列表作为可用性事实源。

#### Scenario: 单 Agent 状态

- **WHEN** 用户进入 Chat 工作台且当前只有 Codex 一个 Agent 可用
- **THEN** 输入区展示 Codex 执行主体
- **AND** 控件以只读、禁用下拉或单项选择器表达，不暗示存在其他可用 Agent

#### Scenario: 模型和推理配置来自服务端

- **WHEN** 页面加载执行配置能力
- **THEN** 系统展示服务端认可的默认模型和推理配置
- **AND** 模型与推理选项包含显示名、稳定值、可用状态和禁用原因

#### Scenario: 长模型名与窄屏布局

- **WHEN** 模型名较长或用户使用窄屏视口
- **THEN** 配置控件通过截断、tooltip、菜单详情、换行或更多菜单保持可读
- **AND** 不遮挡输入框、发送按钮、停止按钮或执行状态

### Requirement: 配置发送与历史追溯

系统 SHALL 在用户发送消息时提交当前 Agent、模型和推理配置，并由后端重新校验会话权限、空间权限、执行端能力和配置可用性。系统 SHALL 在轮次事实源保存请求配置、实际生效配置和降级原因摘要；历史轮次 SHALL 展示该轮实际生效配置，且当前选择不得改写历史配置。

#### Scenario: 发送配置进入执行链路

- **WHEN** 用户选择模型和推理配置后发送消息
- **THEN** 发送请求携带 Agent、模型和推理配置标识
- **AND** 后端重新校验配置可用性与权限
- **AND** 轮次记录保存请求配置和实际生效配置

#### Scenario: 服务端降级

- **WHEN** 服务端因额度、权限、执行端版本或策略使用不同配置
- **THEN** 页面展示实际生效配置和脱敏降级原因
- **AND** 请求日志、Task Trace 和错误提示不得泄漏内部路径、完整配置、密钥、Token、Authorization、Cookie 或 `.env` 内容

#### Scenario: 历史轮次查看

- **WHEN** 用户查看历史轮次详情
- **THEN** 页面展示该轮实际使用的 Agent、模型和推理配置
- **AND** 继续会话后的当前配置变化不重写历史轮次事实

### Requirement: 配置状态与运行边界

系统 SHALL 覆盖配置加载中、加载失败、不可用选项、运行中、停止中、状态未知和已归档会话状态。运行中配置控件 SHALL 不改变已经发出的执行；已归档会话 SHALL 保持只读。

#### Scenario: 配置加载失败

- **WHEN** 执行配置能力接口加载失败
- **THEN** 输入区布局保持稳定
- **AND** 系统按服务端策略使用默认配置继续或禁用发送并展示可恢复提示

#### Scenario: 不可用选项

- **WHEN** 模型或推理配置因无权、额度不足、执行端不支持或策略禁用而不可用
- **THEN** 菜单展示禁用态和简短原因
- **AND** 后端发送接口仍拒绝无权或不可用配置

#### Scenario: 运行中配置边界

- **WHEN** 同会话已有轮次处于运行中、停止中或未知状态
- **THEN** Agent、模型和推理配置控件不改变当前执行
- **AND** 首版可以禁用配置修改，或明确标注只影响下一轮

### Requirement: 执行配置原型驱动验收

系统 SHALL 在实现输入区执行配置选择前完成 UI Contract、UI Skeleton 和局部一致参考合同。实现完成前 SHALL 提供 1440px 桌面视口、关键交互、窄屏、深浅主题、computed style、Mock/API 边界和 linked REQ 最终一致性证据。

#### Scenario: UI Skeleton 先行

- **WHEN** Change 开始实现 Chat 输入区执行配置 UI
- **THEN** 先完成配置栏、控件插槽、菜单容器、状态容器、稳定选择器和 1440px 验收焦点
- **AND** 未完成 Skeleton 证据前不得关闭细节实现任务

#### Scenario: 菜单交互验收

- **WHEN** 模型或推理菜单准备验收
- **THEN** 验证选择后关闭、点击外部关闭、Esc 关闭、内部点击不误关闭父级浮层
- **AND** 记录截图、DOM 断言、computed style 或等价证据

#### Scenario: Mock/API 边界验收

- **WHEN** UI 使用 Mock 配置完成 Skeleton 或局部实现
- **THEN** Change 证据声明 Mock 字段、真实 API 覆盖范围和生产风险
- **AND** 归档前确认真实配置能力、发送和历史回显已接入或明确非目标
