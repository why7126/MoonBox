## 背景与动机

前台需求中心的空间切换浮层虽然已经有交互骨架，但当前 `workspaces` 仍来自项目治理配置派生的单空间上下文，无法反映后台空间管理中的真实空间、成员、状态和角色。REQ-0018 要把前台空间切换列表接入后台空间事实源，让用户只在自己已加入的空间之间切换，并正确处理冻结、回收和最近选择失效场景。

## 变更内容

- 将需求中心上下文中的空间列表从项目治理配置派生升级为后台空间事实源驱动。
- 增加前台安全的空间可见性过滤：仅返回当前登录用户已加入空间，默认排除回收中空间。
- 增加冻结空间只读语义：可展示、可切换查看，但必须在 UI 和上下文中标记只读。
- 强化最近选择校验与失效回退，避免本地缓存空间不再可访问时闪现错误空间。
- 保留“创建或加入空间”入口位置，但不实现创建、加入申请或审批流程；该流程归属 REQ-0019。
- 补充 BFF/API、前端状态、UI Skeleton、1440px 视觉验收、测试和文档同步任务。

## 能力影响

### 新增能力

无。

### 修改能力

- `web-catalog-requirement-center-real-data`: 需求中心真实数据聚合中的空间上下文从项目治理元数据派生升级为后台空间事实源驱动。
- `web-catalog-requirement-center`: 前台用户菜单空间切换交互增加真实空间、冻结只读、空态/错误态和最近选择失效回退约束。

## 影响范围

- 后端：需求中心 BFF 或前台空间上下文服务需要读取后台空间、成员和产品绑定事实源，并做字段白名单与权限过滤。
- 前端：需求中心空间切换浮层、当前空间状态、最近选择缓存、空态/错误态、冻结只读状态和看板上下文刷新。
- API：如新增或调整前台空间上下文响应字段，需同步 API 文档和测试。
- 安全：普通前台用户不得通过后台管理空间列表接口读取全量空间、配额、审计或删除信息。
- 测试：需要后端过滤/权限测试、前端空间切换状态测试和 1440px UI 验收证据。
