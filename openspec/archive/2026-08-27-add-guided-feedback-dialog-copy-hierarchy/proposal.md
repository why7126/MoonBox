# 优化引导式反馈弹窗顶部说明层级

## 背景

现有引导式反馈契约要求命令在需要用户选择、确认或补充信息时优先使用原生交互卡片，并提供结构化选项、推荐项和可补充说明。但卡片顶部说明尚未约束文案层级，容易出现“副标题 + hint”重复承载同一流程信息的问题，降低决策界面的清晰度。

## 目标

- 明确交互卡片顶部说明只保留一处主说明。
- 禁止副标题、hint、description 或说明正文重复表达同一流程信息。
- 将约束同步到上下文预算规则、`/spec-opt` Skill 和 OpenSpec delta，供后续命令 Skill 复用。

## 非目标

- 不修改业务 `src/` 代码、Web 页面或客户端运行时交互。
- 不批量改写所有命令 Skill 的既有反馈契约文本。
- 不调整原生交互卡片工具能力或客户端实现。
