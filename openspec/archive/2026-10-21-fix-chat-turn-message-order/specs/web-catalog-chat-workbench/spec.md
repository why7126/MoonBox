# Chat 消息顺序与时间语义增量规格

## MODIFIED Requirements

### Requirement: 对话与轨迹一致展示
系统 MUST 提供对话与轨迹双视图，共享轮次身份，工具开始与结束按执行轮次和工具标识配对，历史缺失详情显示未采集。消息入口 MUST 定位本轮轨迹，停止仍只作用于当前活动轮次。系统 SHALL 使同轮次已经保存的助手文字在对话中可读，包括停止、未知和恢复轮次；已有最终正文优先，降级文字明确标识部分输出及缺口，不以文字存在推断执行完成。恢复和读取 SHALL 保持幂等、会话权限及轮次隔离。

#### Scenario: 查看工具结果
- **WHEN** 用户选择已记录的工具节点
- **THEN** 展示脱敏参数、结果、退出码和可用计时，未采集字段不伪造，超长内容明确截断

#### Scenario: 窄屏阅读
- **WHEN** 用户在窄屏查看对话与轨迹
- **THEN** 详情上下排列，表格局部滚动，输入框不产生页面横向溢出

#### Scenario: 有输出后停止
- **WHEN** 停止轮次已有助手输出事件但缺失持久化助手正文
- **THEN** 对话显示已保存的部分文字，刷新后仍可读，状态保持已停止

#### Scenario: 输出后状态未知
- **WHEN** 轮次在保存助手输出后进入未知状态
- **THEN** 对话显示部分文字及未知提示，不宣告命令完成或自动重发命令

#### Scenario: 恢复与重复处理
- **WHEN** 未知轮次恢复为完成、失败或已停止，并重复处理事件或恢复请求
- **THEN** 正文只归属该轮次且不重复；终态由权威执行事实决定，同 item 快照替代增量而不二次追加

#### Scenario: 正常最终答案
- **WHEN** 正常完成轮次存在持久化最终答案及过程增量
- **THEN** 对话优先显示最终答案，不把过程文字重复拼入或错误标识为最终结论

#### Scenario: 无助手输出
- **WHEN** 失败或停止轮次没有助手文字
- **THEN** 保留真实状态，不伪造正文或成功提示

#### Scenario: 分页与事件缺口
- **WHEN** 目标历史轮次跨消息或事件分页，或保存的事件有缺口或裁剪
- **THEN** 按稳定轮次身份有界读取已保存文字，不跨轮次拼接、不重复正文，并明确部分内容与截断边界

#### Scenario: 未授权读取
- **WHEN** 用户尝试读取他人会话的正文或降级输出
- **THEN** 系统拒绝访问，降级路径不绕过会话权限，观测摘要不保存原始正文或凭证

系统 SHALL 对虚拟输出与持久消息使用相容的稳定身份和确定性总排序，同轮用户在助手之前，不因保存时间跨秒、恢复或分页转换而倒置。排序键与显示时间分离，历史不可靠时间明确降级，不编造时间事实。

#### Scenario: 跨秒提问和回复
- **WHEN** 用户消息比轮次创建晚一秒或多秒，随后生成助手回复
- **THEN** API 和 Web 均按轮次与轮内顺序展示用户在前，时间来源保持真实

## ADDED Requirements

### Requirement: 会话消息统一排序与分页收敛
系统 MUST 使用跨轮稳定平局键与轮内角色顺序形成总序，在 SQL 分页前纳入虚拟助手，前端使用同一正向规则。游标读取 MUST 保留权限校验，重复页和迟到响应不得造成重复、永久漏项或跨会话污染；数据停止变化后已加载范围复核 SHALL 收敛至服务端同范围全集。

#### Scenario: 同秒多轮与拆页
- **WHEN** 同秒多轮以页大小1加载，且同轮消息被拆到不同页
- **THEN** 完整合并无重复遗漏，用户先于同轮助手，多轮顺序稳定

#### Scenario: 旧轮迟到输出
- **WHEN** 加载历史期间已越过游标的轮次新增输出或完成持久化
- **THEN** 范围复核补齐该输出，保留稳定身份位置且旧响应不能覆盖新内容

#### Scenario: 切换会话和重复恢复
- **WHEN** 旧响应在切换会话后到达或同轮重复恢复
- **THEN** 旧会话响应丢弃，同轮恢复幂等，新轮重试保持独立身份

### Requirement: 消息时间来源与历史降级
系统 MUST 区分轮次开始、消息保存、输出事件与更新时间；不得用排序键伪造回复发生时间。历史时间不可确认时 SHALL 标明未知，保留原始数据。

#### Scenario: 历史回复时间不可靠
- **WHEN** 历史助手仅有旧轮次投影时间且无可靠事件时间
- **THEN** 页面明确时间未确认，仍按正确因果顺序展示，不改写原始记录

#### Scenario: 流式转持久化与刷新
- **WHEN** 输出从事件投影转为持久消息并刷新页面
- **THEN** 身份及位置一致，时间来源可解释，部分输出和执行终态仍依据权威事实
