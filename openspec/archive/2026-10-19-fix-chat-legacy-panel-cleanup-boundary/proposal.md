# 聊天旧面板清理边界修复提案

## 背景

BUG-0048-chat-legacy-panel-cleanup-removes-conversation 已通过评审并纳入 sprint-010。旧清理扫描全部带标签容器，聊天正文触发祖先删除，造成会话空白。

## 变更内容

将 DOM 清理限制为明确旧面板标识与明确旧评审对话框；覆盖普通正文、父容器和正常对话框回归；同步本地 Web 容器。

## 能力影响

为 web-catalog-chat-workbench 增加旧面板清理边界约束，不改变现有布局和业务权限。

## 影响范围

runtimeBuild.ts、相关测试及本地 Web 镜像。API、DB、客户端生成与权限不变。真实产品验证复用用户授权的 REQ-0046 评审，不自动批准其他 Issue。

## 回滚方案

保留部署前 Web 镜像；异常时恢复原镜像。不删除聊天记录或改写评审事实。

## 验收返修范围补充

真实 REQ-0046 评审暴露 trace 的既有 req_id 身份字段不被后端接受。为完成用户授权的评审应用验证，兼容 trace 的 req_id/requirement_id 表达；字段冲突仍拒绝，不改变评审权限、状态和文件范围门禁。
