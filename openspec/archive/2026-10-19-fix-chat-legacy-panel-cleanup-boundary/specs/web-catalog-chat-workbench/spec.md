# 聊天旧面板清理安全边界规格

## ADDED Requirements

### Requirement: 旧治理面板清理不得删除正常会话
系统 MUST 只清理具有明确旧治理面板标识或明确旧评审对话框身份的元素，不得因普通聊天正文包含旧面板关键词而删除正文、会话外壳或无关对话框。

#### Scenario: 普通消息提及确认应用
- **WHEN** 带可访问标签的聊天区域包含确认应用等普通文本
- **THEN** 清理后会话外壳、消息与输入区保持存在

#### Scenario: 明确旧面板与正常消息并存
- **WHEN** 明确旧面板包含旧入口文案且旁边有正常消息
- **THEN** 只清理旧面板，重复调用不继续删除正常节点
