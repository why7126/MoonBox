# Git 隐私扫描上下文识别优化

## 背景

当前327条告警已逐类核对：278条哈希或标识符、44条测量数值、2条装饰器误匹配、1条合成身份、2条检测测试样例。URL整行跳过和占位符子串放行会漏报。用户明确授权本次治理优化。

## 变更内容

识别有限的哈希、JSON数值与Python转义装饰器上下文，去除URL整行跳过；占位符按规则及完整值判断，测试样例动态构造，不豁免测试目录。

## 能力影响

新增 git-privacy-context-scanning 规格，保持密钥、连接串及真实路径阻断。

## 影响范围

仅扫描器、测试、脚本说明和治理材料，无产品API、数据库、UI或部署变化。
