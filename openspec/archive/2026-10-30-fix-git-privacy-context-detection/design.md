# Git 隐私扫描上下文设计

## 识别边界

仅对手机号候选的完整标准长度十六进制摘要或UUID，以及非字符串JSON小数测量值排除误报。邮箱仅排除转义换行后的路由装饰器形态和精确合成提交邮箱。URL不再豁免整行。

## 占位符

完整的已知占位符、环境变量表达式可保留；真实值包含example、localhost、问号等不放行。连接串逐项核对凭据，主机localhost不是凭据安全依据。本机路径仅允许明确占位用户目录。

## 验证

旧版与新版对同一文件快照对照；正例覆盖URL同排邮箱、带占位字样的密钥、真实连接串、真实路径、测试目录敏感值。负例覆盖已核实327条来源。保留未识别告警，不能为零告警增加宽泛豁免。
