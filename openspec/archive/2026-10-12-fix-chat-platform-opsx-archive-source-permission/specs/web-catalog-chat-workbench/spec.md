# Chat 平台 source 工作区归档权限与状态诊断修复

## MODIFIED Requirements

### Requirement: 配置状态与运行边界

系统 SHALL 覆盖配置加载中、加载失败、不可用选项、运行中、停止中、状态未知和已归档会话状态。运行中配置控件 SHALL 不改变已经发出的执行；已归档会话 SHALL 保持只读。

#### Scenario: 配置加载失败

- **WHEN** 执行配置能力接口加载失败
- **THEN** 输入区布局保持稳定
- **AND** 系统按服务端策略使用默认配置继续或禁用发送并展示可恢复提示

#### Scenario: 不可用选项

- **WHEN** 模型或推理配置因无权、额度不足、执行端不支持或策略禁用而不可用
- **THEN** 菜单展示禁用态和简短原因
- **AND** 后端发送接口仍拒绝无权或不可用配置

#### Scenario: 运行中配置边界

- **WHEN** 同会话已有轮次处于运行中、停止中或未知状态
- **THEN** Agent、模型和推理配置控件不改变当前执行
- **AND** 首版可以禁用配置修改，或明确标注只影响下一轮

#### Scenario: 执行启动前失败可恢复

- **WHEN** Chat 平台在创建外部 executor turn 前发生工作区、沙箱、容器或权限 setup 失败
- **THEN** 系统 MUST 将该轮记录为 failed，并释放会话活动占用
- **AND** 错误码 MUST 使用脱敏的安全枚举
- **AND** 页面 MUST 展示可恢复失败状态，不得展示为持续状态未知
- **AND** 只有外部 executor turn 已创建但终态不可确认时，系统 MAY 使用 unknown 并等待后续核实
