## 背景与动机

需求中心未覆盖无 REQ/BUG 来源的独立 Change，既有卡片也缺少当前 Change 身份。补齐活动与归档可见性及授权追溯，并按用户确认仅调整原卡片 ID 行和中文标题。

## 变更内容

- 在完整授权项目快照内识别独立与关联 Change，覆盖归档、歧义和来源缺失，先识别关联再过滤权限。
- REQ/BUG 原 ID 下新增同字号 Change ID 文本行，卡片标题改为同一 Change 中文标题；其余卡片结构和动作保持。
- 独立 Change 使用自身身份，提供受控文档入口、状态和任务进度；统计搜索不重复计算关联 Change。
- 补齐 UI 及 API 授权回归和观测链路验证，阶段按钮复用已有能力门禁，不新增执行服务或自动Chat发送。

## 能力范围
