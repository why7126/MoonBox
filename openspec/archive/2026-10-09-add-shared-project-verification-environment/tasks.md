# 平台提供跨空间项目验证环境实施任务

## 1. 身份、授权与环境预检

- [x] 1.1 核对现有空间/仓库绑定、工作副本、制品目录、请求日志和 Task Trace 边界，固化验证任务身份与允许输入。
- [x] 1.2 实现 Node 锁文件、包管理器、Playwright、OS/架构和镜像摘要的环境身份与声明校验。
- [x] 1.3 实现分层预检和 ready/preparable/unavailable 诊断，覆盖依赖、浏览器、系统库启动及目标服务。

## 2. 制品准备与运行隔离

- [x] 2.1 构建固定版本 Firefox/Chromium 验证 runner，加入构建时和启动时浏览器探针、版本与摘要记录。
- [x] 2.2 实现受控制品准备和不可变只读复用，验证锁文件或 OS/架构变化导致缓存失效，失败不误用旧制品。
- [x] 2.3 实现按空间/项目/任务隔离的工作副本、资源和网络限制，拒绝宿主路径、任意命令、Docker socket 与跨空间访问。

## 3. API、任务与证据

- [x] 3.1 实现授权预检、创建/查询/取消 API 与幂等任务状态，按实际数据模型同步 SQLite/MySQL 迁移及测试。
- [x] 3.2 实现 Firefox/Chromium 任务执行、超时/取消/恢复与活跃制品引用保护。
- [x] 3.3 实现权限保护的截图、视口、浏览器版本、computed style 和断言摘要，区分环境失败、测试失败与真实浏览器通过。
- [x] 3.4 同步 OpenAPI、Orval、API 与数据库文档；请求日志和 Task Trace 只记录脱敏身份、版本、状态、计数及错误类别。

## 4. 验证与交付

- [x] 4.2 使用两个空间、同仓库双绑定和另一个独立 Web 项目验证工作区、凭证和结果隔离。
