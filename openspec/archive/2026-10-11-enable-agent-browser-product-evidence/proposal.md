# Agent 浏览器自主取证治理提案

## 背景

现有规则在证据不足时直接要求人工补证，导致可由 Agent 在产品中复现和采集的测试、验收、BUG 证据被转交用户，延缓闭环。

## 变更内容

- 明确 Agent 可在已有授权下直接访问产品浏览器取证，通常优先 Firefox，无需二次确认。
- 明确自主取证的权限、敏感信息、不可逆操作与证据存放边界。
- 仅在自主取证不可行或仍不足时请求人工补证，并记录原因。
- 将该规则接入 `.agents/skills/` 下所有技能，统一任务入口行为。
- BUG 探索、生成与完善命令在根因未确认时持续自主补证，不以文档生成作为停止点。
- 通用探索与需求探索在现状判断需要产品运行态证据时主动查看产品，保持只读探索边界。

## 能力影响

### 修改能力

- `harness-runtime`：Agent 问题排查与验收证据获取流程。

## 影响范围

治理规则、全部 46 份技能入口、OpenSpec 和 Sprint 文档；不改变业务代码、API、数据库或部署。
