# 每轮统一运行状态与核验入口修复提案

## 背景

REQ-0046已评审并纳入sprint-011。Chat状态行、底部恢复大面板与需求卡片分别解释结果，容易把模型结束、业务完成及当前准入混同。BUG-0052已实现后端证明与交接，剩余联合展示验收需要本Change承接。

## 变更内容

将恢复内容迁入所属轮次的唯一状态入口与内联详情；按可信执行、业务、正文完整性及读取状态统一投影。统一详情/证据/恢复确认/草稿替换动作族，接入核验、差异及原执行定位。保留可信生命周期，独立解释当前异常与准入；覆盖历史、迟到、重连、权限与双视口。

## 能力影响

### 新增能力

无独立新业务能力。

### 修改能力

- web-catalog-requirement-center：增加生命周期、核验异常与动作准入的分层展示。
