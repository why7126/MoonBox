# 产品经理可理解的沟通规格

## ADDED Requirements

### Requirement: 产品经理视角输出
Agent MUST 先说明业务结果和用户影响，优先日常语言，必要技术术语随文解释，决策说明体验、成本、时间和风险。

#### Scenario: 说明技术问题
- **WHEN** 向产品经理解释技术问题
- **THEN** 先说明用户可见现象，并解释必要术语及其影响

#### Scenario: 请求方案选择
- **WHEN** 需要用户选择方案
- **THEN** 说明体验、成本、时间和风险；未知值明确待确认，不编造估算
