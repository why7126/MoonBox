# 阻止 Issue 与迭代目录生成工具残留设计

## 现状与目标

仓库根目录 `.agents/skills/` 是唯一技能入口。现有目录校验只遍历仓库根目录，不能发现 `issues/` 和 `iterations/` 的直属隐藏工具目录。目标是在通用目录校验中识别这些残留，并安全清理当前四个空目录。

## 设计决策

- 只检查 `issues/` 与 `iterations/` 的直属 `.agents/`、`.codex/`，与本次可复核的问题范围一致；不会遍历每个 Issue 或 Sprint 历史目录。
- 使用 `exists()` 与 `is_symlink()` 同时识别目录和同名符号链接，空目录仍视为边界违例。
- 校验器只报错，不自动删除；本次清理由明确的空目录检查后执行 `rmdir`，非空目录保留供人工核查。
- 只对本次范围补规则和索引，不推断创建者或修改业务运行代码。

## 风险与回退

若后续工具仍尝试创建目录，校验会在完成门禁失败并暴露路径；需另查具体写入入口。回退校验变更不会恢复已清理的空目录，也不会影响业务数据。
