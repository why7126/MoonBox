# 阻止 Issue 与迭代目录生成工具残留

## 背景

`issues/` 与 `iterations/` 下出现空的 `.agents/`、`.codex/` 目录。现有目录校验只覆盖仓库根目录，未阻断这类治理事实源根目录中的工具残留。

## 变更内容

- 清理已确认为空的四个工具目录，不触碰 Issue 或 Sprint 事实文件。
- 将两个治理根目录的直属工具目录加入目录结构校验；即使目录为空也报错，不由校验器自动删除。
- 同步目录规则、Agent 入口和文档索引，并做正反向校验。

## 能力

### 修改现有能力

- `harness-runtime`：强化治理目录边界及验证。

## 影响

仅影响治理规则、目录校验脚本和文档；无 API、数据库、Web、管理端、客户端生成或 Docker Compose 变更。
