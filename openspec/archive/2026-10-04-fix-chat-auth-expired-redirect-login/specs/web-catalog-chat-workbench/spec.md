# Chat 工作台登录失效重定位规格增量

## MODIFIED Requirements

### Requirement: 个人工作台入口与权限

系统 MUST 提供 /chat 独立工作台，按本人、有效空间成员和对象权限过滤会话；保留既有需求中心抽屉，通过显式入口携带对象进入Chat，不自动执行输入。系统 MUST 在本地会话过期或受保护 Chat API 返回认证失败时清理前端会话并重定位到登录页，不继续展示需要鉴权的数据；系统 MUST 区分认证失败、权限不足、网络异常和服务端异常。

#### Scenario: 访问他人会话

- **WHEN** 用户猜测其他所有者或空间的会话标识
- **THEN** 系统拒绝读取消息、Diff或续写且不泄漏内容

#### Scenario: 从需求中心继续

- **WHEN** 用户点击在Chat工作台继续
- **THEN** 系统携带授权对象提示，保留旧抽屉语义，不迁移模拟消息或自动启动执行

#### Scenario: 登录失效后刷新 Chat 工作台

- **GIVEN** 用户本地仍保留前端会话且停留在 `/chat`
- **WHEN** Chat 工作台初始化或刷新时受保护 API 返回 401 认证失败
- **THEN** 系统清理前端会话并重定位到 `/login`
- **AND** 系统不得继续展示需要鉴权的会话、空间、项目、能力或消息数据
- **AND** 系统不得进入循环跳转或无限重试

#### Scenario: 本地会话已过期

- **GIVEN** 本地会话包含可判定的过期时间
- **WHEN** 用户直接访问 `/chat` 且会话已过期
- **THEN** 系统清理该会话并展示登录页
- **AND** 系统不得先渲染受保护工作台再依赖业务请求失败退出

#### Scenario: 权限不足不误判为登录失效

- **GIVEN** 用户仍处于有效登录态
- **WHEN** Chat 工作台请求因空间、仓库、会话或对象权限不足返回 403
- **THEN** 系统展示权限不足或访问受限提示
- **AND** 系统不得清理有效登录态或强制跳转登录页

#### Scenario: 网络异常和服务端异常不误登出

- **GIVEN** 用户仍处于有效登录态
- **WHEN** Chat 工作台请求发生浏览器网络异常或服务端 5xx
- **THEN** 系统展示可恢复错误或重试入口
- **AND** 系统不得清理有效登录态

#### Scenario: 重新登录后恢复授权范围内访问

- **WHEN** 用户因 Chat 工作台登录失效被重定位到 `/login` 并重新登录成功
- **THEN** 系统允许用户回到授权范围内的 Chat 工作台或默认前台入口
- **AND** 系统不得携带 Token、Cookie、Authorization header、完整请求体或完整响应体作为恢复参数
