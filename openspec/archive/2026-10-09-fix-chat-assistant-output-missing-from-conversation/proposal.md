# Chat 助手输出正文可读性修复提案

## 背景

来源：`issues/bugs/review/BUG-0030-chat-assistant-output-missing-from-conversation/bug.md`，已评审 high 缺陷，纳入 sprint-009。历史两轮有助手输出轨迹但无对话正文，分别为已停止和状态未知。原始数据已删除，历史根因不可验证。

本轮用户明确要求跳过 confirmed 校验直接生成 Change；此例外仅用于本次方案生成。根因保持 hypothesis，不声明实现或验收完成。

## 变更内容

- 让同轮次已经保存的助手文字在对话中可读，覆盖停止、未知及恢复轮次。
- 为消息缺失设计持久化及读取降级路径，维护消息、输出事件与终态的关联。
- 保留部分输出、截断和未知状态提示，过程文字不冒充最终答案，不自动重发治理命令。
- 确保重复恢复、分页和刷新不重复正文、不跨轮次串接，并保持会话访问权限。

## 能力影响

### 新增能力

无。

### 修改能力

- `web-catalog-chat-workbench`：扩展“对话与轨迹一致展示”的可读正文、恢复幂等与权限场景。

## 影响范围

预期涉及 Chat execution/reconcile、消息读取 API、Web 对话展示及聚焦测试。数据库表结构是否调整在设计验证后决定；优先复用现有消息与事件，不预设迁移。若响应字段变化，同步 OpenAPI、客户端和 API 文档。无新增部署服务或对象存储操作。

## 回滚方案

回退本 Change 代码及接口兼容改动，保留已保存消息与事件，不删除历史记录、不批量重放命令、不凭正文存在修改终态。若最终需要迁移，在实施前补齐兼容和回滚方案。
