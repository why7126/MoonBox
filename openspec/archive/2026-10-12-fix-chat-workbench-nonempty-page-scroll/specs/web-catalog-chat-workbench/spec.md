# Chat 非空白对话滚动边界规格

## ADDED Requirements

### Requirement: 消息角色标签与对话滚动边界

系统 MUST 将消息角色标签限制在所属消息卡片定位上下文内，保留可访问语义和视觉隐藏行为；非空白对话内容超出可视区域时 MUST 在消息区域内部滚动，不能因标签定位产生页面级额外滚动或破坏底部输入区布局。

#### Scenario: 长对话保持内部滚动
- **WHEN** 用户在桌面视口打开超出消息可视区的长对话并滚动至消息首尾
- **THEN** 页面滚动高度与可视高度差不超过 1 CSS px，页面 scrollTop 不因消息区滚动而变化，消息内容首尾可达

#### Scenario: 隐藏标签保留局部定位和语义
- **WHEN** 系统渲染用户与助手消息角色标签
- **THEN** 绝对定位标签的定位祖先为所属消息卡片，角色语义仍可由辅助技术读取且标签不视觉露出

#### Scenario: 会话切换与底部布局稳定
- **WHEN** 用户切换空白、短消息和长对话并操作输入区
- **THEN** 输入区可见可编辑，底部背景完整，悬浮元素无异常位移或遮挡，发送与显示能力正常
