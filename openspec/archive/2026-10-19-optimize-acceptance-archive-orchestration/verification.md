# 自动验收编排优化验证记录

## 覆盖与边界

本次只修改治理脚本、规范、技能、测试与 Change/Sprint。不修改业务 src、API、DB、UI、Orval、Docker Compose 或权限 profile。

| 范围 | 证据 |
|---|---|
| 连续执行、局部阻塞、依赖与采集状态 | test_acceptance_orchestration 的缺证、依赖、待采集与中断续接场景 |
| 精确指纹、历史兼容、去重 | 章节、下游失效、旧计划指纹和同组命令对照 |
| 环境、样本与浏览器 | 标准与技能契约、environment_contract 校验；未运行真实产品浏览器 |
| 状态规范与归档预演 | 技能契约反例、已有归档恢复回归、真实临时副本预演 |
| 指标 | 实测命令计数与时长、reported 活动聚合和原文拒绝测试 |

## 验证结果

聚焦50项回归通过。旧版与新版使用相同隔离夹具：单项缺证由0通过/3阻塞变为2通过/1阻塞；三项相同无副作用命令从执行3次降至1次，均3项通过。实测时长记录在 comparison.json，不推算真实产品全链路提速比例。

实际执行了本项目治理检查器与临时副本归档预演；合成用例不冒称已观察所有 Agent 自主取证行为。真实产品动作、浏览器交互、部署和模型执行耗时均不在本次治理验证范围。

## 已知非阻断事项

现有 Starlette 测试依赖弃用提示；目录检查存在旧 SQLite 路径迁移提示，未修改运行数据。用户授权的根目录冲突元数据原样转存至忽略的本地临时目录并验证哈希一致。其他既有变更保留。
