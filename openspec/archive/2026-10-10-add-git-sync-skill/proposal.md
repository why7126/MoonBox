# 建立安全的 Git 远程同步技能

## 背景

现有 `/git-check` 只负责推送前安全扫描，缺少从提交范围识别、暂存、提交、版本标签到远程同步的连续治理入口。工作区可能同时包含多条交付链路，直接全量暂存容易混入无关或敏感文件。

## 变更内容

- 新增 `/git-sync` 技能，以明确交付范围为默认，分阶段执行 Git 安全检查、选择性暂存、提交、可选版本标签和远程推送。
- 对不应入库的文件先分类处理：新增忽略规则、从索引移除已跟踪文件或排除本次暂存，并保留本地数据。
- 提交说明只依据暂存内容和可追溯的 REQ、BUG、Change、Sprint 事实；版本标签只依据正式发布记录。
- 同步 Agent 入口、上下文预算规则和 Git 安全规则。

## 能力

### 新增能力

- `git-sync-governance`：安全、可追溯地将指定交付范围提交并同步到远程仓库。

## 影响

仅影响 `.agents/skills/`、`AGENTS.md`、治理规则、OpenSpec Change 和治理日志；不涉及 API、数据库、Web、管理端、客户端生成或 Docker Compose。
