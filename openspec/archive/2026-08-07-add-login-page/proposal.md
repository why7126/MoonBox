## 背景与原因

MoonBox Landing v1.0.2 已完成首页与登录页混合原型设计，其中登录页部分需要沉淀为正式 Web Catalog 登录入口能力，确保首页 CTA、登录页状态、品牌呈现和用户名密码表单可以被实现、验收和追溯。

当前 `openspec/specs/` 尚无官网登录页能力规格；本 Change 将 `REQ-0002-login-page` 中已评审并纳入 `sprint-001` 的登录页需求转为新增规格。

## 变更内容

- 新增 MoonBox Web 登录页能力，覆盖首页进入登录页、`#login` 页面状态、返回首页、登录页品牌 Logo、背景遮罩和用户名密码表单。
- 登录表单包含用户名、密码、记住我和登录按钮；用户名与密码必填。
- 登录页不展示忘记密码、申请体验、注册、第三方登录、邮箱验证码或手机号验证码。
- 当前登录页只实现前端原型与必填校验，不连接真实后端鉴权，不签发 Token，不改变真实会话状态。
- 登录页视觉复用首页产品视觉背景，并使用深色遮罩保证表单可读性。

## 能力影响

### 新增能力

- `web-catalog-login-page`: MoonBox Web 官网登录页入口、页面状态、返回首页、品牌视觉和用户名密码表单前端体验。

### 修改能力

- 无。

## 影响范围

- `web`: 需要在 Web 前端实现或对齐登录页视图、`#login` 状态、返回首页行为、Logo/背景资产引用、表单字段和响应式展示。
- `admin`: 无影响。
- `backend`: 无影响。
- `api`: 无接口变更。
- `database`: 无数据结构变更。
- `storage`: 无对象存储边界变更。
- `miniapp`: 无影响。
