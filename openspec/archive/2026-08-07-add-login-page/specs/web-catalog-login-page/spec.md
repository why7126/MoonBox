## ADDED Requirements

### Requirement: 登录页入口与页面状态
系统 MUST 提供 Web 登录页入口，使首页登录相关 CTA 能进入同一个登录页，并通过 `#login` 或等价前端状态表达登录页当前状态。

#### Scenario: 首页 CTA 进入登录页
- **WHEN** 访客在官网首页点击登录相关 CTA
- **THEN** 系统显示 Web 登录页
- **AND** 首页主体内容不再作为当前主交互界面展示

#### Scenario: 直接访问登录页状态
- **WHEN** 访客直接打开带 `#login` 或等价登录状态的地址
- **THEN** 系统显示 Web 登录页
- **AND** 用户名输入框可成为首个可填写字段

### Requirement: 登录页返回首页
系统 MUST 在登录页提供返回首页入口，并在返回时恢复首页视图、清除登录页状态。

#### Scenario: 用户从登录页返回首页
- **WHEN** 用户点击登录页左上角的返回首页入口
- **THEN** 系统恢复官网首页视图
- **AND** 系统清除 `#login` 或等价登录页状态
- **AND** 登录页表单、遮罩和登录卡片不再作为当前主交互界面展示

### Requirement: 登录页品牌与背景视觉
系统 MUST 在登录页展示 MoonBox 品牌 Logo，并复用首页产品视觉作为背景，通过深色遮罩保证表单可读性。

#### Scenario: 登录页展示品牌 Logo
- **WHEN** 用户打开 Web 登录页
- **THEN** 登录卡片顶部展示 MoonBox 产品 Logo
- **AND** Logo 不是旧 Logo、占位图或纯文本替代

#### Scenario: 登录页背景保持可读
- **WHEN** 用户在桌面端或移动端查看登录页
- **THEN** 登录页背景展示首页产品视觉
- **AND** 背景叠加深色遮罩或等价视觉处理
- **AND** 登录表单、按钮和辅助文本清晰可读

### Requirement: 用户名密码登录表单
系统 MUST 在登录页提供用户名、密码、记住我和登录按钮，并对用户名与密码执行必填校验。

#### Scenario: 用户查看登录表单
- **WHEN** 用户打开 Web 登录页
- **THEN** 页面展示用户名输入框
- **AND** 页面展示密码输入框
- **AND** 页面展示记住我控件
- **AND** 页面展示登录按钮

#### Scenario: 必填校验阻止空提交
- **WHEN** 用户未填写用户名或密码并提交登录表单
- **THEN** 系统阻止提交
- **AND** 系统展示浏览器原生或字段级必填提示

#### Scenario: 密码默认隐藏明文
- **WHEN** 用户在密码输入框输入内容
- **THEN** 系统默认以密码类型展示输入内容
- **AND** 页面不直接显示密码明文

### Requirement: 登录页原型提交边界
系统 MUST 将当前登录页提交限制为前端原型行为，不得发起真实认证请求或改变真实会话状态。

#### Scenario: 提交不连接真实鉴权
- **WHEN** 用户在当前原型范围内提交登录表单
- **THEN** 系统不发起真实后端鉴权请求
- **AND** 系统不生成 Token
- **AND** 系统不改变真实会话状态

### Requirement: 登录页信息收敛
系统 MUST 避免展示未纳入本需求的认证或账号流程入口。

#### Scenario: 未支持入口不展示
- **WHEN** 用户打开 Web 登录页
- **THEN** 页面不展示忘记密码入口
- **AND** 页面不展示申请体验入口
- **AND** 页面不展示注册入口
- **AND** 页面不展示第三方登录、邮箱验证码或手机号验证码入口

### Requirement: 登录页响应式与视觉约束
系统 MUST 保证登录页在桌面端和移动端均不出现关键内容溢出、遮挡或非 MoonBox 视觉语言。

#### Scenario: 桌面端登录卡片居中展示
- **WHEN** 用户在桌面端打开 Web 登录页
- **THEN** 登录卡片居中展示
- **AND** 背景产品视觉可见但不干扰表单阅读

#### Scenario: 移动端不溢出不遮挡
- **WHEN** 用户在移动端打开 Web 登录页
- **THEN** 登录卡片、输入框、按钮和返回入口不横向溢出
- **AND** 关键文案不互相遮挡

#### Scenario: 登录页符合 MoonBox UI 规则
- **WHEN** 登录页展示给用户
- **THEN** 页面使用深色 MoonBox 主题
- **AND** 主按钮使用金色强调
- **AND** 登录卡片使用近直角和细线边框
- **AND** 页面不引入蓝紫科技渐变、大圆角卡片或厚重阴影
