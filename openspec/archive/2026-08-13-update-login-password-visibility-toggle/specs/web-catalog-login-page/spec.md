## MODIFIED Requirements

### Requirement: 用户名密码登录表单
系统 MUST 在登录页提供用户名、密码、记住我和登录按钮，对用户名与密码执行必填校验，并允许用户主动切换密码输入框的显示/隐藏状态。

#### Scenario: 用户查看登录表单
- **WHEN** 用户打开 Web 登录页
- **THEN** 页面展示用户名输入框
- **AND** 页面展示密码输入框
- **AND** 页面展示记住我控件
- **AND** 页面展示登录按钮

#### Scenario: 必填校验阻止空提交
- **WHEN** 用户未填写用户名或密码并提交登录表单
- **THEN** 系统阻止提交
- **AND** 系统展示浏览器原生或字段级必填提示

#### Scenario: 密码默认隐藏明文
- **WHEN** 用户打开 Web 登录页
- **THEN** 密码输入框默认使用密码类型展示
- **AND** 页面不直接显示密码明文

#### Scenario: 用户显示密码
- **WHEN** 用户在密码隐藏状态触发“显示密码”控件
- **THEN** 系统将密码输入框切换为明文展示状态
- **AND** 系统不清空、不重置、不改写密码输入值
- **AND** 系统不提交登录表单
- **AND** 系统不调用登录接口

#### Scenario: 用户隐藏密码
- **WHEN** 用户在密码显示状态触发“隐藏密码”控件
- **THEN** 系统将密码输入框恢复为密码隐藏状态
- **AND** 系统保留当前密码输入值
- **AND** 系统不提交登录表单
- **AND** 系统不调用登录接口

#### Scenario: 密码显隐控件支持无障碍操作
- **WHEN** 用户使用键盘或辅助技术访问密码显隐控件
- **THEN** 控件可被键盘聚焦并通过 Enter 或 Space 触发
- **AND** 控件提供当前动作的可读标签
- **AND** 控件通过 `aria-pressed` 或等价语义表达当前显隐状态

#### Scenario: 密码显隐不泄露敏感信息
- **WHEN** 用户主动显示密码
- **THEN** 密码明文只存在于当前输入框可视状态
- **AND** 系统不得将密码写入 URL、日志、错误上报、埋点、本地存储、测试输出或其他持久化位置

### Requirement: 登录页响应式与视觉约束
系统 MUST 保证登录页在桌面端和移动端均不出现关键内容溢出、遮挡或非 MoonBox 视觉语言，并保证密码显隐控件不破坏登录页布局。

#### Scenario: 桌面端登录卡片居中展示
- **WHEN** 用户在桌面端打开 Web 登录页
- **THEN** 登录卡片居中展示
- **AND** 背景产品视觉可见但不干扰表单阅读

#### Scenario: 移动端不溢出不遮挡
- **WHEN** 用户在移动端打开 Web 登录页
- **THEN** 登录卡片、输入框、按钮和返回入口不横向溢出
- **AND** 关键文案不互相遮挡
- **AND** 密码显隐控件不超出登录卡片边界
- **AND** 密码显隐控件不遮挡密码输入内容或登录按钮

#### Scenario: 登录页符合 MoonBox UI 规则
- **WHEN** 登录页展示给用户
- **THEN** 页面使用深色 MoonBox 主题
- **AND** 主按钮使用金色强调
- **AND** 登录卡片使用近直角和细线边框
- **AND** 页面不引入蓝紫科技渐变、大圆角卡片或厚重阴影

#### Scenario: 密码字段显隐控件布局稳定
- **WHEN** 用户在登录页输入密码并切换显示/隐藏状态
- **THEN** 密码输入框右侧预留足够空间容纳显隐控件
- **AND** 显隐控件与输入框垂直居中或等价对齐
- **AND** 登录卡片高度、字段间距、记住我、登录按钮和错误反馈区域不发生不必要抖动
