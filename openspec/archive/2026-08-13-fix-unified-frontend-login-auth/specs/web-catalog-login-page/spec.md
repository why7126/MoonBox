# web-catalog-login-page Delta

## MODIFIED Requirements

### Requirement: 用户名密码登录表单

系统 MUST 在登录页提供统一用户名密码登录表单，使前台用户、后台管理员和超级管理员均从同一入口登录，并在登录成功后默认进入前台。

#### Scenario: 普通前台用户登录成功

- **GIVEN** 用户角色为前台用户
- **AND** 用户状态为正常
- **WHEN** 用户在 `/login` 提交正确用户名和密码
- **THEN** 系统创建可服务端校验的统一登录态
- **AND** 系统默认进入前台需求中心
- **AND** 用户菜单不展示“进入后台”入口

#### Scenario: 待激活用户首次登录自动激活

- **GIVEN** 用户角色为前台用户或后台管理员
- **AND** 用户状态为待激活
- **WHEN** 用户在 `/login` 提交正确用户名和密码
- **THEN** 系统允许登录
- **AND** 系统将用户状态更新为正常
- **AND** 系统默认进入前台需求中心

#### Scenario: 后台角色登录后展示后台入口

- **GIVEN** 用户具备后台管理员角色或为系统超级管理员
- **AND** 用户状态为正常或待激活
- **WHEN** 用户在 `/login` 登录成功
- **THEN** 系统默认进入前台需求中心
- **AND** 用户菜单展示“进入后台”入口

#### Scenario: 冻结删除与凭证错误登录失败

- **WHEN** 用户状态为已冻结或已删除，或提交不存在账号/错误密码
- **THEN** 系统拒绝登录
- **AND** 系统不得创建有效服务端会话
- **AND** 系统不得写入有效前端登录态
- **AND** 错误提示不得暴露内部权限实现细节

### Requirement: 登录页原型提交边界

系统 MUST 将登录页提交接入正式统一登录能力；登录页不得继续停留在纯前端原型提交边界。

#### Scenario: 提交连接统一鉴权

- **WHEN** 用户在 `/login` 提交用户名和密码
- **THEN** 系统调用后端统一登录能力或等价认证入口
- **AND** 登录成功后建立服务端可校验、可过期、可撤销的登录态
- **AND** 登录失败时展示受控认证失败提示

## ADDED Requirements

### Requirement: 前台接口统一登录态

系统 MUST 允许已登录的前台用户访问前台业务接口，并避免将前台接口绑定到后台管理员角色。

#### Scenario: 普通前台用户访问需求中心上下文

- **GIVEN** 普通前台用户已登录
- **WHEN** 用户访问需求中心前台上下文接口
- **THEN** 系统接受统一登录态
- **AND** 系统返回该用户可访问的前台上下文
- **AND** 系统不得要求用户具备后台管理员角色
