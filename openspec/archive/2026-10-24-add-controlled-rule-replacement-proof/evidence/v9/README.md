# 第九轮隔离归档诊断

此目录记录一次性隔离项目的真实产品归档入口结果。`direct-archive/first-attempt.json` 与 `direct-archive/result.json` 分别对应两次经单独授权的调用；两次均返回 409，活动 Change 保持原位，已归档目录数为 0，生效规格未增加样本规则。没有产生归档操作记录或恢复记录。

第二次调用前，只读核对了验收准入、证据绑定、交付文件摘要、五项静态校验及归档预演，均通过。调用仍返回通用 `archive_command_unverified`，当前证据不足以确定内部失败点。因此该样本只能证明失败时未错误归档，不能证明归档成功、恢复或异常分支的完整体验，也不能据此放行对应验收项。

样本仅使用隔离项目与测试数据，不涉及正式项目。隔离服务和环境文件在取证后清理。
