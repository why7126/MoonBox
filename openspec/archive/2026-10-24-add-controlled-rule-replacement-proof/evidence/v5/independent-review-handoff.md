# 规则修改轻量方案独立验收核对单

## 已提供的测试材料

- `live-isolated-api.json`：当前源代码构建与一次性隔离项目的真实接口操作。相同标题的规则修改可以读取原文和修改后内容；验收未完成时仍阻断归档。旧确认入口返回拒绝且没有新增确认记录。内容变化会改变检查标识，历史链断裂会拒绝读取，恢复后回到原结果。
- `live-chat-execution-unavailable.png`：同一隔离产品的 Chat 工作台。项目连接成功，但执行服务未配置，因此无法通过 Chat 发送归档命令或呈现命令失败后的上下文入口。这张图仅证明环境限制，不计入抽屉视觉验收。
- `archived-bug-independent-status.json`：BUG-0063 已归档、REQ-0050 尚在验收中的独立状态核对。

## 请独立验收人员核对

请在其负责且有权限的项目中，使用**当前版本**和一条**尚未归档的规则修改对象**，逐项确认：

1. 对象出现规则修改阻断时，点击“查看修改”可看到原规则、修改后、修改理由、仍禁止的情形和受影响验收；输入框没有常驻“确认规则修改”入口。
2. “重新检查归档”不会发送 Chat 命令或直接归档；未签署、无权限、证据缺失、历史断链或检查后内容变化时仍被阻断。
3. 关闭抽屉、按 Esc、加载失败后，原会话草稿和已成功上传的附件保留；桌面与窄屏、深浅主题显示可读。
4. 独立签署仅针对实际负责的验收项；不要代替其他人员签署，也不要使用已归档 BUG-0063 作为新的待归档候选。

请把验收人员身份、负责项目或对象、签署结果和可复核的脱敏证据交回本 Change 的验收流程。没有这些事实时，AC-L05、AC-L06、AC-L09、AC-L10 等项继续保持待验收；不以本隔离环境的 API 检查替代签署或真实 Chat 操作。
