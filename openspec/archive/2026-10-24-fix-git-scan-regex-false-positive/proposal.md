# Git 安全扫描误报修复

## 背景

git-sync 被路径过滤正则与虚构测试夹具误报阻断。用户明确要求修复并继续提交。

## 变更内容

路径识别排除用户名位置的正则分隔符，测试夹具使用已有显式占位符约定；保留真实路径拦截。清理两处末尾空行并复核现有隐私警告。

## 能力影响

新增 git-scan-path-precision 治理能力说明。

## 影响范围

仅治理扫描器、回归测试与格式；不修改 API、数据库、UI、部署或权限。
