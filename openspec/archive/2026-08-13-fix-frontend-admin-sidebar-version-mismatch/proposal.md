# 修复前台与后台侧边栏版本号不一致

## 修复原因

来源缺陷：`BUG-0009-frontend-admin-sidebar-version-mismatch`。

MoonBox 前台需求中心侧边栏展示 `v0.1.0`，管理后台用户管理页侧边栏展示 `v1.0.5`。前台已经使用共享版本常量，后台用户管理页仍保留原型补丁版本号硬编码，导致用户在前台与后台之间切换时误判发布版本或部署状态。

## 修复内容

- 管理后台用户管理页侧边栏复用共享产品版本事实源。
- 移除后台侧边栏独立硬编码 `v1.0.5`。
- 补充后台用户管理页版本展示回归测试。
- 保持前台需求中心侧边栏版本展示不回归。
- 明确本修复不涉及后端 API、数据库、权限、部署拓扑或客户端生成。

## 非目标

- 不改变产品真实版本号。
- 不新增版本管理 API、运行时版本接口或发布治理能力。
- 不调整后台用户管理业务能力、权限、列表、弹窗、头像上传或账号状态操作。
- 不调整前台需求中心看板、空间切换、用户菜单或认证行为。

## 回滚方案

如修复引入前端构建或后台侧边栏渲染回归，回滚后台侧边栏版本展示改动和对应测试即可恢复旧行为。回滚后 `BUG-0009` 风险仍存在，不得在未替代修复前归档该 BUG。
