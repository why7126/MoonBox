## 背景与原因

MoonBox 已进入多空间、多产品协作与资源治理阶段，但后台目前缺少空间全生命周期管理入口。平台运营团队需要统一管理空间创建、审批、产品绑定、配额、冻结恢复、回收、永久删除和审计，降低空间、产品、负责人和资源用量之间的数据不一致风险。

## 变更内容

- 新增后台空间管理能力，包含空间列表、申请审批、回收站和空间详情。
- 新增空间与产品一对一强绑定规则：创建空间时同步创建同名产品，空间改名时同步产品名，不支持解绑或迁移。
- 新增空间生命周期治理：正常、冻结、回收中、永久删除，并支持冻结、恢复、续期、删除、恢复回收和超级管理员永久删除。
- 新增空间配额与用量治理：成员数、存储量、AI Token/模型调用量，80% 预警，100% 限制新增或继续消耗对应资源。
- 新增后台空间申请审批：后台管理员核定负责人、有效期和配额，通过后创建空间与同名产品，拒绝必须填写原因。
- 新增通知与审计要求，覆盖申请、配额、到期、冻结恢复、负责人变更、回收和永久删除。
- 新增后台 UI 原型驱动实现门禁，承接 `admin-list`、`admin-modal` 和 prototype-driven UI Gate。

## 能力影响

### 新增能力

- `web-admin-space-management`: 定义后台空间管理能力，包括空间列表、申请审批、回收站、详情、空间产品绑定、配额生命周期、通知审计和后台 UI 横切验收。

### 变更能力

- `web-admin-crud-list-template`: 复用既有后台 CRUD 列表页模板和弹窗治理要求，不新增规范级修改。
- `web-admin-user-management`: 作为后台列表、分页、弹窗、toast 和审计体验参照，不新增规范级修改。

## 影响范围

- Backend/API：新增后台空间、空间申请、空间操作、配额、审计相关 API 和服务逻辑。
- Database：新增或扩展空间、产品绑定、空间成员、空间申请、配额用量、空间审计、生命周期状态相关数据结构和迁移。
- Web Admin：新增空间管理导航入口、列表页、申请审批页、回收站、空间详情页和多类高风险弹窗。
- Security：新增后台权限校验、状态约束、幂等保护、二次确认、原因填写和高风险审计。
- Documentation/Testing：同步 API、DB、UI、测试和知识库横切验收；实现阶段不得写入真实密钥、真实客户数据或本机绝对路径。
