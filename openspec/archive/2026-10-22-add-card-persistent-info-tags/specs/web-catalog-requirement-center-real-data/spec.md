# 卡片根因与人天真实数据增量规格

## ADDED Requirements

### Requirement: 单卡预估人天投影
系统 MUST 使用授权项目内对象有效Sprint归属的scope_estimates估算，支持已归档源；不得用总容量、优先级或story_points替代。

#### Scenario: 总量分项与异常值
- **WHEN** 存在Issue总量、关联Change分项或重复记录
- **THEN** 唯一总量优先且同行不重复计数，完全相同记录去重；只有完整唯一分项可以求和，冲突或缺失不得猜测
- **AND** 仅有限非负数有效，0和小数展示，字符串、布尔、负数和非有限数不输出数值

### Requirement: 根因内容与状态兼容投影
系统 MUST 在有效分析或证据正文存在时读取root_cause_status，兼容合法根因status和缺失时的根因状态章节；不把普通文档生命周期当根因确认。

#### Scenario: 冲突及模板
- **WHEN** 多个明确声明冲突、专用字段非法或正文只是空模板
- **THEN** 有效正文存在的冲突显示待确认，空模板不显示根因标签
- **AND** 仅一致confirmed显示已确认，unknown/hypothesis/probable为待确认

### Requirement: 标签数据隔离与读取效率
系统 MUST 在同一授权快照聚合元数据，复用文档权限与请求观测，不通过前端逐卡下载根因全文。

#### Scenario: 更新与撤权
- **WHEN** 项目切换、源文件同尺寸修改、删除、权限撤销或请求失败
- **THEN** 不串项目、不继续暴露越权正文、不把旧值冒充当前事实或填零，并保留可诊断状态
- **AND** 行为采集失败不阻断文档读取，日志不记录根因正文或敏感路径
