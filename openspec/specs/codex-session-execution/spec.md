# codex-session-execution Specification

## Purpose
规定 Codex 会话在 MoonBox 内的线程映射、隔离工作区、真实执行互斥、权限快照、可信计量、额度释放、删除保留与治理写入边界，确保 Chat 执行链路可恢复、可审计且不绕过 OpenSpec 与 Sprint 管理。
## Requirements
### Requirement: 会话映射与工作区

系统 MUST 显式绑定Codex线程、空间仓库和工作区身份，并跨轮复用；只允许预配置授权仓库。每仓库唯一主工作区为默认入口，独立开发Git worktree按交付链路按需创建，多会话可共享同一工作区；活动轮次固定身份与版本，目录缺失不得自动回退。

#### Scenario: 恢复会话

- **WHEN** 服务恢复或用户切换回来
- **THEN** 验证线程标识与工作目录一致，不选择最近线程

#### Scenario: 首次启动失败

- **WHEN** 未取得执行端标识即失败
- **THEN** 保留未连接MoonBox会话，不宣称恢复成功

### Requirement: 原子发送与运行互斥

系统 MUST 保持会话作用域幂等，并以工作区写锁限制共享目录同时只有一个写任务；等待、连接、停止中和未知也禁止该工作区新写入。不同交付链路的不同工作区可按容量并行，共享治理/Git集成另以仓库操作锁串行。

#### Scenario: 重复请求

- **WHEN** 同请求从多个标签页或网络重发到达
- **THEN** 返回同轮次且只有一个有效执行

#### Scenario: 重启后未知

- **WHEN** 旧worker租约失效但运行终态未知
- **THEN** 保持禁止新写入，确认原进程终止后才释放

### Requirement: 快照权限与撤权隔离

系统 MUST 保存每轮实际引用版本或受控内容快照并重验权限；不得使已撤权内容通过旧线程历史、回复或Diff继续泄漏。

#### Scenario: 对象撤权

- **WHEN** 旧线程包含用户已无权访问的对象内容
- **THEN** 限制对应历史及继续执行；不能安全清理上下文时引导新建干净会话

### Requirement: 事件持久化与可信差异
系统 MUST 保留事件归属、原标识和本地序列，持续分块提交并去重，使用可信前后快照区分本轮和累计Diff；禁止以内存全量汇总作为持久化前提。只有提交完成的段可报告已保存。

#### Scenario: 两轮修改同文件
- **WHEN** 第二轮调整第一轮已修改文件
- **THEN** 本轮差异只反映第二轮且保留累计基准，全文与差异可按需读取

#### Scenario: 事件重放
- **WHEN** 终态后收到重复或较早事件
- **THEN** 依据可信来源标识与偏移去重，不重复消息或把终态回退；缺乏重放依据时标明未知缺口

#### Scenario: 保存中断
- **WHEN** worker在块写入或段提交时退出
- **THEN** 重启仅公开已提交段，校验未发布块并显示未确认尾段，重复恢复不重复计量

### Requirement: 中止确认与断连恢复

系统 MUST 区分停止请求和停止完成；断连查询原执行，只有明确终止后允许用户显式重试。

#### Scenario: 中止超时

- **WHEN** 停止请求发出后无法确认结束
- **THEN** 进入未知并禁止再次写入，保留已有修改

#### Scenario: 明确重试

- **WHEN** 旧轮次已失败或已停止且用户发起重试
- **THEN** 创建关联原轮次的新轮次，重验原快照权限，不自动重跑或回滚

### Requirement: 平台额度与结果空间
系统 MUST 使用服务端认证与用户空间可信计量；本次单机部署仍使用部署者 Codex 认证，费用及上游额度由该账号承担，不向前端或仓库脚本暴露凭证。用户／空间月度Token及累计Chat存储缺省无限，支持显式有限运营策略且升级保留；不设单轮Token预算，不以结果累计字节设固定业务上限。解析、队列与容器仅保留部署级资源保护。

#### Scenario: 未配置限额
- **WHEN** 月度Token或累计Chat存储运营配置未提供
- **THEN** 默认为无限并记录用量，必要认证、仓库或存储配置缺失仍返回未就绪，非法配额报错而非无限

#### Scenario: 显式不设运营上限
- **WHEN** 用户／空间策略为unlimited
- **THEN** 不按相应运营总量阻断；既有有效并发策略、同会话互斥及未知态继续生效，部署处理能力不足时受控排队

#### Scenario: 终态已确认但用量尚未核实
- **WHEN** 收到可信终态而无可信Token用量
- **THEN** 幂等释放该轮并发占用，Token保持未知，实际已提交存储按账本计量，迟到结算不重复释放或累计；未知执行仍占用互斥

#### Scenario: 结果超过预留
- **WHEN** 累计结果超过旧单轮预留或固定快照总量
- **THEN** 不据此中止，按有界批次继续保存；只有显式有效存储运营配额或真实资源保护触发才安全停止并保留已提交结果

#### Scenario: 升级有限策略与废弃预算
- **WHEN** 升级含已有有限月度或存储配置及旧单轮预算
- **THEN** 保留有限运营策略，旧单轮字段仅兼容诊断不限制新轮次，排空或核验旧活动轮次后切换

### Requirement: 主动删除与独立保留

系统 MUST 保留聊天快照和Diff至主动删除，不自动按90/180天清理；删除只在运行终止且无未处理变更时允许，代码和审计独立。

#### Scenario: 请求删除

- **WHEN** 会话没有活动或未知执行且没有未处理变更
- **THEN** 二次确认后按主存储、备份和执行端副本策略清理，不删除代码和应保留审计

#### Scenario: 副本无固定删除期限

- **WHEN** 执行副本和备份期限显式配置为 unlimited
- **THEN** 不自动过期，不伪造截止时间；主动删除仍清理主存储、记录独立删除日志并跟踪副本，备份未物理清除前保持待清理，恢复前重放删除避免内容复活

#### Scenario: 仅有历史Diff

- **WHEN** 历史曾修改但当前变更已处理
- **THEN** 不因历史文件计数永久禁止删除

### Requirement: 治理写入与执行安全

系统 MUST 在执行端限制目录、网络、凭证及正式功能治理写入；不默认授权提交合并推送部署，严格只读不能只靠提示词。

#### Scenario: 无治理授权写入

- **WHEN** 用户对无合规Change的正式功能提出开发请求
- **THEN** 允许讨论但拒绝正式功能写入，不因Chat入口绕过审批与Sprint

#### Scenario: 执行环境隔离不足

- **WHEN** 不能验证跨会话资源或凭证隔离
- **THEN** 禁用并发或真实执行，不将worktree当完整隔离

### Requirement: 观测与双数据库兼容

系统 MUST 关联行为、可信请求和执行链路，过滤敏感正文，采集失败不阻断主流程；SQLite/MySQL验证迁移、互斥与保留语义。

#### Scenario: 采集失败

- **WHEN** 事件或日志持久化失败但主请求仍可执行
- **THEN** 主流程继续且保留脱敏降级摘要，不记录完整Prompt或密钥

#### Scenario: 数据库切换

- **WHEN** 同一并发和清理测试运行在SQLite与MySQL
- **THEN** 幂等、授权、运行互斥和删除语义一致

### Requirement: 有界工具详情
系统 MUST 在既有个人事件流中保存白名单工具详情，记录前脱敏并限制大小，保持原标识去重与Worker隔离；缺失字段不推算。完整协议与凭证配置不得进入详情或通用审计。

#### Scenario: 工具输出含凭证
- **WHEN** 命令或输出含凭证形态字段或本机路径
- **THEN** 持久化前替换敏感内容，长输出标注截断，事件大小不超过既有页面边界

### Requirement: 执行配置快照与生效追溯

系统 SHALL 在 Codex 会话每轮执行中保存请求执行配置和实际生效执行配置。请求配置 SHALL 包含 Agent、模型和推理配置稳定标识；实际生效配置 SHALL 反映服务端校验、执行端能力、额度、权限或降级策略后的结果。配置快照 SHALL 与轮次绑定，不得被后续会话选择覆盖。

#### Scenario: 请求配置与实际配置一致

- **WHEN** 用户选择的 Agent、模型和推理配置均可用并通过后端校验
- **THEN** 该轮执行记录保存请求配置和相同的实际生效配置
- **AND** 历史轮次详情可以追溯这些脱敏配置标识

#### Scenario: 请求配置被拒绝

- **WHEN** 用户提交无权、不可用或执行端不支持的配置且不能降级
- **THEN** 系统拒绝创建新的有效执行轮次或将轮次标记为受控失败
- **AND** 返回文档化错误码，不泄漏内部配置全文、凭证、本机路径或用户输入正文

#### Scenario: 请求配置被降级

- **WHEN** 服务端策略允许将请求配置降级到可用配置
- **THEN** 该轮执行记录保存请求配置、实际生效配置和脱敏降级原因摘要
- **AND** 页面和 Task Trace 均以实际生效配置解释本轮执行

### Requirement: 配置观测与运行互斥

系统 SHALL 将执行配置选择纳入行为事件、请求日志、Task Trace 和流程节点的脱敏观测。系统 SHALL 保持既有同会话运行互斥，运行中、停止中和未知状态不得通过配置切换影响当前执行。

#### Scenario: 配置选择观测

- **WHEN** 用户更改模型或推理配置并发送消息
- **THEN** 行为事件和请求日志只记录事件名、结果、脱敏配置标识、状态码、错误码和耗时
- **AND** 不记录完整 Prompt、完整回复、完整 Diff、Authorization、Cookie、Token、密钥、本机绝对路径或内部配置全文

#### Scenario: Task Trace 节点记录实际配置

- **WHEN** Codex 执行链路创建 Task Trace 或流程节点
- **THEN** metadata 记录实际生效 Agent、模型、推理配置摘要和降级节点
- **AND** metadata 不包含用户输入正文、完整模型输出或敏感凭证

#### Scenario: 运行中切换不影响当前轮次

- **WHEN** 同会话已有执行处于运行中、停止中或未知状态
- **THEN** 配置切换不得改变已经发出的执行
- **AND** 若 UI 允许预设下一轮配置，后端仍需在下一轮发送时重新校验

### Requirement: 实现授权治理字段归一化

系统 MUST 从服务端可信治理文件归一化来源与 Sprint：BUG 支持 bug、bug_id、source_bug、related_bug，REQ 支持 requirement、requirement_id、req_id、source_requirement，Sprint 支持 sprint、iteration。系统 MUST 校验多字段一致性、合法类型、主对象匹配、成员权限、Issue in_sprint、活动 Change proposed/in_progress 及 Sprint 双向包含；不因字段兼容放开其他阶段或直接 Change 主对象授权。

#### Scenario: 已纳入迭代的缺陷使用别名字段
- **WHEN** 满足全部授权门禁的 BUG Change 使用 bug_id 与 iteration
- **THEN** 实现任务获得 implementation_write 并映射 moonbox-write，不因别名回退治理权限

#### Scenario: 需求来源字段兼容
- **WHEN** 已满足实现门禁的 REQ 使用一致的来源与 Sprint 别名
- **THEN** 获得与规范字段相同的实现权限

#### Scenario: 冲突或缺失事实
- **WHEN** 同义字段冲突、类型非法、来源不匹配或 Sprint 未同时包含 Issue 和 Change
- **THEN** 不授予源码实现权限，并保留可辨识的安全诊断原因

#### Scenario: 其他权限边界保持
- **WHEN** 用户无写权限、处于治理候选、Change 已 applied/archived 或执行中撤权
- **THEN** 继续遵守相应拒绝、治理只写或停止执行规则，不因兼容解析扩权

### Requirement: 同轮次权限决策与实际执行配置留痕

系统 MUST 关联同一 turn 的服务端 scope、reason_code、时间、治理输入版本摘要和执行器实际选用 profile，区分计划配置与已核验启动结果；记录 MUST 脱敏，不存原始会话、凭证或完整治理文件。系统 MUST 不以当前重建值冒充历史日志，不以 UI 标签或会话 completed 代替实现成功。

#### Scenario: 原缺陷场景修复后执行
- **WHEN** 测试环境用原 BUG-0029 字段形态启动合法实现任务
- **THEN** 可核验该 turn 的实现决策、moonbox-write、实际源码写入及一致的治理输入版本摘要

#### Scenario: 配置不一致或观测不可用
- **WHEN** profile 与授权不符，或观测写入失败
- **THEN** 配置不符时阻断启动；观测失败明确记录降级且不扩权，不声称取得缺失证据

### Requirement: 未知轮次有界恢复

系统 MUST 持久化每轮次恢复次数、首尝试时间、下次时间、结果与独立恢复状态，默认最多6次、30分钟，失败等待30/60/120/240/300秒并附加最多10%正向抖动，先触及预算即暂停。暂停 MUST 保留原unknown及写入、并发、账务保护，禁止重放业务命令。

#### Scenario: 永久没有权威终态
- **WHEN** 读取一直缺少终态或发生可重试错误并触及预算
- **THEN** 恢复暂停且跨至少330秒不再为该轮次创建恢复容器，业务仍为unknown

#### Scenario: 瞬态故障后恢复
- **WHEN** 下次时间已到且预算有效，读取到completed、failed或interrupted
- **THEN** 按既有权威映射提交终态并收敛保护和账务；下次时间之前不启动读取

### Requirement: 恢复租约与公平调度

系统 MUST 原子领取到期恢复并持久化租约与预算，单轮次至多一个有效恢复且创建前确认旧恢复容器已退出。恢复 MUST 使用独立有界槽，正常任务优先，资源可用时正常领取延迟在隔离验收中不超过5秒。

#### Scenario: 重启和竞争领取
- **WHEN** 多个worker竞争或租约持有者异常退出后重启
- **THEN** 保留已消费预算与暂停态，过期租约可续接，旧token不能提交，不能形成重复容器风暴

#### Scenario: 多轮次与新任务并存
- **WHEN** 多条unknown持续等待且有新任务到达
- **THEN** 各自按到期时间公平调度且新任务不等待恢复Docker调用

### Requirement: 恢复暂停受控续接

系统 MUST 通过受控运维入口核验操作身份、原执行身份、预期代次与幂等请求，显式续接才创建新预算代次并保留历史摘要。后台扫描、重启或轮询 MUST NOT 自动重置预算。

#### Scenario: 重复或无权续接
- **WHEN** 同一续接请求重复、代次过期或操作者无权限
- **THEN** 重复请求不增加预算，过期或无权请求拒绝，原业务事实与保护保持

### Requirement: 恢复预检安全复用

系统 MUST 仅复用5分钟内且镜像内容、策略、工作区身份、配置及认证版本一致的成功预检，每次保持实际权限与工作区检查；失败不得缓存为成功。无变化跳过昂贵读取 MUST 仍消耗检查预算并退避。

#### Scenario: 身份变化或缓存过期
- **WHEN** 任一缓存身份变化、不可确认或有效期结束
- **THEN** 重新执行预检；安全或身份拒绝立即暂停，不启动实际读取

### Requirement: 恢复观测与资源收尾

系统 MUST 记录脱敏恢复分类、次数、下次时间、暂停原因、缓存命中及实际容器计数，观测失败降级不阻断状态提交；成功、失败、取消和超时均回收本次容器，保持共享服务、卷和宿主数据。

#### Scenario: 错误分类与清理
- **WHEN** RPC拒绝、记录缺失、无终态、身份错误或超时发生
- **THEN** 可区分原因并核对容器创建和回收，不泄露凭据、正文及真实路径，不伪造用户行为

### Requirement: 最终回答跨路径幂等与完整版本投影
系统 SHALL 以轮次内逻辑答案身份和字节偏移处理正常完成与恢复重放，保持相同片段幂等与冲突拒绝；最终正文选择可信顺序的完整答案版本，保留版本内合法多段及重复措辞。历史投影、分页与复制保持一致且有界，不删除原始段或重放业务。

#### Scenario: 同答案跨路径重放
- **WHEN** 正常完成和恢复重复提交同一item及偏移
- **THEN** 只发布一个逻辑片段，相同偏移不同正文拒绝冲突，双库和租约隔离保持有效

#### Scenario: 多个最终版本
- **WHEN** 存在多个完整最终答案或未完成的新版本
- **THEN** 按可信顺序选择最后完整版本，不拼接完整版本，不用未完成版本覆盖完整答案

#### Scenario: 合法多段及历史兼容
- **WHEN** 正文有合法重复段落，或旧数据包含来源不同的完整恢复副本
- **THEN** 保留版本内重复措辞，仅在完整边界与恢复证据成立时折叠副本；预览分页复制一致，无证据不猜测删除

#### Scenario: 有界与权限
- **WHEN** 超大正文分页或其他会话尝试读取结果
- **THEN** 有界读取且隔离权限，游标与版本匹配，不能通过读取重放治理动作
