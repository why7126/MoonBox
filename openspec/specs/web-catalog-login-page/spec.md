## Requirements
### Requirement: 登录页入口与页面状态
系统 MUST 提供 Web 前台登录页入口，使首页登录相关 CTA 能进入同一个前台登录页，并通过 `#login` 或等价前端状态表达登录页当前状态。

#### Scenario: 首页 CTA 进入前台登录页
- **WHEN** 访客在官网首页点击 `开启 MoonBox` 或 `打开第一个项目`
- **THEN** 系统显示 Web 前台登录页
- **AND** 首页主体内容不再作为当前主交互界面展示
- **AND** 系统不得展示管理后台登录页
- **AND** 当前路径不得变为 `/admin`

#### Scenario: 直接访问登录页状态
- **WHEN** 访客直接打开带 `#login` 或等价登录状态的地址
- **THEN** 系统显示 Web 前台登录页
- **AND** 用户名输入框可成为首个可填写字段

#### Scenario: 原型提交进入前台需求中心
- **WHEN** 访客在当前前台登录原型中填写用户名和密码并点击 `登录并开启宝盒`
- **THEN** 系统不得发起真实后端鉴权请求
- **AND** 系统不得跳转到 `/admin`
- **AND** 系统必须进入前台需求中心 `/requirements`

### Requirement: 登录页返回首页
系统 MUST 在登录页提供返回首页入口，并在返回时恢复首页视图、清除登录页路由状态。

#### Scenario: 用户从登录页返回首页
- **WHEN** 用户点击登录页左上角的返回首页入口
- **THEN** 系统恢复官网首页视图
- **AND** 浏览器路径回到 `/`
- **AND** 浏览器地址不包含 `#login`
- **AND** 登录页表单、遮罩和登录卡片不再作为当前主交互界面展示

### Requirement: 登录页品牌与背景视觉
系统 MUST 在登录页展示 MoonBox 品牌 Logo，并复用首页产品视觉作为背景，通过深色遮罩保证表单可读性。

#### Scenario: 登录页展示品牌 Logo
- **WHEN** 用户打开 Web 登录页
- **THEN** 登录卡片顶部展示 MoonBox 产品 Logo
- **AND** Logo 不是旧 Logo、占位图或纯文本替代

#### Scenario: 登录页背景保持可读
- **WHEN** 用户在桌面端或移动端查看登录页
- **THEN** 登录页背景展示首页产品视觉
- **AND** 背景叠加深色遮罩或等价视觉处理
- **AND** 登录表单、按钮和辅助文本清晰可读

### Requirement: 用户名密码登录表单

系统 MUST 在登录页提供统一用户名密码登录表单，使前台用户、后台管理员和超级管理员均从同一入口登录，并在登录成功后默认进入前台。

#### Scenario: 普通前台用户登录成功

- **GIVEN** 用户角色为前台用户
- **AND** 用户状态为正常
- **WHEN** 用户在 `/login` 提交正确用户名和密码
- **THEN** 系统创建可服务端校验的统一登录态
- **AND** 系统默认进入前台需求中心
- **AND** 用户菜单不展示“进入后台”入口

#### Scenario: 待激活用户首次登录自动激活

- **GIVEN** 用户角色为前台用户或后台管理员
- **AND** 用户状态为待激活
- **WHEN** 用户在 `/login` 提交正确用户名和密码
- **THEN** 系统允许登录
- **AND** 系统将用户状态更新为正常
- **AND** 系统默认进入前台需求中心

#### Scenario: 后台角色登录后展示后台入口

- **GIVEN** 用户具备后台管理员角色或为系统超级管理员
- **AND** 用户状态为正常或待激活
- **WHEN** 用户在 `/login` 登录成功
- **THEN** 系统默认进入前台需求中心
- **AND** 用户菜单展示“进入后台”入口

#### Scenario: 冻结删除与凭证错误登录失败

- **WHEN** 用户状态为已冻结或已删除，或提交不存在账号/错误密码
- **THEN** 系统拒绝登录
- **AND** 系统不得创建有效服务端会话
- **AND** 系统不得写入有效前端登录态
- **AND** 错误提示不得暴露内部权限实现细节

### Requirement: 登录页原型提交边界

系统 MUST 将登录页提交接入正式统一登录能力；登录页不得继续停留在纯前端原型提交边界。

#### Scenario: 提交连接统一鉴权

- **WHEN** 用户在 `/login` 提交用户名和密码
- **THEN** 系统调用后端统一登录能力或等价认证入口
- **AND** 登录成功后建立服务端可校验、可过期、可撤销的登录态
- **AND** 登录失败时展示受控认证失败提示

### Requirement: 登录页信息收敛
系统 MUST 避免展示未纳入本需求的认证或账号流程入口。

#### Scenario: 未支持入口不展示
- **WHEN** 用户打开 Web 登录页
- **THEN** 页面不展示忘记密码入口
- **AND** 页面不展示申请体验入口
- **AND** 页面不展示注册入口
- **AND** 页面不展示第三方登录、邮箱验证码或手机号验证码入口

### Requirement: 登录页响应式与视觉约束
系统 MUST 保证登录页在桌面端和移动端均不出现关键内容溢出、遮挡或非 MoonBox 视觉语言，并保证密码显隐控件不破坏登录页布局。

#### Scenario: 桌面端登录卡片居中展示
- **WHEN** 用户在桌面端打开 Web 登录页
- **THEN** 登录卡片居中展示
- **AND** 背景产品视觉可见但不干扰表单阅读

#### Scenario: 移动端不溢出不遮挡
- **WHEN** 用户在移动端打开 Web 登录页
- **THEN** 登录卡片、输入框、按钮和返回入口不横向溢出
- **AND** 关键文案不互相遮挡
- **AND** 密码显隐控件不超出登录卡片边界
- **AND** 密码显隐控件不遮挡密码输入内容或登录按钮

#### Scenario: 登录页符合 MoonBox UI 规则
- **WHEN** 登录页展示给用户
- **THEN** 页面使用深色 MoonBox 主题
- **AND** 主按钮使用金色强调
- **AND** 登录卡片使用近直角和细线边框
- **AND** 页面不引入蓝紫科技渐变、大圆角卡片或厚重阴影

#### Scenario: 密码字段显隐控件布局稳定
- **WHEN** 用户在登录页输入密码并切换显示/隐藏状态
- **THEN** 密码输入框右侧预留足够空间容纳显隐控件
- **AND** 显隐控件与输入框垂直居中或等价对齐
- **AND** 登录卡片高度、字段间距、记住我、登录按钮和错误反馈区域不发生不必要抖动

### Requirement: 前台接口统一登录态

系统 MUST 允许已登录的前台用户访问前台业务接口，并避免将前台接口绑定到后台管理员角色。

#### Scenario: 普通前台用户访问需求中心上下文

- **GIVEN** 普通前台用户已登录
- **WHEN** 用户访问需求中心前台上下文接口
- **THEN** 系统接受统一登录态
- **AND** 系统返回该用户可访问的前台上下文
- **AND** 系统不得要求用户具备后台管理员角色
