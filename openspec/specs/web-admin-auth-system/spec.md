## Requirements
### Requirement: 超级管理员账号密码登录

系统 MUST 提供管理后台登录入口，支持系统内置超级管理员和具备后台管理员角色的用户使用用户名和密码登录后台。

#### Scenario: 超级管理员登录成功

- **GIVEN** 系统存在唯一系统内置超级管理员
- **AND** 超级管理员账号状态允许访问后台
- **WHEN** 超级管理员提交正确用户名和密码
- **THEN** 系统创建服务端会话记录
- **AND** 系统返回 access token、过期时间和当前管理员摘要
- **AND** 当前管理员摘要包含用户 ID、用户名、角色、状态和是否系统内置超级管理员

#### Scenario: 待激活后台管理员首次登录自动激活

- **GIVEN** 用户具备后台管理员角色
- **AND** 用户状态为待激活
- **WHEN** 用户提交有效临时密码登录管理后台
- **THEN** 系统允许本次首次登录激活
- **AND** 系统将用户状态更新为正常
- **AND** 系统创建服务端会话记录
- **AND** 系统返回 access token、过期时间和当前管理员摘要

#### Scenario: 正常后台管理员登录成功

- **GIVEN** 用户具备后台管理员角色
- **AND** 用户状态为正常
- **WHEN** 用户提交正确用户名和密码
- **THEN** 系统创建服务端会话记录
- **AND** 系统返回 access token、过期时间和当前管理员摘要

#### Scenario: 前台用户不得登录管理后台

- **GIVEN** 用户不具备后台管理员角色
- **WHEN** 用户提交正确用户名和密码登录管理后台
- **THEN** 系统拒绝登录
- **AND** 系统不得创建服务端会话记录
- **AND** 系统不得将待激活前台用户状态更新为正常

#### Scenario: 已冻结或已删除用户不得登录

- **GIVEN** 用户状态为已冻结或已删除
- **WHEN** 用户提交正确用户名和密码登录管理后台
- **THEN** 系统拒绝登录
- **AND** 系统不得完成首次登录激活
- **AND** 系统不得创建服务端会话记录

#### Scenario: 登录失败不泄露内部状态

- **WHEN** 用户提交错误用户名或密码，或账号状态/角色不允许访问后台
- **THEN** 系统返回受控认证失败错误
- **AND** 响应不得泄露账号是否存在、密码哈希算法、冻结前状态字段、内部用户状态或系统路径

#### Scenario: 前端展示受控登录失败原因

- **WHEN** 后台登录 API 返回受控失败原因
- **THEN** 前端必须展示后端返回的受控错误说明
- **AND** 前端不得把账号不可用、无后台权限或登录态异常统一误导为用户名或密码错误

#### Scenario: 登录页密码可见性切换

- **WHEN** 用户在管理后台登录页输入密码
- **THEN** 前端必须提供显示或隐藏密码的受控按钮
- **AND** 切换密码可见性不得提交表单或改变输入框布局

### Requirement: access token 与服务端会话记录
系统 MUST 使用 access token 与服务端会话记录共同表达后台登录态，并确保后台登录态可过期、可撤销、可校验。

#### Scenario: 后台 API 校验会话
- **GIVEN** 请求目标为 `/api/v1/admin/**`
- **WHEN** 请求携带 access token
- **THEN** 系统校验 access token 签名或等价有效性
- **AND** 系统校验 access token 未过期
- **AND** 系统校验对应服务端会话存在、未过期且未撤销
- **AND** 系统校验关联账号状态为正常
- **AND** 系统拒绝待激活、已冻结、已删除或无后台管理员角色的账号访问后台 API

#### Scenario: 无效会话被拒绝
- **WHEN** 请求携带的 access token 过期、无效、对应会话不存在、已过期或已撤销
- **THEN** 系统返回 401
- **AND** 系统不得执行业务处理

### Requirement: 退出登录与会话失效
系统 MUST 支持后台管理员退出登录，并在账号状态变化时使相关后台会话失效。

#### Scenario: 退出登录撤销当前会话
- **GIVEN** 管理员已登录管理后台
- **WHEN** 管理员执行退出登录
- **THEN** 系统撤销当前服务端会话
- **AND** 前端清理本地登录态
- **AND** 再次使用同一个 access token 调用 `/api/v1/admin/**` 返回 401

#### Scenario: 账号状态变化使旧会话失效
- **WHEN** 账号被冻结、删除、重置密码或发生影响权限的状态变化
- **THEN** 系统使相关后台会话失效
- **AND** 相关旧 access token 不得继续访问 `/api/v1/admin/**`

#### Scenario: 临时密码说明登录前提
- **WHEN** 管理员创建后台用户或重置后台用户密码后展示临时密码
- **THEN** 前端必须提示临时密码可用于具备后台管理员角色的账号首次登录激活或正常登录
- **AND** 前端不得暗示前台用户、已冻结或已删除账号可凭临时密码登录后台

### Requirement: 后台路由守卫

系统 MUST 在管理后台前端提供路由守卫，避免未登录或登录态失效的用户继续停留在受保护后台页面。

#### Scenario: 管理后台正式入口

- **WHEN** 用户访问 `/admin`
- **THEN** 前端必须进入管理后台入口
- **AND** 未登录用户必须看到管理后台登录页
- **AND** 已登录后台管理员必须进入后台管理首页或当前默认后台页面
- **AND** 旧入口 `#admin-users` 必须保持兼容

#### Scenario: 未登录访问后台

- **WHEN** 未登录用户访问后台受保护路由
- **THEN** 前端进入后台登录页或等价登录入口
- **AND** 页面不得出现空白页、死循环跳转或不可恢复状态

#### Scenario: API 返回 401 后恢复登录路径

- **WHEN** 管理后台 API 返回 401
- **THEN** 前端清理不可用登录态
- **AND** 前端引导用户进入后台登录页或等价登录入口

#### Scenario: 后台登录请求使用后端 API 地址

- **WHEN** 管理员在 Web 前端提交后台登录或退出登录
- **THEN** 前端必须使用配置化 API base URL 或等价反向代理访问后端认证 API
- **AND** 前端不得将后台认证请求固定发送到 Web 前端服务 origin

### Requirement: 后台 API 正式鉴权

系统 MUST 将 `/api/v1/admin/**` 管理接口保护在正式认证授权边界内，不得继续依赖 `x-admin-role: admin` 占位鉴权。

#### Scenario: 管理接口拒绝匿名访问

- **WHEN** 请求 `/api/v1/admin/**` 且未携带有效凭证
- **THEN** 系统返回 401

#### Scenario: 管理接口拒绝无权限身份

- **GIVEN** 请求携带有效凭证
- **AND** 当前身份无后台权限
- **WHEN** 请求 `/api/v1/admin/**`
- **THEN** 系统返回 403

#### Scenario: 占位 Header 不再授权

- **WHEN** 请求仅携带 `x-admin-role: admin`
- **AND** 请求未携带有效 access token 和服务端会话
- **THEN** 系统不得将该请求视为已认证后台管理员
- **AND** 系统返回 401

### Requirement: 超级管理员首次初始化

系统 MUST 支持通过环境变量首次幂等创建唯一系统内置超级管理员，并在生产环境拒绝弱初始密码。

#### Scenario: 首次初始化超级管理员

- **GIVEN** 系统不存在系统内置超级管理员
- **WHEN** 系统启动或执行初始化流程
- **THEN** 系统读取环境变量中的超级管理员用户名和初始密码
- **AND** 系统创建唯一系统内置超级管理员

#### Scenario: 重复启动不重复创建

- **GIVEN** 系统已存在系统内置超级管理员
- **WHEN** 系统再次启动或执行初始化流程
- **THEN** 系统不得创建第二个系统内置超级管理员

#### Scenario: 生产弱密码被拒绝

- **GIVEN** 系统运行在生产环境
- **WHEN** 超级管理员初始密码为空、为示例值或不满足强度要求
- **THEN** 系统拒绝完成生产初始化
- **AND** 系统给出受控错误
- **AND** 系统不得记录明文初始密码

### Requirement: 认证敏感信息保护

系统 MUST 防止认证敏感信息出现在 URL、日志、错误上报、埋点、截图、API 响应或审计明文中。

#### Scenario: 敏感凭证不进入可见通道

- **WHEN** 系统处理登录、退出、会话校验或认证失败
- **THEN** 明文密码、access token、会话 ID 明文不得写入 URL、日志、错误上报、埋点、截图、API 响应或审计明文
