# 需求中心稳定读取性能修复规格

## MODIFIED Requirements

### Requirement: 稳定读取性能与授权一致性

系统 SHALL 降低未变化快照和单文档读取的重复处理，同时保留文件变更可见性、成员与对象授权、项目绑定、写入围栏及缓存隔离。

#### Scenario: 成功暖读性能对照
- **WHEN** 对同一有效快照及环境的基线和修复版分别预热并对context和MD各采样至少30次
- **THEN** 两类暖读p95均较成功基线降低至少50%，冷读单列，不以503快速失败作为基线

#### Scenario: 文件与权限变化
- **WHEN** 文件新增删除重命名修改（含同尺寸快速修改）、权限撤销或绑定/围栏变化
- **THEN** 下一次有效同步读取反映变化或安全拒绝，不能返回跨用户越权内容或混合版本

#### Scenario: 持久解析失败恢复
- **WHEN** 注册表语法错误后被纠正
- **THEN** 读取先返回安全错误，纠正后重试恢复成功；不得永久缓存失败或绕过校验读取


#### Scenario: 首屏与刷新固定规模验收
- **WHEN** 在用户确认的当前固定副本规模下（记录实际文件、字节与授权卡片数），对同版本同权限同负载采集至少30个冷样本和至少30个暖样本
- **THEN** 系统 SHALL 保持全部卡片和正确状态，context暖/冷P95不超过3/5秒，真实首卡暖/冷P95不超过4/6秒，按nearest-rank计算并记录成功基线差值

## ADDED Requirements

### Requirement: 同快照索引等价与安全复用

系统 SHALL 在每次请求的同一快照内至多解析一次REQ注册表与一次BUG注册表、构建一次唯一归档目录集合索引，并保留身份歧义、路径安全及状态保护语义。

#### Scenario: 异常身份与归档候选
- **WHEN** 存在重复短ID、非法注册表、缺失对象、重复归档或非法路径
- **THEN** 系统保留既有失败或回退语义，活动目录优先，完整日期后缀匹配，不选择模糊候选

#### Scenario: 快照与权限变化
- **WHEN** 文件同尺寸快速修改、原子替换、目录变化、权限撤销或并发写入
- **THEN** 系统复核全部扫描根及安全不变量，返回一致有效快照或安全错误；复用条件不能证明时恢复完整读取，不使用缓存授权或执行状态

### Requirement: 聚合请求计时与资源约束

系统 SHALL 提供同request_id的阶段关联与有界缓存，正常路径未解释耗时不得视为验收通过。

#### Scenario: 完整请求成本核验
- **WHEN** 测量正常HTTP聚合及页面首卡
- **THEN** 记录快照、物化、解析、核对、投影、提交和序列化计时及嵌套关系、误差和差额归属，不记录敏感内容，不把不同采样相加

#### Scenario: 扩充规模与重复运行
- **WHEN** 参考及现有安全上限内合成归档规模分别以并发1和4运行30分钟
- **THEN** 卡片和权限结果完整，超限输入安全拒绝，新增缓存不超过64MiB及2个项目版本，峰值RSS不超过同规模基线加128MiB，预热后末5分钟RSS中位数不超过首5分钟加32MiB且无持续增长，每成功请求CPU耗时不高于基线

#### Scenario: 真实后台服务并行运行
- **WHEN** backend、worker与controller同时运行，使用真实授权状态库，对打开与刷新各采集30轮，并覆盖后台备份及空闲内容维护
- **THEN** 系统 SHALL 保留相同3/5秒HTTP与4/6秒首卡P95目标；后台维护不得因整库长期读锁或逐对象全表引用扫描阻塞页面，不通过关闭后台、跳过审计或清空历史换取达标

#### Scenario: 不同主机负载下持续读取
- **WHEN** 正式路由在自然负载与额外2核受控负载窗口分别执行30次打开、30次刷新，后台三服务持续运行
- **THEN** 各窗口分别满足原暖HTTP及首卡P95目标，记录实际负载、版本、错误与完整样本，不删除长尾或以单一短窗口代替持续效果

#### Scenario: 请求构建期间权限变化
- **WHEN** 批量读取当前用户对象可见性后，卡片构建期间权限、成员资格或绑定发生变化
- **THEN** 返回前结束读事务并重新授权及核对权限，发生变化安全拒绝本次结果；展示批次不用于发送准入，不跨请求缓存授权

#### Scenario: 后台维护与健康检查成本
- **WHEN** 后台长期空闲或存在历史终态待对账记录
- **THEN** 维护按周期运行且不积压补跑，已释放槽位不重复UPDATE；可信收据、未知用量预留、原心跳有效期及失效拒绝保持不变，快速任务领取与恢复不等待历史扫描周期
