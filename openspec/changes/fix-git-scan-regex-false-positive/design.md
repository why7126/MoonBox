# Git 路径扫描精确匹配设计

## 方案

在路径规则的用户名首字符处排除正则元字符，避免把分支分隔符识别成用户目录。真实用户名和其后路径继续扫描，不按文件或目录整块豁免。虚构测试路径改用现有 example 占位符约定。

## 风险与验证

验证裸目录前缀的正则不误报，正则内包含具体用户路径仍报错，普通用户路径与测试文件内真实路径仍报错。警告逐条按哈希、测试数据或实际隐私复核，不自动降低严重性。两处末尾空行属无行为格式修复。
