# 归档工具独立路由规格

## ADDED Requirements
### Requirement: 独立工具与业务事实分离
系统 SHALL 使用部署受控工具根执行归档，保持原业务根与绑定身份。
#### Scenario: 正常跨入口归档
- **WHEN** CLI、服务和执行器使用同摘要只读工具包
- **THEN** 正常、阻断、恢复和重放使用原授权及事实目录，不覆盖工作区
### Requirement: 工具不可信时关闭写入
系统 SHALL 拒绝显式配置的缺失、可写、符号链接、路径逃逸或摘要不符工具包，不自动退回工作区版本。
#### Scenario: 子容器版本不同
- **WHEN** 子容器工具摘要与服务不一致
- **THEN** 在写入之前返回脱敏阻断且保留原操作
### Requirement: 历史恢复与回滚保护
系统 SHALL 保留历史证据、unknown及会话占用；无法验证恢复所需工具版本时阻断。
#### Scenario: 回滚执行器缺失
- **WHEN** 回滚版本缺失执行器
- **THEN** 保持任务领取冻结，不重跑历史轮次
### Requirement: 默认模式兼容
系统 SHALL 在未配置独立路由时保持原工具选择行为。
#### Scenario: 旧部署未启用
- **WHEN** 不提供独立工具配置
- **THEN** 既有归档门禁仍生效，不隐式启用新能力
