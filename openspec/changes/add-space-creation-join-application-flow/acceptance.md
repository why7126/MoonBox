# Acceptance

## 功能验收

- [x] 前台空间切换入口只展示“创建空间”，不展示加入空间入口或标签。
- [x] 创建空间弹窗采集名称、标识、说明、成员上限、存储空间、AI Tokens 和有效期。
- [x] 弹窗副标题整合隔离、审批和审批通过后负责人分配说明，不在表单上方重复展示审批提示行。
- [x] 除空间说明外，必填项展示红色星号。
- [x] 名称输入后自动生成标识，用户手动修改标识后不再自动覆盖。
- [x] 成员、存储空间、AI Tokens 和固定到期时间按后台空间管理一致规则校验。
- [x] AI Tokens 输入框不额外展示 `Tokens` 单位。
- [x] 到期时间默认本季度最后一天 23:59:59，并复用后台空间管理日期时间选择器交互。
- [x] 提交期间按钮禁用并显示“正在创建...”。
- [x] 提交成功后生成待审批申请，不直接创建正式空间，不展示进入空间入口。

## UI 验收

- [x] 创建弹窗符合返修后原型拆解。
- [x] 1440px 视觉验收覆盖默认表单、配额、有效期、到期时间、提交按钮和待审批结果态。
- [x] 表单字段、toast、结果态和底部操作无重叠或溢出。
- [x] 负责人卡已删除；到期时间在 AI Tokens 下方另起一行。
- [x] 到期时间选择器在 1440x900 视口打开时不得超出可视区域，必要时向上展开或在视口内限位，确保可完成日期时间选择。
- [x] 到期时间选择器不展示“取消 / 确定”操作；点击 3 个快捷按钮后立即应用并关闭，点击控件外区域关闭并保留当前值，面板自身不出现滚动条。
- [x] 弹窗右上角关闭按钮清晰可见，具备稳定尺寸、边框/背景和 hover/focus 状态。
