# 规则替代审阅历史视觉核对

本页记录旧版视觉验收，仅供历史追溯，不作为 2026-10-23 轻量方案的页面证据。

审阅者：本次实施 Agent；不代替空间所有者的业务批准或 Sprint 人工签署。

用户已确认右侧差异抽屉、保留义务/签署分组、底部动作与独立启用区。真实 Chat 壳沿用现有 Composer，桌面抽屉 720px、确认窗 520px；390 窄屏抽屉满宽，确认窗保留两侧间距。深浅主题文字、边框、遮罩、长摘要换行和底部按钮已目视核对，截图与 computed style 在 product/，阶段×视口映射在 acceptance-plan.json。最终确认窗显示项目/空间、对象、条文、修订、摘要、24 小时期限及批准不发送/不归档说明。

| 阶段 | 证据前缀 | 观察结论与边界 |
|---|---|---|
| 待审 | prepared-final | 四组合，隔离投影夹具；审批能力来自真实 API，未产生批准 |
| 过期 | expiry-display-fixture | 四组合，显式过期提示、动作禁用；时间字段夹具不冒充自然经过24小时 |
| 拒绝 | rejected-display-fixture | 四组合，状态和动作禁用；实际拒绝请求另见 ordinary-rejected |
| 权限不足 | permission-denied | 四组合，真实管理员账号与 API 403，无法审批 |
| 确认 | confirm-final | 四组合，共用动作族，取消保持审阅；本轮没有提交撤销 |

样式抽样：14px/21px 字体、按钮 7px 10px padding/8px gap、1px主题边框、drawer内部滚动，差异桌面双列/窄屏单列，文档无水平溢出。旧截图用于行为沿革，不作为新增确认说明的最终依据。Esc 会把焦点归还入口，取消不关闭底层审阅，内部点击不误关闭。附件证据使用独立可写会话与 MinIO，审阅截图中的只读会话状态不替代附件测试。

初次启用 prepared/confirm/active 的独立面板已观察；独立信任实际转换由 exact-change-bootstrap.json 验证。UI 截图不证明签名可信性。所有图片中的账号/项目/条文为一次性合成样本，无正式对象或凭据。
