# MoonBox 产品手册总览

MoonBox 是面向 AI 创业者、小型软件团队和 AI 原生企业团队的 AI 原生软件工厂，帮助团队建立由 Agent 驱动的软件研发组织。

## 适用读者

| 读者 | 主要任务 |
|---|---|
| 产品负责人 | 理解 MoonBox 的产品边界、版本能力和部署形态。 |
| 研发负责人 | 评估 Agent Workflow、OpenSpec、需求/缺陷/Sprint/发布治理如何落地。 |
| 运维负责人 | 按部署矩阵选择本地或生产 Docker Compose 模式。 |
| 团队成员 | 学习如何通过规范、技能和文档协同完成软件研发。 |

## 当前能力

- Web 端、管理后台和 REST API。
- SQLite 本地开发路径与 MySQL 生产兼容路径。
- MinIO/S3 兼容对象存储，采用一个项目一个 Bucket，桶内通过二级目录/前缀区分资源类型。
- OpenSpec、需求治理、缺陷治理、Sprint 治理和发布治理。
- Docker Compose 本地六模式矩阵与生产外部依赖部署。
- Mintlify 产品手册源目录与部署预览服务。

## 使用边界

本手册只记录公开产品使用说明、部署入口、操作注意事项和版本差异。不得写入密钥、真实客户数据、内部数据库连接串、Authorization header、Cookie、对象存储凭据或生产私有运维地址。


## 需求中心卡片信息

卡片在等级和负责人标签后展示已有的根因状态与预估开发人天。两者同时存在时，根因状态在前；进入验收或已完成阶段后仍保留。

BUG 有根因分析内容后显示“根因待确认”或“根因已确认”，点击可查看根因文档；状态冲突时按待确认展示。开发人天来自所属迭代的估算，支持 0 和小数，悬停可查看“预估开发人天”提示，不代表实际耗时。缺失信息不会显示占位数字。

### 卡片人天展示优化

人天按有效非负值d分档：S为0≤d≤1，M为1<d≤3，L为3<d≤5，XL为5<d≤10，XXL为d>10；显示“档位·数值人天”（如“M·3人天”），不含“开发”前缀。S青、M蓝、L紫、XL橙、XXL玫红，保留精确值和“档位 · 预估开发数值人天”提示；缺失/非法值隐藏。标签保持统一的紧凑样式；根因仍可点击查看，支持键盘操作。

人天标签中的分隔点采用紧凑留白。
