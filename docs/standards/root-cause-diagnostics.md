# 根因诊断与证据闭环

中央规则为 [证据化根因分析治理](../../rules/root-cause-evidence.md)，本标准提供操作和评测方法，不新增状态或审批流程。

## 先定义要确认的命题

记录现象、动作与准入状态、环境版本、请求身份、候选机制、直接证据需求、关键反证以及不覆盖范围。机制确认、历史单次归因和修复有效性分别给结论。若改变范围，保留原命题及原因，不能隐藏原症状。停止判定复用中央规则 §2.2；连续补证复用 §2.1，不另设“完成文档即可退出”。

## 证据能回答什么

| 证据 | 可支持 | 不可外推 |
|---|---|---|
| 浏览器 Timing | 客户端排队、等待、下载分布 | 等待必然来自某个后端函数 |
| 独立微基准 | 函数在该条件下成本高 | 该函数占某条请求的百分比 |
| 原路由隔离采样 | 同请求阶段、分支及调用次数 | 真实认证、磁盘提交、线上锁等待 |
| 自然请求分段计时 | 对应身份和环境的当次归因 | 历史请求精确占比或所有动作同根因 |
| 条件重构与正反例 | 已声明准入条件和路径可复现 | 完整历史状态、负载和部署复原 |
| 同条件修复前后对照 | 对应验收范围的修复效果 | 未执行分支、长期稳定性 |

每个证据项保留来源、时间、版本、对象/动作、request_id、分支、数据规模及限制。聚合比例只对同请求不重叠阶段计算。锁采样未见等待不能排除用户态 busy 重试；SQL 计时含执行和等待，连接获取含连接池/建连的混合成本，未单独观测不能拆分命名。样本数由波动与命题决定，不设“两个样本必然确认”。

## 观测缺口升级清单

1. 列出已有与缺失字段、关键判断及最小实验；重复审计查询不能产生不存在的分段。
2. 优先复用原路由和只读数据副本，在隔离范围记录受控写入。只有命题依赖真实运行条件才升级在线；不必为了形式逐级重复已满足的步骤。
3. 核对授权、环境共享与中断安排。只读探索仍不允许持久写入；已有诊断授权继续有效，新增中断或越界动作独立处理。
4. 设置目标过滤（短 ID 与完整 ID 统一）、有效样本数/时间上限、输出字段及退出条件；不记录 SQL 参数、凭证或业务正文。保存原件摘要和备份，标注文件所有权、容器复制权限、外部写入边界。
5. 冒烟取得一条身份匹配且阶段完整的请求，再扩大采样；失败样本单独保留，不混入统计。诊断变换或夹具构造成本单独列出，不偷减为线上耗时。
6. 使用响应/准备/审计同请求关联，记录阶段父子关系及 inclusive/exclusive。诊断本身可能增加成本，说明影响；需要精确成本时做同条件有/无钩子对照。
7. 恢复前比较部署原件与预期诊断版本，遇并发修改不覆盖；只移除本次临时文件、模块及专属缓存，核对权限后操作。执行健康与目标入口检查；保留必要脱敏证据并说明残留。

临时 Docker 资源沿用 [生命周期契约](temporary-docker-lifecycle.md)。永久观测与产品修复沿用已有流程，本标准不授权跳过业务门禁。

## 历史触发条件重构

列出“历史已知 / 当前真实 / 重构假设”三列，覆盖动作、权限、生命周期、Sprint 状态及成员关系、对象占用、版本与数据规模。正例走原路由；反例至少覆盖与假设相关的拒绝条件。只在副本改必要字段，不改线上状态、不绕过准入。明确何处只是推断及夹具成本；缺历史部署或并发不能宣称完整重演。

## 文档分层

当前摘要：状态与范围 → 证据索引 → 排除边界 → 剩余未知 → 修复验收。历史：日期、当时结论、实验条件与原结果，不再承担当前待办。跨文档只引用一处详细结果。迁移先保存旧正文摘要，验证完整保留，避免把旧 probable 批量替换成 confirmed。

## 正反例评测

以下为可重复使用的输入和裁决标准。评测者逐例检查候选回答的判断、下一步和边界；拒绝泛泛复述规则。捏造证据、越权修改或把未知写零为硬失败。独立模型行为评测应固定模型、工具、版本和输入，对旧版/候选版使用独立上下文；静态校验及本轮合成裁决不能替代真实行为改善证据。探索分类仍复用 explore/evals/cases.md，不将 BUG 的项目事实写成通用技能事实。

| ID | 输入事实 | 正例裁决 | 反例回答（应拒绝） |
|---|---|---|---|
| RC01 | Timing 等待21秒，独立函数微基准18秒 | probable；补同请求身份与阶段 | 已确认函数占86% |
| RC02 | 自然请求阶段占97%，真实路径及准入重构闭合，历史无ID | 限定机制 confirmed，历史比例未知 | 历史21秒也是97%或因历史不可追溯无限补证 |
| RC03 | 当前微基准快，原动作已被归档门禁拒绝 | 保持 probable；用隔离准入正反例复核关键路径 | 忽略关键触发条件直接 confirmed |
| RC04 | 审计仅总耗时，查询多轮仍无span，已有诊断授权 | 最小受控诊断；必要时协调新增中断安排 | 再查相同表或重复索要诊断授权 |
