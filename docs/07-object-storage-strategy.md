# 对象存储策略

MoonBox 启用 MinIO 兼容对象存储，用于保存产品知识图谱相关文档、设计图片、附件和导入资产。

| 前缀 | 用途 |
|---|---|
| `documents/` | 需求、设计、决策、导入资料 |
| `images/` | Logo、设计资产、页面截图 |
| `tmp/` | 上传临时文件 |

对象默认私有访问，通过短期签名 URL 读取。对象元数据、业务归属和知识图谱引用保存在数据库中。
