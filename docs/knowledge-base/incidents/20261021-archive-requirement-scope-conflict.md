# 归档条文冲突与验收进度事故记录

来源BUG-0062、sprint-012。REQ-0046旧归档36项验收完整，后续同模块独立条文被模块级范围误判冲突；异常被归并为证据无效，进度降为0/36。Sprint浅层任务与trace预检通过，深层同步却迟到阻塞。

## 原因与处理

范围键改为模块与Requirement标题组合，保守拒绝重命名、重复标题、未知操作和缺失delta。完整baseline→expected链、唯一完成归档、交付及delta哈希、原条文与后继最终效果、并发复读继续保留。后继之间可以沿已证明顺序更新彼此条文，但不得触及原对象保护范围。

证据完整性独立于恢复准入；恢复失败仍保留有效AC，实际附件损坏按项减少。产品、CLI、Sprint预检与Workflow Sync共享深层核验，终态写入前拒绝，不靠改旧manifest、journal或清零进度回避冲突。

## 预防与验证边界

增加同模块独立条文正例与真实同条文负例，避免把旧模块级测试当成永久业务约束。使用隔离失败前后全树哈希证明零写入。真实仓库只读结果、合成回归、部署产品与视觉证据分别记录；修复ready不等于Sprint已关闭。部署验收与最终结果以Change verification及验收清单为准。
