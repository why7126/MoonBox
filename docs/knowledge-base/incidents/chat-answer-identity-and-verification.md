# Chat 最终答案身份与自动核验状态经验

## 问题与根因
BUG-0065正常完成和恢复使用不同来源前缀，相同答案穿透来源去重；最终正文全量拼接后重复。BUG-0066执行终态停止轮询，而自动核验晚于执行结束，首次待核验状态因此滞留。

## 已验证处理
答案身份跨正常/恢复路径一致，按字节偏移幂等；完整版本提交标记与原轮次围栏共用。历史展示修正不删除业务消息，不能按重复段落猜测。对已保存完整消息，仅在有可信完整来源选择时覆盖读投影，防止受限事件读取回退内容。
核验独立于执行终态，读取匹配操作者/对象/版本的队列事实；最新轮次有界跟进，历史不批量轮询，取消与请求级身份同时阻止迟到响应。

## 证据边界
SQLite、MySQL及前端回归通过；隔离真实浏览器通过HTTP观察后台自动确认，未点击核验或调用模型。原问题会话刷新后正文显示一份。历史上游item身份未完整留存，不据此断言每次真实重复都来自同一原因。
