# Chat 输出事件与正文一致性经验

当前代码机制已在隔离 SQLite 中复现：事件先提交而正文只在正常收尾保存，会在断连后留下事件与正文不一致；仅恢复终态不能修复正文。历史原轮次数据已删除，不反推其实际路径。

修复采用锁内幂等补存和有界只读投影；正文存在性与执行完成分开判断，最终答案优先于过程增量。消息写入失败不能吞掉 unknown 状态，GET 不能隐式修改历史。

复用检查：断连、正常终结对照、恢复三类终态、并发重复恢复、分页、权限和事件缺口。后端回归与合成 DOM 检查已有证据；真实浏览器视觉验收待完成，因此本记录不表示整体交付通过。验证入口：`openspec/changes/fix-chat-assistant-output-missing-from-conversation/verification.md`。
