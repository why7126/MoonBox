# 需求中心快照读取性能与安全复用

## 已验证机制

同一请求的注册表身份索引与归档目录索引可消除逐卡重复解析和扫描；106身份与171目录对照需同时覆盖短ID歧义、活动优先、重复归档、删除、版本隔离和越界路径。标题只在不可变请求上下文复用，不缓存授权或可变响应。

首遍缓存字节只是候选，第二遍完整读取后逐字节比较。即使文件系统没有推进mtime/ctime，第二遍差异也会使尝试失效，后续回退双遍完整读取。用目录描述符、O_NOFOLLOW、文件类型/链接数/大小及读取前后fstat保留原安全边界。缓存预算需计入字典、路径和元数据对象，不能只算正文。

## 测量边界

局部索引微基准、ASGI HTTP和真实浏览器分别记录。正常HTTP需补齐核对、投影、提交、序列化调度及请求审计；父子阶段不能相加。冷样本清理应用缓存不等于清理操作系统页缓存。旧基准夹具会随业务模型字段和模块相对导入变化失效，须先跑成功探针再做长测。

## 当前限制

本次按固定输入完成时延和30分钟资源验证；功能回归、配对HTTP和真实浏览器分别签认，首次空库初始化单列。长请求下RSS应独立定时采样，不能等请求结束才采集；先按目标并发预热。尾部不稳定时固定扩大样本数并保留既有慢样本，不按结果挑选批次。源规模增长超过固定上限时，应由用户明确选择上限内扩容/超限拒绝或另行评审上限；本轮用户选择保留安全上限。证据与当前结果见[Change验证记录](../../../openspec/changes/fix-requirement-center-context-load-latency/verification.md)。
