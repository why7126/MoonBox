# Chat 跨秒消息倒置的排序与时间分离实践

## 问题与依据

BUG-0055 的根因证据 E1—E6 解释了轮次开始时间被用作助手消息时间、前端时间优先排序导致的跨秒倒置。完整事实源见 [根因分析](../../../issues/bugs/review/BUG-0055-chat-turn-message-order-inversion/root-cause.md)。

## 修复与预防

消息排序使用轮次和轮内角色的确定性总序，分页前纳入虚拟身份；显示时间独立标注来源，历史不可靠时间保留且降级。游标只能防止偏移漂移，已越过游标的旧轮迟到输出还需复核已加载范围。复核串行且分批，避免轮询不断取消深页工作；保护会话切换和滚动锚点。

验证同时比较后端全集与前端合并，覆盖跨秒、拆轮页、重复页、晚到输出和持久化转换；比较器单测不能替代接口、集成和真实产品观察。恢复保持既有终态与部分输出语义，不通过改写时间掩盖问题。

## 当前验证边界

SQLite/ASGI 与 React DOM 合成回归已有证据；MySQL 真实运行和部署浏览器验收尚未完成，本文不宣称缺陷已关闭。进度与后续证据见 [Change 验证记录](../../../openspec/changes/fix-chat-turn-message-order/verification.md)。
