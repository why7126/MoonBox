# 历史归档证明与后续同步经验

REQ-0056完成归档后，BUG-0073同步追加关联缺陷表并更新时间，使全文哈希绑定失配。仅逆向这两处差异即可精确匹配原哈希，确认合法后续元数据变化与未知正文变更需要分别验证，不能删除原证明后重跑。

fix-archive-trace-supplement以独立补证保留原文、原证明哈希及当前哈希，消费时仍复核其他proof字段、缺陷归属与已归档状态。43项回归及2项自动验收通过。[实现与验收](../../../openspec/archive/2026-11-01-fix-archive-trace-supplement/trace.md)。这只覆盖追加缺陷索引和更新时间，不接受任意文档漂移。

Sprint关闭同步随后改写三份既有验收回填的事件和时间，再次导致绑定失配。已恢复为原证明精确匹配字节，关闭事实保留Sprint文档；迁移后当前导航单独修复，最终53份文件扫描通过。[关闭复核](../../../iterations/archive/sprint-018/acceptance-report.md)。这次恢复不代表同步器已永久修复，后续行动沿用S16-A001。

可复用顺序：先识别变更文件和字段；取得原字节哈希证据；只对确定差异建立独立补证；保留原journal/manifest；执行完整关闭后再次检查。语义相近不等于证明一致，目录已移动不等于完整收尾。
