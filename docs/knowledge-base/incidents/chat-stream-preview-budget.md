# Chat 流式片段不等于正文长度

BUG-0067 的旧预览固定读取 21 段，并以返回 21 段判断截断。原现场 294 段仅 1126 bytes，前 21 段恰好对应半句截图；红测证明 20 正常而 21/22/294 失败。片段数取决于上游流式粒度，不能代表用户正文是否过长。

修复使用字符预算、批量读取窗口、元数据额外探测；确有剩余内容才提示仅展示部分输出。读取预算始终有界，不能为解决截断而无界加载。历史缺口与损坏另行标注，不与正常生成、展示限制或执行终态混用。

复验覆盖恰好字符/字节/片段边界、中文换行、最终答案身份、跨轮次游标、无写入读取，以及 SQLite/MySQL。UI 回归使用真实浏览器和 API 加隔离合成数据；这证明展示交互，不替代真实 Agent 执行轮次。证据归属 fix-chat-stream-preview-premature-truncation。
