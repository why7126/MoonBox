# 直接治理命令完成证明与安全核验

## 已确认机制

全仓指纹把无关对象编辑与本轮真实交付冲突混为一类。同步成功后再回填说明也会改变全仓指纹，导致执行结束而阶段保护未解除。历史 BUG-0055 未保存同步时的文件级清单，因此不能从当前差异倒推出当时的具体文件归因。

## 防止复发

同步证明记录动作相关文件摘要，最终收尾核验复读相关依赖，同时检查全局身份唯一性、关联与 Sprint 容量。只有明确的派生说明字段可以归一化，正文、任务、规则与能力规格保持受保护。专用评审和归档证明不被通用核验替代。

终态执行进入持久核验队列，重启可重建，按 operation/version 去重，不依赖看板刷新。错误区分缺证、损坏、身份变化、相关冲突和权限变化。旧步骤只读保存，恢复产生新的当前核验，不伪造历史证据。

## 验证边界

真实模型执行、HTTP 接口回归、CLI、数据库兼容和视觉观察分开记录。准备成功、按钮可点、进程退出 0 均不能独立证明完成；必须回读最终成果、卡片阶段与下一动作准入。本轮产品观察结果以 Change 验收证据为准。

隔离副本需要保留技能入口依赖的完整元数据与治理辅助模块。仅通过导入检查或 dry-run 不足以证明正式同步可执行；本轮分别发现原型追溯字段和生命周期辅助模块遗漏，实际模型样本正确阻断。应先在独立预检副本执行对应正式同步，确认两条路径的依赖闭包，再消耗真实模型额度。预检副本结果不能冒充模型样本成功。

当前执行保护是可变记录，不能作为旧轮次历史证明的唯一读取索引。合法后续同步替换保护后，历史签认仍按原会话与请求身份读取；只读历史展示与当前动作准入分离，不提供旧操作恢复能力。

隔离样本的前检通过后，模型仍可能把共享 YAML 手工拼接成无效格式；本轮 REQ 被运行时写权限门禁停止，未产生有效签认。成功收尾样本复用生成文档、保留有效 Sprint 数据并使用标准同步脚本。不得通过清空保护或修饰终态把失败样本计为成功；失败现场独立保留，追加模型调用按授权额度执行。
