# 跨入口续接的完成证明与执行保护收敛

BUG-0061 以 BUG-0055 为历史现场。旧产品执行只到进度同步，CLI 后继完成后，当前交付事实和原执行证明不再相等。原恢复要求完全相等、看板又覆盖为旧确认阶段，导致阶段回退和归档受阻。累计19项治理文件差异可核对，但没有完整同步时正文，不能把累计差异归因为首次失败的具体改写。

修复区分原执行历史、独立后继交付、当前动作准入。正式同步输出结构化事件/模式/结果/对象；shell退出0、dry-run/check、启动/进度同步均不代表交付完成。apply/modify后继需要标准验收收据、有效计划和逐AC输入、同任务范围及完整变化覆盖。旧记录缺少事件证据时保持缺证，不能静默升级为真实完成。

验收摘要是派生输出。多次验收产生的新增历史run/checkpoint摘要应核对归属后保留；不让旧失败报告成为当前成功证据，不允许借派生分类改写已有历史。相关交付变化、共享规则变化、缺证及过期证据继续阻断，无关对象并发不应绑入全局指纹。

核验与发送分开保护：核验前后重读权限、绑定、来源快照及guard版本；发送仍走当前准入。journal先记待确认签名、数据库条件确认后再标记完成，中断按同版本续接，不重放命令。原步骤与事件通过摘要比对保全。

验证方法：先跑完整临时入口及CLI归档对照，避免模型轮次耗在夹具缺件；再执行真实产品发送至归档业务终态。接口合成、真实模型、正式历史恢复和CLI证据单列。不能以ready、HTTP入队、按钮可点或模型文本替代归档目录、Issue阶段和标准脚本效果。
