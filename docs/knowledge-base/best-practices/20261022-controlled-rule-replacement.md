# 受控规则替代的验证与恢复经验

## 当前适用边界（sprint-013关闭后）

REQ-0050当前方案沿用正常验收、项目权限、完整历史及写入前复核，不要求新增独立密钥、签名收据、首次可信启用或额外人员确认。差异审阅保持只读，查看不代表批准或归档；业务规格演进以当前结构化验收和全文覆盖为准。原历史证明只读保留，不能将旧确认转换为新版准入。

来源：[当前需求交付](../../../openspec/archive/2026-10-24-add-controlled-rule-replacement-proof/trace.md)、[已验收规格演进](../../../openspec/archive/2026-10-26-support-reviewed-spec-evolution/trace.md)、[Sprint-013复盘](../retrospectives/sprint-013-retrospective.md)。可继续复用的是完整证据链、跨入口事实核验、保守未知状态与隔离样本，不复用已退出的授权交互。

## 2026-10-22历史方案经验（仅供旧记录理解）

以下保留原方案事实，不作为当前新Change的实施要求。适用：旧版独立授权、不可变审计和跨入口恢复。

- 批准绑定精确差异、义务、验收和项目版本；两个用途名称不能掩盖同一公钥，首次启用须核验独立密钥。
- 候选预检保持只读，领取才建立可回读原操作。已完成历史允许后续合法演进，但每一条中间边都必须有完整有效证据。
- 归档动作、差异采集和用量结算分别记录。控制器无需模型时记真实零调用；差异采集失败保留原操作并允许安全重试，不伪造成功快照。
- 测试镜像包括真实只读工具依赖；真实失败先看子进程证据，不能以 wrapper 退出码替代合并、迁移和同步事实。
- 自动投影字段与人工签署分开绑定。时间戳补齐不应导致误阻断，人工签署变化仍需拒绝。
- UI 权限、过期显示夹具、真实签名失败、真实附件成功和实际归档执行分别标注，不混为一轮产品证据。

验证入口：tests/unit/test_controlled_successor.py、test_sprint_archive_coordinator.py、src/backend/tests/test_trusted_archive_chat.py 与当前 Change 验收计划。
