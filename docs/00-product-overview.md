# MoonBox 产品概览

MoonBox 是 AI 原生软件工厂，通过 Harness、Agent Workflow 和产品知识图谱，让个人和小团队拥有一支完整的 AI 研发团队，从产品想法到软件交付实现全生命周期研发。

## 目标用户

| 用户 | 核心需求 |
|---|---|
| AI 创业者 / Founder | 快速验证产品想法，降低研发成本，用小团队完成大产品 |
| 小型软件团队 | 统一 AI 使用方式，补齐研发流程，沉淀项目知识，降低扩张成本 |
| AI 原生企业团队 | 建立 AI 原生研发组织能力 |

## 核心问题

- AI Coding 强大，但缺少产品分析、设计、架构、测试、发布和知识沉淀的完整体系。
- 单 Agent 难以形成研发组织能力。
- 产品知识无法长期积累，AI 难以持续理解产品。
- 小团队难以拥有完整研发职能。

## 核心能力

| 能力 | 定位 | 责任 |
|---|---|---|
| Harness Runtime | AI 软件研发操作系统内核 | 项目结构、规则、技能、Workflow、Context、Knowledge |
| Agent Workflow Engine | AI 研发流程编排系统 | Agent 调度、状态流转、节点审批、自动执行 |
| Product Knowledge Graph | 产品长期记忆 | 连接需求、设计、代码、测试、决策和经验 |
| Agent Organization Model | Agent 组织模型 | Agent 角色、协作、能力评价和资产管理 |

## 竞品差异

| 产品 | 定位 | MoonBox 差异 |
|---|---|---|
| Cursor | AI Coding | 从代码生成升级到软件生产 |
| Devin | AI 工程师 | 从单 Agent 升级到 Agent 组织 |
| Jira | 项目管理 | 从管理人升级到管理 Agent |
| GitHub | 代码协作 | 从代码仓库升级到软件工厂 |
